## 🎯 สาระสำคัญประจำบท (Core Concepts)
1. **Priority Queue ADT**: โครงสร้างที่คืนค่าข้อมูลที่มีความสำคัญสูงสุด (Min-Heap หรือ Max-Heap)
2. **Binary Heap Properties**:
   - **Structure Property**: เป็น Complete Binary Tree (บรรจุเต็มทุกระดับ ยกเว้นระดับสุดท้ายที่ชิดซ้าย)
   - **Heap-Order Property**: ค่าของโหนดพ่อต้องน้อยกว่าหรือเท่ากับลูกเสมอ (สำหรับ Min-Heap)
3. **การแทนค่าด้วย 1D Array (เริ่มที่ดัชนี 1)**:
   - Root อยู่ที่ index 1
   - Left Child ของโหนด $i$ อยู่ที่ $2i$
   - Right Child ของโหนด $i$ อยู่ที่ $2i + 1$
   - Parent ของโหนด $i$ อยู่ที่ $\lfloor i / 2 \rfloor$
