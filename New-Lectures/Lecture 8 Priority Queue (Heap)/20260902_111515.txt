อาจารย์:
"ปกติไปถ่ายเอกสารที่ร้านถ่ายเอกสารน่ะนะครับ ก็ต้องตามคิวใช่ไหมครับ มาก่อนถ่ายก่อน มาทีหลังคุณก็ต้องรอคอย
ปรากฏว่านิสิตจะไปถ่ายบัตรประจำตัวนิสิตใบเดียว จะไปแนบคำร้อง นะครับ บัตรประจำตัวนิสิตถ่ายแป๊บเดียวใช่ไหมครับ ถ่ายหน้าหลังอะไรไม่ถึงนาที
แต่ปรากฏว่าโชคร้ายครับนิสิต ไปถึงร้านถ่ายเอกสาร คนก่อนหน้าเราเนี่ย ยกหนังสือมาถ่าย ยกหนังสือ Text Book มาถ่ายตั้ง 700 หน้า นะครับ
ร้านถ่ายเอกสารบอกว่า ถ้าตามคิวก็อีก 2 วันน่ะกว่าจะถ่ายเสร็จ คุณรอไหมล่ะ คุณจะถ่ายบัตรนิสิตไม่ถึงนาที คุณต้องไปรอ 2 วัน
ส่วนใหญ่ทำไงครับ เจ๊ช่วยหน่อย ถ่ายบัตรนิสิตไม่ถึงนาทีเลย ยังไงถ่ายหนังสือ 2 วันมันก็คือ 2 วัน เจ๊แซงคิวให้ผมหน่อย มีการเจรจาต่อรอง และส่วนใหญ่นิสัยคนไทยก็จะ โอเค แซงคิวให้ใช่ไหมครับ
ก็ทำไม คุณถ่ายบัตรนิสิตไม่ถึงนาที แล้วคุณต้องไปรอ 2 วัน คุณรอปะล่ะ ไม่รอใช่ไหมครับ เขาก็จะแซงคิวให้คุณ เพราะไงถ่ายหนังสือมันก็ไม่เสร็จหรอก มันก็ไม่ได้ทำให้มันดีขึ้นใช่ไหมครับ เป็นต้น
พอเข้าใจไหมครับ ในบางอย่างนะครับ เขาก็พิจารณาว่า ถ้ามันใช้เวลาน้อยกว่า ก็แซงคิวให้

ในระบบปฏิบัติการคอมพิวเตอร์ก็เหมือนกัน งานอะไร งานอะไรที่มันรอคอย ระบบปฏิบัติการก็จะไว้ทำทีหลัง งานอะไรที่มันใช้เวลาน้อยกว่า เช่น การคลิกเมาส์ การกดคีย์บอร์ด ไอ้ระบบปฏิบัติการมันจะลัดคิวทำให้เราก่อน เป็นต้น
อันนี้คือแนวคิดของ Priority Queue เข้าคิวไหม? เข้าคิว แต่มีการพิจารณาสิทธิพิเศษ เงื่อนไขอะไรบางอย่าง ที่อะไรที่มันน้อยกว่า แซงคิวได้ ทันไหมครับ ไม่จำเป็นต้องไปต่อท้ายเสมอไป

อะ พอเข้าใจหลักการแบบง่ายๆ นะครับ อะ ไปต่อครับ
เขาบอกอธิบาย Priority Queue นะครับ คือโครงสร้างข้อมูลที่มีโอเปอเรชันอย่างน้อยที่สุด 2 โอเปอเรชัน ก็คือ:
1. Insert
2. DeleteMin
ในชั้นเรียนของเราก็พิจารณา ข้อมูลตัวไหนน้อยกว่า ให้แซงคิวได้ ก็เลยเป็นคำว่า DeleteMin
Insert เทียบเท่า equivalent แปลว่าเทียบเท่า เทียบเท่ากับการ Enqueue ในบทของ Queue นั่นเอง
DeleteMin จะทำการค้นหา ส่งค่าคืนกลับ แล้วก็ลบค่าที่น้อยที่สุด ใน Priority Queue ซึ่งเทียบเท่ากับการ Dequeue ในบทของ Queue นั่นเอง
เวลาเข้าก็ Insert เวลาออกก็ DeleteMin

แอปพลิเคชัน ในของฝรั่งมันก็เอาไปยกตัวอย่างกับระบบคอมพิวเตอร์ เช่น Printer Queue ถ้างานไหนใช้เวลาน้อยกว่า ปรินเตอร์มันลัดคิวปรินต์ให้ก่อน เป็นต้น หนึ่งของระบบปฏิบัติการนะครับ
อะ ไปต่อครับ Heap Structure คำว่า Heap คืออะไร ดูคำอธิบาย
สมัยผมเป็นนักศึกษาผมก็สงสัย โครงสร้างข้อมูล Priority Queue ไปเกี่ยวอะไรกับ Heap เปิด Dictionary แปลครับ Heap แปลว่า 'กองดิน กองทราย'
แล้วเราก็สงสัย มันไปเกี่ยวอะไรกับ Priority Queue
Heap แปลว่า กอง Dictionary ไปยกตัวอย่าง กองดิน กองทราย อย่างนี้เลยนะครับ
มันอย่างนี้ครับ เวลารถสิบล้อขนดิน ขนทรายมา แล้วเทลงกับพื้นน่ะ ดินกะทรายมันไหลลงมากองที่พื้น แต่ลักษณะที่ดินทรายมันไหลลงมากองที่พื้นเนี่ย ลักษณะมันจะเป็นสามเหลี่ยมเหมือนพีระมิด นึกออกไหมครับ ทรายมันค่อยๆ ไหลลงมา ข้างล่างจะกว้าง ข้างบนจะเป็นยอดแหลมอย่างนี้ ซึ่งโครงสร้างข้อมูลอย่างเงี้ย มันตรงกับโครงสร้างข้อมูลที่เป็น Priority Queue พอดี
ฝรั่งมันก็เลยเรียกชื่อย่อของ Priority Queue เพราะชื่อมันยาวใช่ไหมครับ Priority Queue มันเลยเรียกย่อว่า Heap ครับ ซึ่งตรงกันกับลักษณะโครงสร้างข้อมูลของมันพอดี คือเป็นสามเหลี่ยมเหมือนพีระมิดอย่างนี้

ในสไลด์กล่าวไว้ว่า Heap Structure ซึ่งจริงๆ แล้วมันมีหลายชนิดนะครับ แต่เราเลือกเรียนแค่ชนิดเดียวครับนิสิต หลายชนิดเรียนแล้วเดี๋ยวตก เอาแค่ชนิดเดียวง่ายๆ ครับ: Binary Heap
เอาอันที่ง่ายที่สุดเลยนะครับ สมัยก่อนเรียนหมด แต่สมัยปัจจุบันเอาแค่ง่ายๆ ชนิดเดียว Binary Heap
Binary แปลว่า 2 นะครับ Binary Heap is very common เป็นแบบที่ใช้งานกันทั่วไป ง่ายครับ
เราเรียกย่อๆ ว่า Heap เขียนก็ง่าย เรียกก็ง่าย
Heap จะมีคุณสมบัติด้วยกัน 2 ประการ:
1. Structure Property (คุณสมบัติเชิงโครงสร้าง)
2. Heap-Order Property (คุณสมบัติเชิงอันดับ)"
