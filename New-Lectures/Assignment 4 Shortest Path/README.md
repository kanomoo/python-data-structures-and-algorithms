## 📋 ข้อมูลภาพรวมของใบงาน
การบ้านนี้กำหนดให้นักศึกษา:
1. เขียนโครงสร้างกราฟในรูปแบบ **Adjacency List**
2. เติมตาราง **Dijkstra's Algorithm Table** ไล่ค่า `Known`, `Cost`, `Path` ให้ถูกต้องครบทุกรอบ
3. ทำการคำนวณแยก 2 กรณีตามจุดเริ่มต้น:
   - กรณีเริ่มต้นที่ **จุด A (Start A)**
   - กรณีเริ่มต้นที่ **จุด B (Start B)**
