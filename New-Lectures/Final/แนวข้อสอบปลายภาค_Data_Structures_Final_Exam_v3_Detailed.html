ข้อ 1: Hashing & Open Addressing with Double Hashing (10 คะแนน) บทที่ 7 (Hashing)

กำหนดให้มี Hash Table ว่างขนาด TableSize = 19 (ดัชนี 0 ถึง 18) โครงสร้าง Open Addressing ด้วย Double Hashing:

• Primary Hash: h₀(X) = X mod 19
• Collision Function: f(i) = i × (17 - (X mod 17)) สำหรับรอบการชน i = 0, 1, 2, ...
• Probe Address: h_i(X) = (h₀(X) + f(i)) mod 19
• ชุดตัวเลขที่ต้องแทรกตามลำดับ: 26, 45, 70, 85, 102, 123, 143, 155 (จำนวน 8 ตัว)

1.1 แสดงการคำนวณ Hash Address และ Probe Sequence ละเอียดทุกตัว [3 คะแนน]

จงแสดงวิธีทำของแต่ละคีย์ พร้อมระบุช่องที่ชนและช่องสุดท้ายที่ได้ลง

1.2 ตาราง Hash Table สุดท้าย (Element และ Info: 'A' = Active) [2 คะแนน]

วาดตารางขนาด 19 ช่อง ระบุ Element และ Info ให้ครบถ้วน

1.3 วิเคราะห์การชน (Collision Breakdown) & คีย์ที่ชนมากที่สุด [2 คะแนน]

คีย์ใดชน 0 ครั้ง, คีย์ใดชน 1 ครั้ง, คีย์ใดชนมากที่สุด (กี่ครั้ง และชนที่ช่องใดบ้าง) และจำนวนการชนสะสมรวมทั้งหมด

1.4 การคำนวณ Load Factor (λ) และเกณฑ์การ Rehashing ที่ 80% [3 คะแนน]

คำนวณ Load Factor ปัจจุบัน, จำนวนคีย์ที่ใส่เพิ่มได้อีกก่อนเกิด Rehash, และขนาดตารางใหม่ (New Table Size) หลัง Rehash

ข้อ 7: Advanced Theory, Structural Properties & Calculations (10 คะแนน) สรุปทฤษฎี & ข้อสอบรั่ว 2561-2564

7.1 โครงสร้างข้อมูลที่มี 2 คุณสมบัติ vs 3 คุณสมบัติ [2 คะแนน]

• มี 2 คุณสมบัติ: Binary Heap (Structure Property & Heap-Order Property)
• มี 3 คุณสมบัติ: Binary Search Tree (BST) (Binary tree, Left < Root, Right > Root)

7.2 คุณสมบัติ 3 ข้อของ Ideal Hash Function และข้อที่เป็นไปไม่ได้ในทางปฏิบัติ [2 คะแนน]

ข้อที่เป็นไปไม่ได้: Zero Collisions (ไม่มีการชนกันเลย)
เหตุผล 2 ประการ: 1. Pigeonhole Principle (คีย์อินพุตมีขนาดอนันต์แต่ตารางแฮชมีขนาดจำกัด) 2. การแจกแจงของข้อมูลจริงไม่สามารถคาดเดาได้

7.3 เปอร์เซ็นต์ขยะใน Adjacency Matrix ขนาด 7×7 [2 คะแนน]

ช่องทั้งหมด = 49 ช่อง | ช่องที่มีเส้นเชื่อม (1) = 12 ช่อง (24.49%) | เปอร์เซ็นต์ขยะ (0) = 37 ช่อง (75.51%)
หากใช้ Adjacency List ใช้เพียง 7 + 12 = 19 โหนด (ประหยัดหน่วยความจำได้ 61.22%)

7.5 จำนวนโหนดใน Complete Binary Tree ความสูง h = 10, 15, 16 [2 คะแนน]

• ความสูง h = 10: น้อยสุด = 2¹⁰ = 1,024 โหนด | มากสุด = 2¹¹ - 1 = 2,047 โหนด
