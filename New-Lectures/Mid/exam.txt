การเขียนตอบ: เขียนคำตอบด้วยปากกา รูป Tree วาดด้วยดินสอได้

รายการแนวข้อสอบ

1. Linked List: เขียนประโยคคำสั่งที่ main program

2. Stack: เขียนประโยคคำสั่งที่ main program

3. แผนผังการค้นหาแบบไบนารี:

เขียนขั้นตอนการทำงานใน recursive current_node กับ value และประโยคคำสั่งที่ถูกทำ เมื่อเงื่อนไข if..else เป็นจริง

ให้ผลการเดินท่องไปใน Tree มาให้ แล้วเขียน Tree ออกมา

4. Expression Tree: ข้อนี้ยาวหลายหน้า ให้ Stack เปล่ามาเป็นตั้งๆ ให้เขียนขั้นตอนเครื่องหมายเข้าออก stack วาดภาพ Expression Tree หาคำตอบ
