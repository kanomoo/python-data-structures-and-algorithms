# 📑 แบบฝึกหัดและแนวข้อสอบ: Stack (ถอดแบบตารางแบบฝึกหัดในห้อง 8 ข้อ)

> [!IMPORTANT] **กฎเหล็กสำหรับการทำข้อสอบ Stack (ตามหลักการของอาจารย์):**
> 1. **ห้ามเข้าถึง Private Attributes หรือ Index ภายในตรงๆ** (เช่น ห้ามใช้ `s.items[0]` หรือ `s[1]` เด็ดขาด)
> 2. **ต้องใช้เฉพาะ Method ของคลาส `Stack` ที่เรียนเท่านั้น:** `push(item)`, `pop()`, `top()`, `is_empty()`, `size()`
> 3. **หากต้องใช้โครงสร้างข้อมูลเสริม** ให้ใช้ `Queue` (`enQueue()`, `deQueue()`, `isEmpty()`) หรือตัวแปรชั่วคราว (Temporary Variable) เท่านั้น ห้ามพึ่งพา List/Array ของ Python
> 4. **กำหนดตอนเริ่มต้นให้:** `s = Stack()` (ข้อมูลก้น Stack อยู่ซ้าย, ยอด Stack / Top อยู่ขวา: `[Bottom ... Top]`)
> 5. **หากโจทย์ซับซ้อนเกินกว่าจะใช้คำสั่งเดียว** ให้เขียนลำดับคำสั่ง (Sequence of Operations) ให้ถูกต้องและรักษาระเบียบ LIFO เสมอ

## 📋 ตารางโจทย์ Stack สไตล์เดียวกับแบบฝึกหัดในห้อง (พร้อมเงื่อนไขและเฉลย)

| ข้อ | โจทย์ (Input $\rightarrow$ Output) | เงื่อนไข (Condition) | เฉลยคำตอบ / โค้ด (Solution) |
| :---: | :--- | :--- | :--- |
| **1** | **ตอนเริ่มต้น ตัวแปร `s` ว่าง**<br>`[] -> [10, 20, 30]`<br>*(Bottom: 10, Top: 30)* | เริ่มจาก Stack ว่าง ให้ใช้คำสั่ง `push` สร้างผลลัพธ์นี้ | ```python
s.push(10)
s.push(20)
s.push(30)
``` |
| **2** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[1, 2, 3, 4]` *(Top คือ 4)*<br>`[1, 2, 3, 4] -> [1, 2, 3]` | ลบข้อมูลที่อยู่บนสุด (Top) ออก 1 ตัว | ```python
s.pop()
``` |
| **3** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[A, B, C, D]` *(Top คือ D)*<br>`[A, B, C, D] -> [A, B, D, C]` | สลับตำแหน่ง C และ D โดยห้ามแก้ข้อมูลตรงๆ ให้ใช้ `pop` และ `push` เท่านั้น | ```python
d = s.pop()
c = s.pop()
s.push(d)
s.push(c)
``` |
| **4** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[1, 2, 3, 4]` *(Bottom คือ 1)*<br>`[1, 2, 3, 4] -> [2, 3, 4]` | ลบโหนดก้น Stack (Bottom = 1) ออก โดยใช้ Queue `q` ช่วย และรักษาระดับลำดับเดิม | ```python
# 1. เทจาก s ใส่ q: q = [4, 3, 2, 1]
while not s.is_empty():
    q.enQueue(s.pop())

# 2. เอา 1 ก้น stack ออก (ตัวที่ 4 ใน q)
# ถ่าย 4, 3, 2 เข้า s คืน
s.push(q.deQueue()) # 4
s.push(q.deQueue()) # 3
s.push(q.deQueue()) # 2
q.deQueue()         # ทิ้ง 1

# 3. กลับลำดับให้ถูกต้อง
while not s.is_empty():
    q.enQueue(s.pop())
while not q.isEmpty():
    s.push(q.deQueue())
``` |
| **5** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[1, 2, 1, 3]` *(Top คือ 3)*<br>`[1, 2, 1, 3] -> [1, 2, 3]` | ลบเลข `1` ตัวบนสุดออก (ที่อยู่ระหว่าง 2 กับ 3) โดยใช้ตัวแปรชั่วคราว | ```python
top_val = s.pop()   # ดึง 3 ออก
s.pop()             # ดึง 1 ออก (ลบทิ้ง)
s.push(top_val)     # ใส่ 3 กลับคืน
``` |
| **6** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[A, B, C]` *(Top คือ C)*<br>`[A, B, C] -> [A, C]` | ลบ B ออก โดยใช้ Stack เสริมหรือตัวแปร ห้ามเข้าถึง index ตรงๆ | ```python
c = s.pop()         # ดึง C ออก
s.pop()             # ดึง B ทิ้ง
s.push(c)           # ใส่ C กลับคืน
``` |
| **7** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[A, B, C, D]` *(Top คือ D)*<br>`[A, B, C, D] -> [A, D]` | ลบ B และ C ออกจาก Stack | ```python
d = s.pop()         # ดึง D ออก
s.pop()             # ดึง C ทิ้ง
s.pop()             # ดึง B ทิ้ง
s.push(d)           # ใส่ D กลับคืน
``` |
| **8** | **สมมติตอนเริ่มต้น ตัวแปร `s` ข้อมูลคือ**<br>`[A, B, C]` *(Top คือ C)*<br>`[A, B, C] -> [A, B, X, C]` | เพิ่ม X เข้าไปใน Stack ระหว่าง B กับ C | ```python
c = s.pop()         # ดึง C ออก
s.push('X')         # ใส่ X เข้าไป
s.push(c)           # ใส่ C กลับคืน
``` |

# 🧠 คำอธิบายหลักการคิดและเทคนิคการเขียนโจทย์ของอาจารย์

จากการวิเคราะห์สไลด์การสอน, ข้อสอบจริงใน `Mid/`, และใบงาน 8 ข้อ อาจารย์มีหลักการออกข้อสอบและวิธีคิดดังนี้:

### 1. หลักการ "State Transformation" (Input $\rightarrow$ Output)
- อาจารย์จะให้ **สถานะเริ่มต้น (Initial State)** และ **สถานะเป้าหมาย (Target State)** มาให้เห็นชัดเจน
- นักศึกษาต้องวิเคราะห์ว่า **โหนดเป้าหมายอยู่ที่ตำแหน่งใด** (อยู่ที่ Head/Top, อยู่ตรงกลาง, หรืออยู่ที่ Tail/Bottom)
- การดึงข้อมูลออกมาต้อง **รักษาโหนดที่ไม่เกี่ยวข้องไว้** แล้ว Push/Insert กลับเข้าไปตามลำดับเดิม

### 2. หลักการ "LIFO vs FIFO" ในการถ่ายโอนข้อมูล
- เมื่อโจทย์กำหนดให้จัดการข้อมูลที่อยู่ลึก (เช่น ลบเลข 4 และ 9 หรือลบก้น Stack):
  - **Stack $\rightarrow$ Queue $\rightarrow$ Stack:** ลำดับข้อมูลจะถูก **Reverse (กลับด้าน)**
  - **Stack $\rightarrow$ Queue $\rightarrow$ Stack $\rightarrow$ Queue $\rightarrow$ Stack (สลับ 2 รอบ):** ลำดับข้อมูลจะ **คงเดิม (Original Order)**
- นี่คือเหตุผลที่ข้อสอบจริงในห้องสั่งว่า *"ให้ใช้ Queue `q` ช่วยในการลบข้อมูลใน Stack `s`"*

### 3. หลักการ "Pointer Linking vs Method Call" (ข้อ 6, 7, 8 ของใบงาน)
- **โจทย์ระดับ Method:** ใช้ `remove()`, `insert()`, `add()` สำหรับ Linked List หรือ `push()`, `pop()` สำหรับ Stack
- **โจทย์ระดับ Pointer Manipulation:** อาจารย์จะสั่งห้ามใช้ method แต่ให้เขียนตัดต่อ Pointer ตรงๆ เช่น:
  - `mylist.head.set_next(node)`
  - `mylist.head.next = mylist.head.get_next().get_next()` (การข้ามโหนด = การลบ)
  - `node.set_next(mylist.head.get_next())` (การเอาโหนดใหม่ไปต่อกับหางก่อน แล้วค่อยเปลี่ยนหัวมาชี้โหนดใหม่)
