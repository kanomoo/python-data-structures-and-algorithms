Question: Write the statements in main program when the instance variable listA with ordered inputs are 1, 3, 8, 7, 9 and has result outputs are 9, 5, 1, 3, 7, 2, 8 by using class LinkedList's methods that we learned only.

💡 เฉลยและวิธีคิด:
# Initial: 1 -> 3 -> 8 -> 7 -> 9
listA.remove(9)       # ลบ 9 ท้ายออก -> 1 -> 3 -> 8 -> 7

listA.insert(8, 3)     # แทรก 8 ที่ index 3 -> 1 -> 3 -> 7 -> 8

listA.add(9)          # add แทรกที่ head -> 9 -> 5 -> 1 -> 3 -> 7 -> 2 -> 8

2. Stack & Queue (10 คะแนน)

2.1 Delete elements using Queue (ข้อสอบจริงจาก Mid) Score: 10

Question: If there is the exists Stack's instance variable s which has 5 elements 8, 4, 6, 9, 2 (where 8 is Bottom and 2 is Top) already. Write statement in main program to delete element 4 and 9 from the instance variable s with using the exists Queue's instance variable q and has result output are 8, 6, 2 (Bottom: 8, Top: 2) by using class Stack's and Queue's methods that we learned only.

💡 เฉลยและวิธีคิด:
# 1. Pop ข้อมูลออกจาก Stack โดยคัดเอาเฉพาะ 2, 6, 8 ใส่ Queue q
val = s.pop()    # 2
q.enQueue(val)
s.pop()          # 9 (ทิ้ง)
val = s.pop()    # 6
q.enQueue(val)
s.pop()          # 4 (ทิ้ง)
val = s.pop()    # 8
q.enQueue(val)
# ตอนนี้ q = [Front: 2, 6, 8 :Rear]

# 2. ถ่ายข้อมูลกลับคืนเพื่อคงลำดับเดิม
while not q.isEmpty():
    s.push(q.deQueue())    # s = [Bottom: 2, 6, 8 :Top]

while not s.is_empty():
    q.enQueue(s.pop())     # q = [Front: 8, 6, 2 :Rear]

while not q.isEmpty():
    s.push(q.deQueue())    # s = [Bottom: 8, 6, 2 :Top] (ได้ 8, 6, 2 ตามเดิม)

Question: เขียนขั้นตอนการทำงานใน recursive current_node กับ value และประโยคคำสั่งที่ถูกทำ เมื่อเงื่อนไข if..else เป็นจริง เมื่อแทรกค่า 25 ลงใน BST ที่มีโหนด 50, 20, 70, 30:

💡 ตารางแสดงขั้นตอนการทำงาน (Recursive Tracing):
Call ครั้งที่ current_node.value value เงื่อนไขที่ตรวจสอบ ประโยคคำสั่งที่ถูกทำงาน (Executed Statement)
1 50 25 25 < 50 is True (left มีโหนด 20) self._insert_recursive(current_node.left, 25)
2 20 25 25 > 20 is True (right มีโหนด 30) self._insert_recursive(current_node.right, 25)
3 30 25 25 < 30 is True (left ว่าง) current_node.left = Node(25) (สร้างโหนดสำเร็จ)

Question: วาดภาพ Expression Tree และหาคำตอบจาก Postfix: 5 3 + 8 6 2 / - *

💡 รูป Expression Tree & ผลการคำนวณ:
* / \ + - / \ / \ 5 3 8 / / \ 6 2

การคำนวณ: Subtree ซ้าย $= 5+3=8$, Subtree ขวา $= 8 - (6/2) = 5$, ราก $= 8 \times 5 =$ 40

5. หลักการอะไรเอ่ย & 6. คำถามย่อย (20 คะแนน)

💡 เฉลยสรุปประเด็นสำคัญ:
  • หลักการ LIFO: Last-In, First-Out ใน Stack (ตัวอย่าง: Function Call Stack, Undo/Redo)
  • กฎของ BST: Left Child < Parent < Right Child ทุก Subtree
  • Collision Resolution: Chaining ต่อ Linked List ในช่องเดิม, Open Addressing (Linear Probing) เลื่อนหาช่องว่างถัดไปใน Array
  • Array vs Linked List Access: Array ใช้ $O(1)$ (Contiguous Memory), Singly Linked List ใช้ $O(n)$ (Sequential Traversal)
  • Hash Indexing: "cat" เก็บ Index 4, "dog" เก็บ Index 6, "bird" ชนที่ Index 4
  • [None]*7 vs []: [None]*7 จอง 7 ช่อง กำหนดค่าตาม Index ได้ทันที, [] ขนาด 0 ถ้าเข้าถึงด้วย index จะเกิด IndexError
  • Output ของฟังก์ชัน mystery(5): ได้ 15 ($5 \times 3 \times 1$)
