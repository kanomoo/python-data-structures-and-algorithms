2. Stack & Queue Manipulation (10 คะแนน) (ชุดที่ 1)

2.1 Delete elements using Queue (จากรูปภาพข้อสอบจริง Screenshot) Score: 10

Question (EN): If there is the exists Stack's instance variable s which has 5 elements 8, 4, 6, 9, 2 (where 8 is Bottom and 2 is Top) already. Write statement in main program to delete element 4 and 9 from the instance variable s with using the exists Queue's instance variable q and has result output are 8, 6, 2 (Bottom: 8, Top: 2) by using class Stack's and Queue's methods that we learned only.

(คำแปลไทย): หากมีตัวแปร Stack ชื่อ s ซึ่งมีข้อมูล 5 ตัวคือ 8, 4, 6, 9, 2 อยู่แล้ว จงเขียนประโยคคำสั่งในโปรแกรม main เพื่อลบข้อมูลตัวเลข 4 และ 9 ออกจากตัวแปร s โดยใช้ตัวแปร Queue ชื่อ q ช่วย และให้ได้ผลลัพธ์สุดท้ายเป็น 8, 6, 2 โดยใช้เฉพาะเมธอดของคลาส Stack และ Queue ที่เรียนมาเท่านั้น
💡 เฉลยละเอียดแสดงให้ 2 รูปแบบ:
🔹 รูปแบบที่ 1: แบบเขียนคำสั่งทีละบรรทัด (ไม่ใช้ while loop - ตรงไปตรงมา)
# 1. Pop ข้อมูลออกจาก Stack s โดยกรองเอาเฉพาะ 2, 6, 8 ใส่ Queue q
val = s.pop()    # ได้ 2
q.enQueue(val)
s.pop()          # ได้ 9 (ลบทิ้ง ไม่เก็บ)
val = s.pop()    # ได้ 6
q.enQueue(val)
s.pop()          # ได้ 4 (ลบทิ้ง ไม่เก็บ)
val = s.pop()    # ได้ 8
q.enQueue(val)
# สภาพใน Queue ตอนนี้: q = [Front: 2, 6, 8 :Rear]

# 2. ถ่ายจาก q เข้า s (สั่งทีละตัว ไม่ใช้ while)
s.push(q.deQueue())    # ใส่ 2 เข้าก้น s
s.push(q.deQueue())    # ใส่ 6
s.push(q.deQueue())    # ใส่ 8 อยู่บนสุด
# สภาพใน Stack ตอนนี้: s = [Bottom: 2, 6, 8 :Top]

# 3. Pop จาก s กลับเข้า q เพื่อสลับกลับลำดับ
q.enQueue(s.pop())     # pop 8 เข้า q
q.enQueue(s.pop())     # pop 6 เข้า q
q.enQueue(s.pop())     # pop 2 เข้า q
# สภาพใน Queue ตอนนี้: q = [Front: 8, 6, 2 :Rear]

# 4. Dequeue จาก q กลับเข้า s จะได้ลำดับที่ถูกต้องตรงตามโจทย์
s.push(q.deQueue())    # ใส่ 8 เข้าก้น s
s.push(q.deQueue())    # ใส่ 6
s.push(q.deQueue())    # ใส่ 2 อยู่บนสุด
# ผลลัพธ์สุดท้าย: s = [Bottom: 8, 6, 2 :Top] (ถูกต้อง 100%)
🔹 รูปแบบที่ 2: แบบใช้ while loop (สั้น กระชับ เป็นมาตรฐาน)
# 1. Pop และคัดกรองเฉพาะ 2, 6, 8 ใส่ Queue q
val = s.pop(); q.enQueue(val)
s.pop() # ทิ้ง 9
val = s.pop(); q.enQueue(val)
s.pop() # ทิ้ง 4
val = s.pop(); q.enQueue(val)

# 2. ถ่ายโอนสลับ 2 รอบด้วย while loop
while not q.isEmpty():
    s.push(q.deQueue())

while not s.is_empty():
    q.enQueue(s.pop())

while not q.isEmpty():
    s.push(q.deQueue())

    • "dog": $314 \pmod 7 = 6 \implies \text{เก็บที่ } \text{my\_strings}[6] = \text{"dog"}$
    • "bird": $417 \pmod 7 = 4 \implies \text{เกิด Collision ที่ Index 4}$
  2. ความแตกต่างระหว่าง [None] * 7 กับ []:

    • my_strings = []: เป็นการสร้าง list ว่างเปล่า ที่ไม่มีสมาชิกใดๆ อยู่ภายในเลย ขนาดเริ่มต้นคือ 0 การเพิ่มสมาชิกเข้าไปจะต้องใช้เมธอดเช่น append() หรือ insert() หากเข้าถึงด้วย index เช่น my_strings[1] จะเกิด IndexError

  • Worst-case BST: เมื่อข้อมูลเรียงลำดับมาล่วงหน้า Tree จะเอียงเป็นเส้นตรง (Skewed Tree) ทำให้ Time Complexity กลายเป็น $O(n)$ เหมือน Linked List
  • Circular Queue Modulo: ใช้ (rear + 1) % capacity เพื่อให้ Pointer วนกลับไปใช้พื้นที่ว่างด้านหน้า index 0 ได้
  • Postfix Calculation: คอมพิวเตอร์ชอบ Postfix เพราะไม่ต้องใช้วงเล็บและไม่มีความกำกวมเรื่องลำดับความสำคัญ ใช้ Stack คำนวณได้ใน $O(n)$
  • Quadratic Probing: แก้ Primary Clustering ของ Linear Probing โดยขยับแบบกำลังสอง $+1^2, +2^2, +3^2$

6.1 Recursive Binary Tree Count Nodes Score: 5

Question (EN): Trace return value of count_nodes(root) for Tree with Root 10 (left: 5 with right: 7, right: 15).

(คำแปลไทย): จง Trace การนับจำนวนโหนดของ Tree
💡 เฉลย:

Root (1) + Left Subtree (2 โหนด) + Right Subtree (1 โหนด) $= 1 + 2 + 1 = \mathbf{4}$
