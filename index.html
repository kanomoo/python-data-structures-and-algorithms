  • ✓ แอนิเมชันคู่ขนาน Tree Structure View & 1-Based Array Index View
  • ✓ ชิปคำนวณสูตรคณิตศาสตร์: Parent $\lfloor i/2 \rfloor$, Left $2i$, Right $2i+1$
