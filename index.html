การเขียน Path (ได้ 0 คะแนนทันทีหากใช้ลูกศร)

นิยามของ Path ทางคณิตศาสตร์คือ Sequence of vertices ต้องเขียนคั่นด้วยจุลภาคเท่านั้น!

❌ ห้ามเขียน: A -> B -> C หรือ A → B → C (ได้ 0 คะแนน)
✅ ต้องเขียน: A, B, C หรือ (A, B, C) (คะแนนเต็ม)
2

สูตร Complete Graph: $E = \frac{V(V-1)}{2}$

เมื่อโจทย์ถามกราฟ $V=10$ มีเส้นเชื่อมกี่เส้น:

❌ ห้ามตอบติดสูตร: 10*(10-1)/2 หรือ 90/2 (หักคะแนน)
✅ ต้องตอบจำนวนเต็ม: 45 หรือ 45 เส้น
3

คำถามบน Null Graph ($V=\{\}, E=\{\}$)

หากข้อสอบถามว่าจงหา Path จากจุด $A$ ไปยังจุด $C$ บนกราฟว่าง:

✅ คำตอบที่ถูกต้อง: "ไม่มี Path จาก $A$ ไป $C$ เนื่องจากไม่มีจุด $A$ และจุด $C$ อยู่ในกราฟนี้"
4

การคำนวณร้อยละ Memory Waste (7x7 Adjacency Matrix)

กราฟ 7 จุดยอด 12 เส้นเชื่อม (ตาราง $7 \times 7 = 49$ ช่อง):

ช่องที่มีค่า 1 (ใช้งานจริง)
$$\frac{12 \times 100}{49} = \mathbf{24.48\%}$$
ช่องที่มีค่า 0 (สูญเปล่า)
$$\frac{37 \times 100}{49} = \mathbf{75.51\%}$$

💡 เหตุผลที่ Adjacency List เป็นพระเอก: ใช้เพียง $|V| + |E| = 7 + 12 = 19$ ช่อง ประหยัดพื้นที่กว่าถึง 61.22%!
