อาจารย์:
"ฟังก์ชันแฮชที่อยู่ในชีทเลยนะครับ ก็คือเอาค่า ASCII ของแต่ละตัวอักษรเนี่ยมาบวกเข้าด้วยกัน เสร็จแล้วสุดท้ายก็ Mod ด้วย Table Size นะครับ ก็ไม่ได้ออกฟังก์ชันที่มันพิสดารอะไร สอนยังไงก็ออกสอบอย่างงั้นนะครับ เป็นต้น มีบางเทอมนะครับ ก็ให้ข้อมูลมาเป็น String ก็มีนะครับ...

เรื่อง Hashing เนี่ย จะเป็นข้อใหญ่ข้อที่ 1 นะครับ ในข้อสอบตอนปลายภาค นะครับ แต่มันคงไม่ใช่เอาข้อมูลใส่ลงไปง่ายๆ นะครับ มันก็จะมีเรื่องของการชนกัน (Collision) แล้วก็การแก้การชนกัน นะครับ...
ข้อมูลชนกันก็คือ เราเอาไปผ่าน Hash Function แล้วตกตำแหน่งเดียวกันนะครับ ซึ่งตำแหน่งนั้นมีข้อมูลอื่นอยู่ก่อนหน้า เราก็เรียกว่าชนกันนะครับ ก็จะมี Separate Chaining
Separate Chaining ก็คือ ข้อมูลแยกออกมาจาก Hash Table ต่อเป็น Linked List ถ้าลักษณะแบบนี้นักศึกษาก็จะเห็นว่า ต่อให้มันชนกันยังไงก็ตาม มันก็ใส่เข้าไปได้ใช่ไหมครับ เพราะ Linked List มันยืดยาวออกมา นะครับ Separate แปลว่าแยกออกจาก Hash Table ใน Hash Table ไม่มีเลขใส่อย่างนี้นะครับ แล้วตัวเลขข้อมูลอยู่ไหน อยู่ใน Linked List ครับนักศึกษา ไอ้ Linked List เนี่ยฝรั่งมองเหมือนต่อเป็นโซ่ เขาก็เลยเรียกว่า Chaining นะครับ...
ซึ่งวิธีการนี้ เป็นวิธีแรกๆ ที่แก้การชนกัน แต่ไม่นิยมใช้ เพราะว่าจะต้องจัดการถึง 2 ขั้นตอน คือต้องผ่าน Hash Function ก่อน แล้วก็ไปจัดการที่ Linked List อีก นะครับ...

เขาก็เลยมาวิธีที่ 2 ที่เราเรียนกันถึงสัปดาห์ที่แล้ว คือ Open Addressing นะครับ Open Addressing จะแบ่งเป็นอีก 3 วิธีย่อย นะครับ
หลักการก็คือ ถ้ามีการชนกันนะครับ มันก็จะหาช่องว่างใหม่ นะครับ
อันนี้เป็นสูตรที่เราต้องท่องนะครับ:
H_i(x) = (hash(x) + F(i)) mod Table_Size โดยกำหนดให้ F(0) = 0 นะครับ
สมัยผมเรียน ผมก็ท่องนะครับ พอถ้ารู้ออกสอบแล้วมันต้องใช้สูตร นะครับ ก็ท่องไปเลย แล้วก็ถ้ามีการชนกันนะครับ เราก็จะไปหาช่องว่างใหม่ นะครับ วิธีการไปหาช่องว่างใหม่ก็เปลี่ยนค่า i นะครับ H_0(x), H_1(x), H_2(x) เป็นต้น นะครับ

แล้วก็สัปดาห์ที่แล้วเราเริ่มวิธีการแก้การชนกันวิธีแรก คือ Linear Probing
Linear แปลว่าเชิงเส้น นะครับ Probing ก็คือไปตรวจสอบ นะครับ คือพอเราได้ตำแหน่งใหม่แล้ว เราต้องตรวจสอบว่ามันมีข้อมูลอยู่หรือไม่ ถ้ามันยังว่างอยู่ เราก็เอาข้อมูลใส่เข้าไป นะครับ เป็นต้น ซึ่งฟังก์ชัน Linear เชิงเส้น ก็คือฟังก์ชันที่ไม่มีเลขยกกำลัง ง่ายที่สุดก็คือ F(i) = i นะครับ...
ถ้ามหาวิทยาลัยอื่นสอน เขาอาจจะแปลงสูตรก็ได้ เช่น F(i) = 2i + 1, F(i) = 3i - 5 อะไรประมาณนั้นน่ะ แต่ผมเอาฟังก์ชันที่ง่ายที่สุดเลยครับ F(i) = i ไม่ได้แปลงสูตรแต่อย่างใด นะครับ แต่คำว่าเชิงเส้นคือไม่มียกกำลัง นะครับ

แล้วก็กำหนด Hash Table นะครับ เราก็ไล่จากซ้ายไปหาขวา ทางซ้ายก็คือ Hash Table แบบว่างเปล่าตอนเริ่มต้น ซึ่งคุณจะเจอทรงแบบเนี้ยตอนสอบปลายภาค คือให้มาตั้งหนึ่งอะว่างๆ แล้วให้คุณเอาเลขใส่ลงไป ไม่ว่าจะเป็นชื่อคน หรือตัวเลข แล้วแต่โจทย์ในแต่ละปีอะ ใส่ลงไป เป็นต้น นะครับ ซึ่งวิธีการ Open Addressing ข้อดีก็คือ ข้อมูลจะใส่เข้าไปใน Hash Table จริงๆ ไม่ต้องไปใส่ใน Linked List แต่อย่างใด แล้วถ้าสมมุติมันชนกัน แปลว่าช่องนั้นคุณใส่ไม่ได้ คุณก็ไปหาช่องว่างใหม่ นะครับ... เหมือนกับคุณจะนั่งเก้าอี้เลกเชอร์อะ เก้าอี้เลกเชอร์มันเต็ม คุณก็ไปหาเก้าอี้ตัวอื่น นั่ง นะครับ

เวลาใส่ข้อมูลนะครับ ข้อสอบจะกำหนดข้อมูลตั้งต้นมาให้ เวลาใส่ก็ใส่ทีละตัวจากซ้ายไปหาขวา อย่าใส่มั่ว ถ้าใส่มั่วแล้วตำแหน่งมันผิดนะครับ ผมเตือนไว้ก่อน แล้วก็มีรุ่นพี่หลายท่านใส่มั่วด้วยนะครับ
สมมุติข้อมูลตั้งต้นให้มาคือ 89, 18, 49, 58, 69 คุณจะต้องใส่จากซ้ายไปขวาทีละตัว คุณหยิบ 89 มาคำนวณก่อน ลงไปช่องไหน แล้วค่อยตัวที่ 2 คือ 18... รุ่นพี่คุณใส่มั่วยังไง พอได้ข้อมูลมาปุ๊บเป็นโจทย์ รุ่นพี่คุณใส่ตัวแรกใส่ 58 ตัวที่ 2 ใส่ 68 ตัวที่ 3 ใส่ 69 มั่วมาก อันนี้ตำแหน่งมันผิดนะครับ เตือนไว้ก่อนอย่าหาทำ นะครับ ให้ใส่ทีละตัวจากซ้ายไปหาขวา เวลาทำก็เอาดินสอปากกาติ๊กไป ตัวนี้คิดแล้ว ตัวนี้คิดแล้ว เป็นต้น นะครับ

ซึ่งคุณจะเห็นว่า ผมพูดเรื่อง Input ตั้งแต่บท Linked List แล้ว ในข้อสอบก็เล่นลำดับ Input ใช่ไหมครับ ถ้า Input บอกว่าให้ใส่ตามลำดับอย่างเงี้ยะ ก็แปลว่าคุณต้องใส่จากซ้ายไปขวาทีละตัว...
ข้อสอบบอกให้ใส่ 1, 3, 7, 8, 9 นิสิตหลายท่านเริ่มใส่ 9 ก่อนเลย ใส่ 9 ก่อนก็ 0 ทันทีเลยครับนิสิต...
ทั้ง 40 - 50 คนตอนรุ่นพี่คุณน่ะ ผมก็ไม่เข้าใจ ตอนเรียนอธิบายแบบนี้ไปแล้ว แต่ตอนสอบท่านก็ยังทำผิด เป็นต้น นะครับ...

สัปดาห์ที่แล้วก็สอนนิสิตทำไปแล้วนะ... อ๋อ อันนี้ผมลองเขียนใน VS Code นะครับ... ผมเดาว่าถัดจากรุ่นคุณเนี่ย น่าจะเป็นการเรียนเขียนโปรแกรมแนวใหม่ ก็คือ โครงสร้างข้อมูลในโค้ดเนี่ย กะว่าจะเอา AI ใส่เข้าไปด้วย นะครับ ผมกำลังลองเขียนอยู่... เขาเรียกว่า Agentic... Agentic AI เขียนแทรกเข้าไปใน Python เลยครับนิสิต นะครับ... แต่เอาไว้รุ่นหลังพวกคุณครับ เอาแค่เราเรียนตรงไปตรงมาแค่นี้ก็ลำบากแล้ว ถ้าเอา AI ใส่เข้าไปน่าจะเหนื่อย นะครับ แต่ลองหัดเขียนอยู่ กะว่าจะปรับปรุงหลักสูตรคราวหน้า นะครับ Data Structure with AI เป็นต้น...

อะ ต่อ นะครับ... Linear Probing ทำไปแล้ว สรุปว่า เมื่อเราใส่ครบ 5 ตัว Linear Probing จะมีการชนกันและแก้การชนกันรวมทั้งสิ้น 7 ครั้ง 7 ครั้งก็คือ 49 ชน 1 ครั้ง, 58 ชน 3 ครั้ง, 69 ชน 3 ครั้ง รวมเป็น 7 ครั้ง ให้เวลานับ นับรวมแบบนี้นะครับ แปลว่าถูก อย่าไปนับแยกเป็นชน 7 แก้ 7 รวมเป็น 14 นะครับ ถ้าตอบ 14 ผิดทันที ได้ 0 คะแนน...

เรื่อง Wrap Around สัปดาห์ที่แล้วเปิดให้ดูแล้วใช่ไหมครับ Concept of Wrap Around แปลเป็นไทยก็คือหลักการ Wrap Around ใน Hashing... เวลาที่ key mod back เอาไปผ่าน Hash Function แล้ว ปรากฏว่ามันไปถึงตำแหน่งท้ายของ Hash Table มันจะวนกลับมาตำแหน่งเริ่มต้นใหม่ คือวนกลับมาตำแหน่งที่ 0 ใหม่นั่นเอง ถามว่าทำยังไง Wrap Around Hashing ตอบ: ก็คือการ Mod ด้วย Table Size อีกรอบหนึ่งนั่นเอง ที่อยู่นอกสุด เป็นต้น...

ปัญหาของการใช้ Linear Probing ก็คือเกิด Primary Clustering แปลเป็นไทยว่า ก่อกลุ่มกันขั้นที่ 1 ขั้นต้น หมายความว่าในระหว่างแก้การชนกัน Linear Probing มันจะไปหาช่องว่างใหม่ที่อยู่ถัดไป พอมันว่าง มันก็ใส่ข้อมูลลงไป มันจะกลายเป็นตัวกั้น ทำให้การแก้การชนกันในรอบต่อไปเนี่ย มันจะใช้เวลาหาช่องว่างใหม่นานขึ้น เพราะการแก้การชนกันมันจะกลายเป็นตัวป้องกันการหาช่องว่างใหม่ ยิ่งแก้การชนกันรอบถัดไป ถ้าชนกันอีก มันก็เสียเวลาหาช่องว่างใหม่นานขึ้น... แปลเป็นไทยก็คือ การแก้การชนกันของ Linear Probing จะใช้เวลามากขึ้น เมื่อจำนวนข้อมูลมากขึ้น นั่นเอง... เราก็เลยไปสู่วิธีที่ 2 ครับ Quadratic Probing..."

[สรุปประเด็นเน้นสอบปลายภาค (Exam Highlights)]
1. Hashing เป็นข้อสอบใหญ่ข้อที่ 1 ตอนปลายภาค
2. สูตรหลัก Open Addressing:
   H_i(x) = (hash(x) + F(i)) mod Table_Size โดย F(0) = 0
3. Linear Probing: F(i) = i (แก้การชนโดยเลื่อนทีละ 1 ช่องถัดไป)
4. ปัญหาของ Linear Probing: Primary Clustering (ข้อมูลเกาะกลุ่มก้อนใหญ่ ทำให้ค้นหาและแก้นานขึ้น)
5. กฎเหล็กการทำข้อสอบ: ต้องใส่ข้อมูลเรียงจากซ้ายไปขวาตามลำดับโจทย์ ห้ามสลับลำดับเด็ดขาด
6. การนับจำนวนการชน: ให้นับจำนวนครั้งที่เกิดการขยับหาช่องใหม่ (เช่น 49 ชน 1 ครั้ง, 58 ชน 3 ครั้ง, 69 ชน 3 ครั้ง รวมเป็น 7 ครั้ง) ห้ามตอบ 14 ครั้ง
