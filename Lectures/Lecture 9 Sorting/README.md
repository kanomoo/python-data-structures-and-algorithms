# Lecture 9 Sorting

Lecture materials for sorting algorithms and comparison of approaches (ผู้สอน: ดร.ประดิษฐ์ พิทักษ์เสถียรกุล).

## 📁 ไฟล์ใหม่ 4 ไฟล์ในโฟลเดอร์ `New/`
1. **`DATA STRUCTURES & ALGORITHMS_Lecture 9 168.pdf`**: สไลด์บรรยายหลักทางการ (Preliminaries, Insertion sort, Selection sort, Bubble sort, 3 Cases in algorithms: Best/Worst/Average).
2. **`For Example Bubble sort.pdf`**: เอกสารตัวอย่าง Bubble Sort, ทฤษฎี Inversions กับจำนวนการสลับ, และแบบฝึกหัดข้อสอบจริงบนชุดข้อมูล `[64, 34, 25, 12, 22, 11, 90]`.
3. **`For Example Selection sort 169.pdf`**: เอกสารตัวอย่าง Selection Sort บน `[64, 25, 12, 22, 11]`, เติมคำตอบ Round 3 & 4, และเจาะลึกโครงสร้างภาษา Python (`range()` metadata, `range(0)` vs `[]`, และ `for j in range(i + 1, n)`).
4. **`Short note Insertion sort.pdf`**: ใบงานเจาะลึก Insertion Sort บน `[34, 8, 64, 51, 32, 21]`, ตารางนับ Position Moves รวม 9 ครั้ง, และคำอธิบายเงื่อนไข `while j > 0 and tmp < a[j - 1]`.
