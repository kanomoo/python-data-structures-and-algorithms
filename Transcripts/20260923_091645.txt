อาจารย์: เอาล่ะครับ เข้าสู่เนื้อหาบทที่ 10 เรื่อง Graph Algorithm (ทฤษฎีกราฟ)
เปิด Google Classroom ดูสไลด์ บทที่ 10 เรื่องกราฟนี้ จะออกสอบปลายภาค 2 ข้อใหญ่ และมีข้อย่อยประมาณ 3-4 ข้อ รวมแล้วคะแนนไม่ต่ำกว่า 20 คะแนน จากคะแนนเต็มข้อสอบ 70 คะแนน (หาร 2 เหลือ 35 คะแนนปลายภาค)
กราฟในทางคณิตศาสตร์ ไม่ใช่กราฟแท่งหรือกราฟเส้นสถิติ แต่เป็นความสัมพันธ์ระหว่างจุด (Vertices) กับเส้น (Edges)
นิยามทางคณิตศาสตร์:
G = (V, E)
V (Vertex / Vertices หรือบางที่เรียก Node): คือเซตของจุดยอด V = {v1, v2, ..., vn}
E (Edge): คือเซตของเส้นเชื่อม E = {e1, e2, ..., em}
เส้นเชื่อมแต่ละเส้น e เป็นคู่ลำดับ (Pair) ของจุดยอด: e = (v, w) โดย v คือจุดเริ่มต้น และ w คือจุดสิ้นสุด (v, w เป็นสมาชิกของเซต V)
ประเภทของกราฟ:
1. Undirected Graph (กราฟไม่มีทิศทาง): เส้นเชื่อมไม่มีหัวลูกศร เส้น (u, v) มีความหมายเดียวกับ (v, u) เช่น เส้น AB เท่ากับ BA
2. Directed Graph หรือ Digraph (กราฟมีทิศทาง): เส้นเชื่อมมีหัวลูกศรกำกับทิศทาง (u, v) หมายถึงมีเส้นลากจาก u ไปยัง v ซึ่งไม่เหมือนกับ (v, u)

[00:30:00 - 00:45:00]
อาจารย์: นิยามคำว่า Adjacent (อยู่ถัดจาก / ประชิด):
จุดยอด w จะ Adjacent กับจุดยอด v ก็ต่อเมื่อ มีเส้นเชื่อม (v, w) อยู่ในเซต E
เช่น ถ้ามีเส้นจาก A ไป B เรากล่าวว่า B อยู่ถัดจาก A (B is adjacent to A)
แต่ถ้าเป็น Digraph และมีเส้นจาก A ไป B เท่านั้น เราจะพูดว่า A adjacent to B ไม่ได้ เพราะไม่มีเส้นจาก B ไป A

นิยามคำว่า Path (ทางเดิน / เส้นทาง):
Path คือลำดับของจุดยอด (Sequence of vertices): w1, w2, w3, ..., wn
โดยที่คู่ของจุดยอดที่อยู่ติดกัน (wi, wi+1) จะต้องมีเส้นเชื่อมอยู่ในเซต E เสมอ
*** ฟังตรงนี้ให้ดีนะครับ ออกข้อสอบปลายภาคแน่นอน! ***
สมมุติโจทย์ให้กราฟมา แล้วถามว่า:
"จงเขียน Path จาก Vertex A ไปยัง Vertex C"
วิธีตอบที่ถูกต้องตามนิยามคณิตศาสตร์:
เขียนเป็นลำดับจุดยอดคั่นด้วยเครื่องหมายจุลภาค (Comma) คือ:
A, B, C
หรือ (A, B, C)
คำเตือนเด็ดขาด: "ห้ามเขียนหัวลูกศร เช่น A -> B -> C เด็ดขาด! ถ้านักศึกษาเขียนเป็นลูกศรมา ผมให้ 0 คะแนนทันที!"
เพราะนิยามทางคณิตศาสตร์ Path คือ Sequence of Vertices ไม่ใช่ลูกศร ถ้าเขียนลูกศรมาแปลว่าไม่เข้าใจนิยามคณิตศาสตร์ ให้ 0 ทันทีนะครับ ชี้แจงล่วงหน้าแล้ว อย่ามาบ่นตอนหลัง

[00:45:00 - 00:55:00]
อาจารย์: นิยามคำว่า Length of Path (ความยาวของเส้นทาง):
Length of a path คือ The number of edges on the path (จำนวนของเส้นเชื่อมที่อยู่บนเส้นทางนั้น)
ถ้า Path ประกอบด้วยจุดยอด N จุด ความยาว Length จะเท่ากับ N - 1
เช่น Path A, B, C มีจุดยอด 3 จุด มีเส้นเชื่อมคือ (A,B) และ (B,C) รวมเป็น 2 เส้น ดังนั้น Length = 2
มีรุ่นพี่คุณบางคน ถามว่า Length จาก A ไป C ยาวเท่าใด ตอบมา "2 นิ้ว"! เอาไม้บรรทัดทาบหน้าจอโปรเจกเตอร์แล้วตอบ 2 นิ้ว... แบบนี้ได้ 0 คะแนนนะครับ! หน่วยของมันคือจำนวนเส้น (Edges) ไม่ใช่เซนติเมตรหรือนิ้ว
ถ้า Path นั้นไม่มีเส้นเชื่อมเลย (อยู่ที่จุดเดิม ไม่ได้เดินไปไหน) ความยาว Length = 0

[00:55:00 - 01:10:00]
อาจารย์: นิยามคำว่า Loop:
ถ้ามีเส้นเชื่อมจาก v ไปยัง v (จุดเริ่มต้นและจุดสิ้นสุดเป็นจุดเดียวกัน) เราเรียกว่า Loop
นิยาม Simple Path: ทางเดินที่จุดยอดทุกจุดแตกต่างกันทั้งหมด (ยกเว้นจุดแรกและจุดสุดท้ายอาจเป็นจุดเดียวกันได้)
นิยาม Cycle (วงรอบ):
Cycle คือ Path ที่มีความยาว Length >= 1 และจุดเริ่มต้นกับจุดสิ้นสุดเป็นจุดยอดเดียวกัน (Start vertex = End vertex)
เช่น A, B, C, D, A มีความยาว 4 เส้น จุดเริ่มต้นคือ A จุดสิ้นสุดคือ A แบบนี้เรียกว่า Cycle (วงรอบ)
ถ้าเป็น Directed Acyclic Graph (DAG) คือ Digraph ที่ไม่มี Cycle อยู่เลย

[01:10:00 - 01:25:00]
อาจารย์: นิยามคำว่า Connected Graph (กราฟต่อเนื่อง):
สำหรับ Undirected Graph กราฟจะ Connected (ต่อเนื่อง) ก็ต่อเมื่อ มี Path ระหว่าง "ทุกๆ คู่ของจุดยอด" (There is a path between every pair of vertices)
ระวังนะครับ! Connected พิจารณาที่ "Path" (เส้นทางเดิน) ไม่ใช่ Edge เดี่ยวๆ
ถ้าจุด A ไปจุด D ไม่มีเส้นตรงเชื่อม แต่เราสามารถเดิน A -> B -> C -> D ได้ แปลว่ามี Path ดังนั้นถือว่าต่อเนื่อง
วิธีตรวจว่า Connected หรือไม่: นำจุดยอดทั้งหมดมาจับคู่ให้ครบทุกคู่ เช่น มี 4 จุด A, B, C, D ต้องตรวจ:
(A,B), (A,C), (A,D), (B,C), (B,D), (C,D)
ถ้าทุกคู่มี Path เดินถึงกันได้ กราฟนั้นถือว่า Connected!

เป็นกราฟ! เรียกว่า Null Graph หรือ Empty Graph
โจทย์หลอกในข้อสอบ: กำหนดกราฟว่าง V = {}, E = {} จงเขียน Path จาก A ไป C?

นิยามคำว่า Complete Graph (กราฟสมบูรณ์):
Complete Graph คือกราฟที่มี "Edge" เชื่อมระหว่างทุกๆ คู่ของจุดยอด (There is an edge between every pair of vertices)
สังเกตความแตกต่าง:
- Connected Graph พิจารณาที่ "Path"
- Complete Graph พิจารณาที่ "Edge"
สูตรคำนวณจำนวนเส้นของ Undirected Complete Graph ที่มี N จุดยอด:
Edges = N * (N - 1) / 2
พิสูจน์:
- N = 2: 2 * 1 / 2 = 1 เส้น
- N = 3: 3 * 2 / 2 = 3 เส้น
- N = 4: 4 * 3 / 2 = 6 เส้น
- N = 5: 5 * 4 / 2 = 10 เส้น
*** ข้อสอบปลายภาคออกข้อนี้แน่นอน! ฟังให้ดี ***
โจทย์ข้อสอบปลายภาค:
"กำหนด Undirected Complete Graph มี Vertex จำนวน 10 จุดยอด ถามว่าจะมี Edge ทั้งหมดกี่เส้น?"
วิธีทำ: แทนค่าในสูตร 10 * (10 - 1) / 2 = 10 * 9 / 2 = 45 เส้น!
คำเตือน: "ต้องตอบเป็นจำนวนเต็ม Integer คือ 45 เส้นเท่านั้น! ห้ามตอบติดสูตร 10*(10-1)/2 มาเด็ดขาด ถ้าตอบติดสูตรมา จะได้ 0 คะแนนทันที!" คำนวณตัวเลขง่ายๆ แค่นี้ต้องตอบให้เป็นตัวเลข

อาจารย์: หัวข้อถัดไป: Representation of Graphs (การแทนความหมายกราฟในคอมพิวเตอร์)
คอมพิวเตอร์ไม่สามารถมองเห็นรูปกราฟได้ เราต้องมีโครงสร้างข้อมูลเพื่อบอกคอมพิวเตอร์ว่าจุดไหนเชื่อมกับจุดไหน
มี 2 วิธีหลัก:
1. Adjacency Matrix (เมทริกซ์ประชิด)
ใช้ 2D Array ขนาด |V| x |V|
แถวแทน u, คอลัมน์แทน v
ถ้ามี Edge จาก u ไป v: Array[u][v] = 1
ถ้าไม่มี Edge: Array[u][v] = 0
ดูตัวอย่างกราฟ 7 จุดยอด (Vertices 1 ถึง 7) มี Edges 12 เส้น:
สร้างตารางขนาด 7 x 7 = 49 ช่อง
Vertex 1 มีเส้นไป 2, 3, 4 -> แถวที่ 1 ใส่ 0, 1, 1, 1, 0, 0, 0
Vertex 2 มีเส้นไป 4, 5 -> แถวที่ 2 ใส่ 0, 0, 0, 1, 1, 0, 0
Vertex 3 มีเส้นไป 6 -> แถวที่ 3 ใส่ 0, 0, 0, 0, 0, 1, 0
Vertex 4 มีเส้นไป 3, 6, 7 -> แถวที่ 4 ใส่ 0, 0, 1, 0, 0, 1, 1
Vertex 5 มีเส้นไป 4, 7 -> แถวที่ 5 ใส่ 0, 0, 0, 1, 0, 0, 1
Vertex 6 ไม่มีเส้นออก -> แถวที่ 6 ใส่ 0, 0, 0, 0, 0, 0, 0
Vertex 7 มีเส้นไป 6 -> แถวที่ 7 ใส่ 0, 0, 0, 0, 0, 1, 0
รวมมีช่องที่เป็นเลข 1 ทั้งหมด 12 ช่อง (เท่ากับจำนวน Edge 12 เส้น)

*** ข้อสอบหลุดตรงนี้ จดไว้เลยนะครับ! ***
"Adjacency Matrix ไม่นิยมใช้ เพราะเปลืองเนื้อที่ในหน่วยความจำ"
คำนวณเปอร์เซ็นต์ความสิ้นเปลือง:
ตารางทั้งหมด 49 ช่อง มีช่องที่เป็น 1 อยู่ 12 ช่อง
คิดเป็นเปอร์เซ็นต์ช่องที่มีข้อมูล (1): 12 * 100 / 49 = 24.48 %
ช่องที่เป็น 0 (ไม่ได้ใช้งาน/สิ้นเปลือง): 100 - 24.48 = 75.51 %
ข้อสอบภาษาอังกฤษจะถามว่า:
"What percentage of the memory space is used for entries with a value of 1, and what percentage is used for entries with a value of 0?"
ตอบ: ช่องที่เป็น 1 ใช้ไป 24.48%, ช่องที่เป็น 0 สิ้นเปลืองไป 75.51%!

อาจารย์: เอาล่ะครับมาต่อ วิธีแก้ความสิ้นเปลืองของ Adjacency Matrix เมื่อกราฟเป็น Sparse Graph (กราฟที่มีเส้นเชื่อมน้อย เบาบาง)
เราจะใช้:
2. Adjacency List (รายการประชิด)
โครงสร้างคือ ใช้ Array 1 มิติขนาดเท่ากับจำนวน Vertex (|V|) แต่ละช่องของ Array จะชี้ไปยัง Linked List ของจุดยอดที่มัน Adjacent ด้วย
สำหรับกราฟเดิม 7 จุดยอด 12 เส้น:
- Array ช่องที่ 1 ชี้ไป Linked List: 2 -> 3 -> 4
- Array ช่องที่ 2 ชี้ไป Linked List: 4 -> 5
- Array ช่องที่ 3 ชี้ไป Linked List: 6
- Array ช่องที่ 4 ชี้ไป Linked List: 3 -> 6 -> 7
- Array ช่องที่ 5 ชี้ไป Linked List: 4 -> 7
- Array ช่องที่ 6 ชี้ไป Linked List: ว่าง (Null)
- Array ช่องที่ 7 ชี้ไป Linked List: 6

คำนวณพื้นที่หน่วยความจำที่ใช้ (Space Requirement):
สูตร: O(|E| + |V|)
- Array ใช้ |V| ช่อง = 7 ช่อง
- Node ใน Linked List ใช้ตามจำนวน Edge |E| = 12 โหนด
รวมเนื้อที่ที่ใช้ = 7 + 12 = 19 ช่อง!
เทียบกับ Adjacency Matrix ที่ใช้ 49 ช่อง Adjacency List ประหยัดกว่ามหาศาล!
