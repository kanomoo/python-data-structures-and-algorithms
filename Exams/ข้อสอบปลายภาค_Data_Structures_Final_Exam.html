💡 เฉลยละเอียดและหลักการคิดข้อ 1 (Double Hashing & Rehashing Solution):

1. การหาค่าคงที่ $R$ และฟังก์ชันแฮชหลัก:

  • การเลือกค่า $R$: ตามนิยาม Double Hashing ค่า $R$ ต้องเป็น "จำนวนเฉพาะที่มากที่สุดที่น้อยกว่า TableSize ($R < \text{TableSize}$)"
    ตารางมีขนาด $\text{TableSize} = 19$ จำนวนเฉพาะที่น้อยกว่า 19 ได้แก่ $2, 3, 5, 7, 11, 13, 17$ → จึงได้ $R = 17$
    (⚠️ คำเตือนอาจารย์: ห้ามเลือก $R = 19$ เด็ดขาด เพราะ $R$ ต้องน้อยกว่า TableSize)
  • ฟังก์ชันแฮชหลัก: $h_0(X) = X \bmod 19$
  • ฟังก์ชันคำนวณก้าว (Step Size): $\text{step}(X) = 17 - (X \bmod 17)$
  • ลำดับการตรวจสอบตำแหน่ง: $h_i(X) = (h_0(X) + i \times \text{step}(X)) \bmod 19$

3.3 ฟังก์ชันที่แก้ไขแล้ว (Python - ตรงตามโค้ดในห้องเรียน Exams/InsertionSort.py):

def insertion_sort(a):
    total = 0
    print("Original: ", a, "Position Move")
    for p in range(1, len(a)):
        tmp = a[p]
        j = p
        swap = 0
        while j > 0 and tmp < a[j - 1]:
            a[j] = a[j - 1]
            j -= 1
            swap += 1
        a[j] = tmp
        total += swap
        print(f"After p = {p}", a, swap)
    print(f"Result : {a}")
    print(f"Total Moves: {total}")

    • อย่างน้อย $= 2^{10} = \mathbf{1,024}$ โหนด
    • อย่างมาก $= 2^{11} - 1 = 2048 - 1 = \mathbf{2,047}$ โหนด
  • ความสูง $h = 16$:
    • อย่างน้อย $= 2^{16} = \mathbf{65,536}$ โหนด
    • อย่างมาก $= 2^{17} - 1 = 131072 - 1 = \mathbf{131,071}$ โหนด

⚠️ กับดัก: ตอบติดรูปเลขยกกำลัง เช่น $2^{10}$ ได้ 0 คะแนนทันที ต้องคำนวณเป็นตัวเลขจำนวนเต็ม!

7.5 Complete Graph ไม่มีทิศทาง 10 โหนด และ 16 โหนด มีเส้นเชื่อมกี่เส้น [ข้อสอบปี 2564 & 2561] Score: 3 Marks

(โจทย์ภาษาไทย): Complete Graph แบบไม่มีทิศทาง (Undirected Complete Graph) ที่มีจำนวนโหนด 10 โหนด และ 16 โหนด จะมีเส้นเชื่อมทั้งหมดกี่เส้น? ตอบเป็นตัวเลขจำนวนเต็มเท่านั้น ห้ามติดสมการ
💡 เฉลยละเอียด:

สูตรจำนวนเส้นเชื่อม: $\frac{V(V-1)}{2}$ เส้น

  • สำหรับ $V = 10$ โหนด: $\frac{10 \times 9}{2} = \mathbf{45}$ เส้น
  • สำหรับ $V = 16$ โหนด: $\frac{16 \times 15}{2} = \mathbf{120}$ เส้น

3. การเลือกค่า $R$ ในสูตร Double Hashing (How to Choose R for Double Hashing)

สูตร Double Hashing มาตรฐาน:

$$h_i(X) = (h_0(X) + i \times hash_2(X)) \bmod \text{TableSize} \quad \text{where } hash_2(X) = R - (X \bmod R)$$

กฎเกณฑ์การเลือกค่า $R$ (Rules for choosing $R$):

  • $R$ ต้องเป็น จำนวนเฉพาะ (Prime Number)
  • $R$ ต้องมีค่าน้อยกว่า TableSize อย่างเคร่งครัด: $R < \text{TableSize}$
  • ตามหลักการออกแบบ: $R$ คือจำนวนเฉพาะที่มากที่สุดที่น้อยกว่า TableSize (Largest prime strictly less than TableSize)

ตัวอย่างการเลือก $R$:

  • ถ้า $\text{TableSize} = 10 \implies R = \mathbf{7}$
  • ถ้า $\text{TableSize} = 11 \implies R = \mathbf{7}$ (⚠️ ห้ามเลือก 11 เพราะ $R$ ต้อง $< \text{TableSize}$ อย่างเคร่งครัด!)
  • ถ้า $\text{TableSize} = 19 \implies R = \mathbf{17}$

9. การคำนวณร้อยละความสูญเสียใน RAM (Graph Memory Waste Percentage)

เมื่อแทนกราฟด้วย Adjacency Matrix ขนาด $|V| \times |V|$:

  • จำนวนช่องทั้งหมดในหน่วยความจำ: $|V|^2$ ช่อง
  • ช่องที่มีข้อมูลจริง (มีเส้นเชื่อม Edge = 1): $|E|$ ช่อง (สำหรับ Directed Graph)
  • ร้อยละการใช้งานหน่วยความจำ (Actively Used %): $$\text{Used } \% = \frac{|E|}{|V|^2} \times 100\%$$
  • ร้อยละความสูญเปล่าในหน่วยความจำ (Wasted %): $$\text{Wasted } \% = \frac{|V|^2 - |E|}{|V|^2} \times 100\% = 100\% - \text{Used } \%$$

ตัวอย่างการคำนวณสำหรับกราฟ $|V| = 7, |E| = 12$:

  • ช่องทั้งหมด $= 7 \times 7 = \mathbf{49 \text{ ช่อง}}$
  • ช่องที่มีเส้นเชื่อม $= \mathbf{12 \text{ ช่อง}}$ → ใช้งานจริง $= \frac{12}{49} \times 100\% = \mathbf{24.49\%}$
  • ช่องที่ว่างเปล่า (มีค่า 0) $= 49 - 12 = \mathbf{37 \text{ ช่อง}}$ → สูญเปล่า $= \frac{37}{49} \times 100\% = \mathbf{75.51\%}$

10. สรุปคุณสมบัติ 2 ประการ และ 3 ประการ ของโครงสร้างข้อมูล (Two & Three Properties)

โครงสร้างข้อมูล จำนวนคุณสมบัติ รายละเอียดคุณสมบัติ (Properties Description)
Binary Min-Heap 2 Properties 1. Structure Property: ต้องเป็น Complete Binary Tree (เติมเต็มทุกชั้น เติมซ้ายไปขวา)
2. Heap-Order Property: ค่าของ Parent ต้องน้อยกว่าหรือเท่ากับ Children เสมอ (Parent ≤ Children)
Tree (ในทางทฤษฎีกราฟ) 2 Properties 1. Connected: กราฟต้องเชื่อมโยงถึงกันทุกโหนด
2. Acyclic: กราฟต้องไม่มีวงรอบเด็ดขาด (มี $V-1$ เส้นเชื่อมเสมอ)
AVL Tree 2 Properties 1. BST Property: Left < Root < Right
2. Balance Property: ผลต่างความสูงสองฝั่ง $|h_L - h_R| \le 1$ ทุกโหนด
Hashing (ในอุดมคติ) 3 Properties 1. Deterministic & Fast ($O(1)$): คำนวณง่าย รวดเร็ว ค่าเดิมได้ผลเดิมเสมอ
2. Uniform Distribution: กระจายคีย์ทั่วทุกช่องในตารางอย่างสม่ำเสมอ
3. Collision-Free (One-to-One): ข้อมูลต่างกันต้องได้ดัชนีไม่ซ้ำกันเลย (เป็นไปไม่ได้จริงในทางปฏิบัติเพราะ Pigeonhole Principle)

🧮 ตัวอย่างการคำนวณ String Hashing ในข้อสอบจริง:

สูตรที่ 1 (ผลบวก ASCII ธรรมดา - Simple ASCII Sum):

$$\text{hash}(s) = \left( \sum_{i=0}^{k-1} \text{ASCII}(s[i]) \right) \bmod \text{TableSize}$$
  • คำนวณคีย์ "CAT" สำหรับตารางขนาด 11 ($M=11$):
    $\text{ASCII}('C') = 67, \quad \text{ASCII}('A') = 65, \quad \text{ASCII}('T') = 84$
    $\text{Sum} = 67 + 65 + 84 = \mathbf{216}$
    $\text{hash}("CAT") = 216 \bmod 11 = \mathbf{7}$ → ตกช่องดัชนี 7
  • คำนวณคีย์ "DOG" สำหรับตารางขนาด 11 ($M=11$):
    $\text{ASCII}('D') = 68, \quad \text{ASCII}('O') = 79, \quad \text{ASCII}('G') = 71$
    $\text{Sum} = 68 + 79 + 71 = \mathbf{218}$
    $\text{hash}("DOG") = 218 \bmod 11 = \mathbf{9}$ → ตกช่องดัชนี 9

สูตรที่ 2 (Polynomial Hash ในตำรา Weiss):

$$\text{hash}(s) = (s[0] + s[1] \cdot 32 + s[2] \cdot 32^2) \bmod \text{TableSize}$$
