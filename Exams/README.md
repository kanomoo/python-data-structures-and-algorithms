# Exams

This folder contains compact Python examples used for exams, practice, and quick demonstrations of core data structures and OOP concepts.

## Contents

- `BasicStack.py` and `BasicQueue.py` for simple stack/queue behavior
- `BasicSinglyLinkedList.py` and `LinkedList.py` for linked list practice
- `Queue.py` for an alternative queue implementation
- `PythonOop.py` for OOP examples such as encapsulation, inheritance, and overriding
- `Student.py` for class design and grade handling

## Notes

- Some files contain multiple versions of the same idea.
- Many examples are written for learning rather than production use.
