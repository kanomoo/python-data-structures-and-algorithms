## 📝 รายละเอียดโจทย์ (Problem Description)

> **Given the array `[64, 34, 25, 12, 22, 11, 90]`, trace the execution of the Bubble Sort program that we learned in class to sort the array in ascending order.**

---

## 💡 เฉลยและวิเคราะห์ขั้นตอนวิธีทำอย่างละเอียด (Step-by-step Solution)

### คำถามที่ 1: How many passes (outer loop iterations) will the algorithm make?
- **หลักการ:** ใน Bubble Sort สำหรับอาร์เรย์ที่มีสมาชิก $N$ ตัว ลูปนอก (Outer Loop) จะทำงานเท่ากับ:
  $$\text{Passes} = N - 1$$
- **การคำนวณ:** ข้อมูลมี 7 ตัว ($N = 7$ ได้แก่ 64, 34, 25, 12, 22, 11, 90)
  $$\text{Passes} = 7 - 1 = \mathbf{6}$$
- **คำตอบ:** **6**

---

### คำถามที่ 2: How many total swaps from start to finish?
- **วิธีตรง (ไล่โปรแกรม):** เสียเวลาอย่างน้อย 15-20 นาทีและเสี่ยงต่อการนับตกหล่น
- **วิธีลัดขั้นเทพ (Inversion Counting Technique):**  
  การ Swap ใน Bubble Sort 1 ครั้ง จะลดจำนวน Inversion ลง 1 คู่เสมอ  
  ดังนั้น จำนวน Swap ทั้งหมดจึงเท่ากับ **ผลรวมของจำนวนตัวเลขทางขวามือที่มีค่าน้อยกว่าตัวมันเอง**:

```
พิจารณาอาร์เรย์: [64, 34, 25, 12, 22, 11, 90]

• ตัวเลข 64: ตัวทางขวาที่น้อยกว่าคือ 34, 25, 12, 22, 11  ==> นับได้ 5 ตัว
• ตัวเลข 34: ตัวทางขวาที่น้อยกว่าคือ 25, 12, 22, 11      ==> นับได้ 4 ตัว
• ตัวเลข 25: ตัวทางขวาที่น้อยกว่าคือ 12, 22, 11          ==> นับได้ 3 ตัว
• ตัวเลข 12: ตัวทางขวาที่น้อยกว่าคือ 11                  ==> นับได้ 1 ตัว
• ตัวเลข 22: ตัวทางขวาที่น้อยกว่าคือ 11                  ==> นับได้ 1 ตัว
• ตัวเลข 11: ไม่มีตัวทางขวาที่น้อยกว่า                   ==> นับได้ 0 ตัว
• ตัวเลข 90: ไม่มีตัวทางขวาที่น้อยกว่า                   ==> นับได้ 0 ตัว
```

- **ผลรวม Total Swaps:**
  $$\text{Total Swaps} = 5 + 4 + 3 + 1 + 1 + 0 + 0 = \mathbf{14} \text{ ครั้ง}$$
- **คำตอบ:** **14**

---

### คำถามที่ 3: Complete the step-by-step trace of Pass 1:
- **Initial Array:** `[64, 34, 25, 12, 22, 11, 90]`
- **Step 1:** Compare (64, 34) $\to 64 > 34 \implies$ Swap $\to `[34, 64, 25, 12, 22, 11, 90]`
- **Step 2:** Compare (64, 25) $\to 64 > 25 \implies$ Swap $\to `[34, 25, 64, 12, 22, 11, 90]`
- **Step 3:** Compare (64, 12) $\to 64 > 12 \implies$ Swap $\to `[34, 25, 12, 64, 22, 11, 90]`
- **Step 4: Compare (64, 22)** $\to 64 > 22 \implies$ Swap $\to \mathbf{[34, 25, 12, 22, 64, 11, 90]}$
- **Step 5:** Compare (64, 11) $\to 64 > 11 \implies$ Swap $\to `[34, 25, 12, 22, 11, 64, 90]`
- **Step 6:** Compare (64, 90) $\to 64 < 90 \implies$ No Swap $\to `[34, 25, 12, 22, 11, 64, 90]`

- **คำตอบที่ต้องเขียนลงในช่องว่างของโจทย์:**
  $$\mathbf{[34, 25, 12, 22, 64, 11, 90]}$$

---

### คำถามที่ 4: Show the array state after Pass 1:
- หลังสิ้นสุด Pass 1 ค่า 64 จะลอยไปอยู่หน้า 90 (ซึ่ง 90 มีค่ามากที่สุดและอยู่ในตำแหน่งสุดท้ายอยู่แล้ว)
- **Initial Array:** `[64, 34, 25, 12, 22, 11, 90]`
- **Pass 1 Result:**
  $$\mathbf{[34, 25, 12, 22, 11, 64, 90]}$$

---

### คำถามที่ 5: How many total swaps after Pass 1?
- นับจำนวนการสลับเฉพาะใน Pass 1:
  - Step 1: สลับ 64 กับ 34 (Swap 1)
  - Step 2: สลับ 64 กับ 25 (Swap 2)
  - Step 3: สลับ 64 กับ 12 (Swap 3)
  - Step 4: สลับ 64 กับ 22 (Swap 4)
  - Step 5: สลับ 64 กับ 11 (Swap 5)
  - Step 6: 64 เปรียบเทียบกับ 90 ไม่สลับ (Swap 0)
- **คำตอบ:** **5** ครั้ง
