## 📐 2. กฎและสูตรสำคัญของ Binary Heap (1-Based Array Indexing)

ฮีปนิยมจัดเก็บใน Array โดยเริ่มที่ดัชนี **$1$** (ช่องที่ 0 ปล่อยว่างไว้) เพื่อให้ความสัมพันธ์ของโหนดคำนวณได้ด้วยการคูณหารระดับบิต:

$$\text{Parent}(i) = \left\lfloor \frac{i}{2} \right\rfloor$$
$$\text{Left Child}(i) = 2i$$
$$\text{Right Child}(i) = 2i + 1$$

- **Structure Property**: ต้องเป็น **Complete Binary Tree** เติมเต็มโหนดจากซ้ายไปขวาเสมอ
- **Order Property (Min-Heap)**: ค่าในโหนดพ่อต้อง **น้อยกว่าหรือเท่ากับ** โหนดลูกเสมอ ($\text{heap}[\text{parent}] \le \text{heap}[\text{child}]$)
- **Percolate Up (แทรกข้อมูล)**: นำโหนดใหม่ต่อท้าย แล้วสลับขึ้นไปหาตำแหน่งที่ถูกต้อง ($O(\log n)$)
- **Percolate Down (ลบ Min)**: นำรากออก เอาตัวสุดท้ายมาไว้ที่ราก แล้วสลับลงมากับลูกตัวที่น้อยกว่า ($O(\log n)$)

## 🗑️ 4. ขั้นตอนการทำ `deleteMin()` 3 ครั้ง (Exercise 6.3)

### ครั้งที่ 1: `deleteMin()` ตัวแรก (ลบ 1)
1. ดึงราก `1` ออก
2. นำโหนดตัวสุดท้ายคือ `8` มาวางที่รากแทน
3. ทำ **Percolate Down**:
   - ลูกของรากคือ `heap[2]=3` และ `heap[3]=2` $\implies$ ลูกที่น้อยกว่าคือ `2`
   - $8 > 2 \implies$ **สลับ 8 กับ 2**
   - ที่ตำแหน่ง 3: ลูกคือ `heap[6]=4` และ `heap[7]=5` $\implies$ ลูกที่น้อยกว่าคือ `4`
   - $8 > 4 \implies$ **สลับ 8 กับ 4**
   - ที่ตำแหน่ง 6: ลูกคือ `heap[12]=10` และ `heap[13]=11` $\implies 8 < 10 \implies$ สิ้นสุดการไหลลง

### ครั้งที่ 2: `deleteMin()` ตัวที่สอง (ลบ 2)
1. ดึงราก `2` ออก
2. นำโหนดตัวสุดท้ายคือ `13` มาวางที่รากแทน
3. ทำ Percolate Down: สลับ 13 กับ `3` แล้วสลับกับ `6`...

### ครั้งที่ 3: `deleteMin()` ตัวที่สาม (ลบ 3)
1. ดึงราก `3` ออก
2. นำโหนดตัวสุดท้ายมาวางที่ราก และปรับระเบียบตามลำดับ Heap Property

## 💻 5. โค้ดภาษา Python จำลอง Min-Heap (`Exams/Heap.py`)

```python
class MinHeap:
    def __init__(self):
        # index 0 เก็บ dummy value ไว้เพื่อง่ายต่อสูตรคำนวณ 1-based index
        self.heap = [0]

    def insert(self, val):
        self.heap.append(val)
        self._percolate_up(len(self.heap) - 1)

    def _percolate_up(self, i):
        while i // 2 > 0:
            parent = i // 2
            if self.heap[i] < self.heap[parent]:
                self.heap[i], self.heap[parent] = self.heap[parent], self.heap[i]
                i = parent
            else:
                break

    def delete_min(self):
        if len(self.heap) <= 1:
            return None
        min_val = self.heap[1]
        last_val = self.heap.pop()
        if len(self.heap) > 1:
            self.heap[1] = last_val
            self._percolate_down(1)
        return min_val

    def _percolate_down(self, i):
        while (i * 2) < len(self.heap):
            min_child = self._min_child(i)
            if self.heap[i] > self.heap[min_child]:
                self.heap[i], self.heap[min_child] = self.heap[min_child], self.heap[i]
                i = min_child
            else:
                break

    def _min_child(self, i):
        if i * 2 + 1 >= len(self.heap):
            return i * 2
        else:
            if self.heap[i * 2] < self.heap[i * 2 + 1]:
                return i * 2
            return i * 2 + 1

    def print_heap(self):
        print("Array Representation (1-based):", self.heap[1:])


if __name__ == "__main__":
    h = MinHeap()
    inputs = [10, 12, 1, 14, 6, 5, 8, 15, 3, 9, 7, 4, 11, 13, 2]
    
    print("--- 6.2a: แทรกตัวเลข 15 ตัวลงใน Min-Heap ---")
    for x in inputs:
        h.insert(x)
    h.print_heap()

    print("\n--- 6.3: สั่ง deleteMin() 3 ครั้ง ---")
    for step in range(1, 4):
        val = h.delete_min()
        print(f"ครั้งที่ {step}: ลบค่า Min = {val}")
        h.print_heap()
```
