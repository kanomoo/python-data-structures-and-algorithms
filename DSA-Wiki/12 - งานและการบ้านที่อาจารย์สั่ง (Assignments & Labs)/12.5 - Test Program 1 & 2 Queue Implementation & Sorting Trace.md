## 📥 1. Test Program 1: Queue Implementation with Overflow & Underflow

### 1.1 วัตถุประสงค์และข้อกำหนดโจทย์
1. สร้างคลาส `Queue(limit)` เพื่อจำลองโครงสร้างข้อมูลแบบคิว (FIFO: First-In First-Out)
2. จัดการสภาวะผิดปกติ 2 กรณีตามทฤษฎีในห้องเรียน:
   - **Queue Overflow**: ตรวจจับเมื่อเรียก `enQueue` ขณะที่จำนวนสมาชิกเต็มขีดจำกัด `limit`
   - **Queue Underflow**: ตรวจจับเมื่อเรียก `deQueue` ขณะที่คิวว่างเปล่า (`isEmpty == True`)
3. แสดงผลรหัสนักศึกษาและชื่อในส่วนหัวโปรแกรม
4. ทำการทดสอบ 2 รอบ:
   - รอบที่ 1: สร้างคิวขนาด 5 ช่อง ใส่ข้อมูล 6, 1, 2, 0, 3 แล้วพยายามแทรกตัวที่ 6 (ค่า 7) เพื่อทดสอบ Overflow
   - รอบที่ 2: สร้างคิวขนาด 6 ช่อง ใส่ข้อมูล 6 ตัว แล้ว Dequeue ออกทีละตัวจนหมด และ Dequeue ซ้ำเพื่อทดสอบ Underflow

### 1.2 โค้ดส่งจริงของนักศึกษา (`Lectures/Test Program 1_ Queue/program.py`)

```python
# Paphavin Thitichunhakun 6806021612037

class Queue:
    def __init__(self, limit):
        self.items = []
        self.limit = limit
        self.front = 0
        self.rear = -1
        self.size = 0
        
    def isEmpty(self):
        return len(self.items) <= 0
    
    def enQueue(self, item):
        if len(self.items) >= self.limit:
            print("Queue is overflow")
        else: 
            self.items.append(item)
            self.rear += 1
            self.size += 1
    
    def deQueue(self):
        if self.isEmpty():
            print("Queue is underflow")
        else: 
            self.items.pop(0)
            self.size = self.size - 1
            self.rear = self.size - 1
    
    def printqueue(self):
        for i in range(self.size):
            print(self.items[i], end=' ')
        print()

if __name__ == "__main__":
    print("Paphavin Thitichunhakun 6806021612037")
    queue = Queue(5)
    queue.enQueue(6)
    queue.enQueue(1)
    queue.enQueue(2)
    queue.enQueue(0)
    queue.enQueue(3)
    queue.printqueue()  # แสดง: 6 1 2 0 3
    queue.enQueue(7)    # แสดง: Queue is overflow

    print("\nPaphavin Thitichunhakun 6806021612037")
    queue = Queue(6)
    queue.enQueue(6)
    queue.enQueue(1)
    queue.enQueue(2)
    queue.enQueue(0)
    queue.enQueue(3)
    queue.enQueue(7)
    queue.deQueue()
    queue.deQueue()
    queue.deQueue()
    queue.deQueue()
    queue.deQueue()
    queue.deQueue()
    queue.printqueue()  # ลิสต์ว่าง
    queue.deQueue()     # แสดง: Queue is underflow
```

### 2.1 อัลกอริทึมที่ 1: Insertion Sort

### 2.3 อัลกอริทึมที่ 3: Bubble Sort
- ข้อมูลเริ่มต้น: `[5, 1, 4, 2, 8]`
- **รอบที่ 1 ($i = 0$)**:
  - เปรียบเทียบ 5 กับ 1 $\implies$ **สลับ 5 กับ 1** $\to$ `[1, 5, 4, 2, 8]`
  - เปรียบเทียบ 5 กับ 4 $\implies$ **สลับ 5 กับ 4** $\to$ `[1, 4, 5, 2, 8]`
  - เปรียบเทียบ 5 กับ 2 $\implies$ **สลับ 5 กับ 2** $\to$ `[1, 4, 2, 5, 8]`
  - เปรียบเทียบ 5 กับ 8 $\implies$ ไม่สลับ $\to$ จบรอบ 0 ได้ `[1, 4, 2, 5, 8]`
- **รอบที่ 2 ($i = 1$)**:
  - เปรียบเทียบ 1 กับ 4 $\implies$ ไม่สลับ
  - เปรียบเทียบ 4 กับ 2 $\implies$ **สลับ 4 กับ 2** $\to$ `[1, 2, 4, 5, 8]`
  - เปรียบเทียบที่เหลือ $\implies$ จบรอบ 1 ได้ `[1, 2, 4, 5, 8]`
- **รอบที่ 3 ถึง 5**: ไม่มีคู่ใดต้องสลับอีก $\implies$ หยุดการทำงาน

## 💻 3. โค้ดภาษา Python สำหรับ Test Program 2 Sorting Tracing

```python
def insertion_sort_traced(arr):
    a = arr.copy()
    print("=== 1. Insertion Sort Trace ===")
    print(f"Original: {a}")
    for p in range(1, len(a)):
        key = a[p]
        j = p - 1
        moves = 0
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            moves += 1
            j -= 1
        a[j + 1] = key
        print(f"After p= {p} {a} Position Move: {moves}")
    return a

def selection_sort_traced(arr):
    a = arr.copy()
    print("\n=== 2. Selection Sort Trace ===")
    print(f"Original: {a}")
    n = len(a)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j
        swap_occurred = 1 if min_idx != i else 0
        if swap_occurred:
            a[i], a[min_idx] = a[min_idx], a[i]
        print(f"For i= {i}, j= {n-1} {a} min_idx: {min_idx}, swap: {swap_occurred}")
    return a

def bubble_sort_traced(arr):
    a = arr.copy()
    print("\n=== 3. Bubble Sort Trace ===")
    print(f"Original: {a}")
    n = len(a)
    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if a[j] > a[j + 1]:
                print(f"Swap {a[j]} and {a[j+1]}")
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        print(f"For loop i= {i} arr = {a}")
        if not swapped:
            break
    return a

if __name__ == "__main__":
    insertion_sort_traced([34, 8, 64, 51, 32, 21])
    selection_sort_traced([64, 25, 12, 22, 11])
    bubble_sort_traced([5, 1, 4, 2, 8])
```
