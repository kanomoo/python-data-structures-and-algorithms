## 📝 ส่วนที่ 2: โจทย์ภาษาอังกฤษต้นฉบับ `deleteMin()` & `percolateDown` (Page 3 & 4)

### 🇬🇧 ซอร์สโค้ดมาตรฐานจากสไลด์ (Official Method Implementation):
```python
def delete_min(self): 
    if self.is_empty(): 
        print("Heap is empty") 
        return        
    min_item = self.array[1] 
    self.array[1] = self.array[self.currentSize] 
    self.currentSize -= 1 
    self._percolate_down(1) 
    return min_item 

def _percolate_down(self, hole): 
    temp = self.array[hole] 
    while hole * 2 <= self.currentSize: 
        child = hole * 2 
        if child != self.currentSize and self.array[child + 1] < self.array[child]: 
            child += 1 
        if self.array[child] < temp: 
            self.array[hole] = self.array[child] 
        else: 
            break 
        hole = child 
    self.array[hole] = temp
```

### 🇬🇧 คำถามเจาะลึกและเฉลยจากเอกสารแจกหน้า 4 (Page 4 Trace):
```text
การทำงานในฟังก์ชัน percolateDown:
hole = 1
temp = array[11] = 31 (ตัดช่อง 11 ทิ้ง, currentSize ลดเหลือ 10)

while loop รอบที่ 1:
- hole = 1, hole * 2 <= 10 (2 <= 10 จริง)
- child = 2 (Left Child มีค่า 14)
- เปรียบเทียบ array[3] < array[2] (16 < 14 เท็จ) -> ไม่ทำ child++
- เปรียบเทียบ array[child] < temp (14 < 31 จริง) -> array[1] = 14
- ปรับหลุม: hole = child = 2

while loop รอบที่ 2:
- hole = 2, hole * 2 <= 10 (4 <= 10 จริง)
- child = 4 (Left Child มีค่า 24)
- เปรียบเทียบ array[5] < array[4] (21 < 24 จริง!) -> ทำ child++ ทำให้ child = 5
- เปรียบเทียบ array[child] < temp (21 < 31 จริง) -> array[2] = 21
- ปรับหลุม: hole = child = 5

while loop รอบที่ 3:
- hole = 5, hole * 2 <= 10 (10 <= 10 จริง)
- child = 10 (Left Child มีค่า 32)
- child == currentSize (10 == 10) -> ไม่มีลูกขวา ไม่ทำ child++
- เปรียบเทียบ array[child] < temp (32 < 31 เท็จ!) -> break หยุดลูปทันที!

คำตอบคำถามท้ายเอกสารหน้า 4:
- ออกจาก while loop ตัวแปร hole มีค่าเท่ากับเท่าไร = 5
- บรรจุ temp: array[hole] = temp -> array[5] = 31
- while loop ทำงานกี่รอบ = 2 รอบ (รอบที่ 3 หลุดลูปด้วย break ไม่มีการเลื่อนค่า)
```

## 📝 ส่วนที่ 3: ข้อสอบปลายภาคฉบับจริง (DeleteMin 3 ครั้งติดต่อกัน)

อาจารย์นำโจทย์นี้ไปออกต่อในข้อสอบปลายภาค โดยสั่งให้รัน `deleteMin()` ต่อเนื่องอีก 2 ครั้ง:

### 🔴 DeleteMin ครั้งที่ 2 (ดึง 14 ออก, `temp = 32`, ขนาดยุบเหลือ 9):
- `hole = 1`
- รอบ 1: เลือกลูกตัวน้อยกว่าระหว่างช่อง 2 (21) กับช่อง 3 (16) $\to$ เลือกลูก 16 (`child = 3`)
  - $16 < 32$ (จริง) $\to \text{array}[1] = 16, \text{hole} = 3$
- รอบ 2: เลือกลูกตัวน้อยกว่าระหว่างช่อง 6 (19) กับช่อง 7 (68) $\to$ เลือกลูก 19 (`child = 6`)
  - $19 < 32$ (จริง) $\to \text{array}[3] = 19, \text{hole} = 6$
- รอบ 3: ช่อง 6 ไม่มีลูก ($6 \times 2 = 12 > 9$) $\to$ หยุดลูป
- บรรจุ `temp = 32` ลงที่ `array[6]`
- **Array ครั้งที่ 2:** `[None, 16, 21, 19, 24, 31, 32, 68, 65, 26]`

---

### 🔴 DeleteMin ครั้งที่ 3 (ดึง 16 ออก, `temp = 26`, ขนาดยุบเหลือ 8 — ข้อสอบปลายภาค!):
- `hole = 1`
- รอบ 1: เลือกลูกตัวน้อยกว่าระหว่างช่อง 2 (21) กับช่อง 3 (19) $\to$ เลือกลูก 19 (`child = 3`)
  - $19 < 26$ (จริง) $\to \text{array}[1] = 19, \text{hole} = 3$
- รอบ 2: เลือกลูกตัวน้อยกว่าระหว่างช่อง 6 (32) กับช่อง 7 (68) $\to$ เลือกลูก 32 (`child = 6`)
  - $32 < 26$ (**เท็จ!**) $\to$ หยุดลูปทันที
- บรรจุ `temp = 26` ลงที่ `array[3]`
- **Array ครั้งที่ 3 (คำตอบสุดท้าย 10 คะแนนเต็ม):**  
  `[None, 19, 21, 26, 24, 31, 32, 68, 65]`
