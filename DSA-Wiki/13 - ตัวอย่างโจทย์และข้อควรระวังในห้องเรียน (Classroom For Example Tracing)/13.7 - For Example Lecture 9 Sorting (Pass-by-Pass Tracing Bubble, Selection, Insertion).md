## 📝 ส่วนที่ 1: Selection Sort & เจาะลึก Python Internals (`For Example Selection sort 169.pdf`)

### 🇬🇧 1.1 โจทย์และโครงสร้างโค้ด Selection Sort
กำหนดอาร์เรย์เริ่มต้น `[64, 25, 12, 22, 11]` (ขนาด $n = 5$, ดัชนีคือ 0 ถึง 4) ให้แจกแจงการทำงานของฟังก์ชัน `selection_sort()` ในแต่ละรอบว่า:
1. ค่าน้อยที่สุด (Minimum value) คือค่าใด และอยู่ที่ดัชนีใด
2. สมาชิกในส่วนที่ยังไม่ได้จัดเรียง (Remaining unsorted elements) เหลืออะไรบ้าง

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            temp = arr[i]
            arr[i] = arr[min_idx]
            arr[min_idx] = temp
```

### 🔍 1.2 เฉลยละเอียดครบทั้ง 5 รอบ (พร้อมเติมคำตอบในใบงาน 169)

#### 🔴 Round 1 ($i = 0$, สมมติ $\text{min\_idx} = 0$):
- ลูป `for j in range(1, 5)` วิ่งตรวจสอบดัชนี 1, 2, 3, 4:
  - $j=1$: $\text{arr}[1]=25 < \text{arr}[0]=64 \implies \text{min\_idx} = 1$
  - $j=2$: $\text{arr}[2]=12 < \text{arr}[1]=25 \implies \text{min\_idx} = 2$
  - $j=3$: $\text{arr}[3]=22 < \text{arr}[2]=12$ (เท็จ)
  - $j=4$: $\text{arr}[4]=11 < \text{arr}[2]=12 \implies \text{min\_idx} = 4$
- **1. Find the minimum:** ในอาร์เรย์ `[64, 25, 12, 22, 11]` ค่าน้อยที่สุดคือ **11 ซึ่งอยู่ที่ตำแหน่งดัชนี 4**
- **2. Swap:** สลับค่าน้อยที่สุด (11) กับสมาชิกตัวแรกของส่วนที่ยังไม่ได้จัดเรียง (64)
  - ก่อนสลับ: `[64, 25, 12, 22, 11]`
  - หลังสลับ: `[11, 25, 12, 22, 64]`
- **3. Result:** สมาชิกตัวแรก (`11`) ถูกจัดเรียงแล้ว ตอนนี้ส่วนที่ยังไม่ได้จัดเรียงคือ `[25, 12, 22, 64]`

---

#### 🔴 Round 2 ($i = 1$, สมมติ $\text{min\_idx} = 1$):
- ตำแหน่งที่ 0 เรียงเสร็จแล้ว ลูป `for j in range(2, 5)` วิ่งตรวจสอบดัชนี 2, 3, 4:
  - $j=2$: $\text{arr}[2]=12 < \text{arr}[1]=25 \implies \text{min\_idx} = 2$
  - $j=3$: $\text{arr}[3]=22 < \text{arr}[2]=12$ (เท็จ)
  - $j=4$: $\text{arr}[4]=64 < \text{arr}[2]=12$ (เท็จ)
- **1. Find the minimum:** From the unsorted array `[25, 12, 22, 64]` the minimum is **12 at index 2**
- **2. Swap:** Swap the minimum (12) with the first of the unsorted array (25)
  - Before swap: `[11, 25, 12, 22, 64]`
  - After swap: `[11, 12, 25, 22, 64]`
- **3. Result:** Now, 2 elements (`[11, 12]`) was sorted. The remaining unsorted array is `[25, 22, 64]`

---

#### 🔴 Round 3 ($i = 2$, สมมติ $\text{min\_idx} = 2$) *(เติมคำตอบในใบงานหน้า 2)*:
- ตำแหน่งที่ 0 และ 1 เรียงเสร็จแล้ว ลูป `for j in range(3, 5)` วิ่งตรวจสอบดัชนี 3, 4:
  - $j=3$: $\text{arr}[3]=22 < \text{arr}[2]=25 \implies \text{min\_idx} = 3$
  - $j=4$: $\text{arr}[4]=64 < \text{arr}[3]=22$ (เท็จ)
- **1. Find the minimum:** From the unsorted array `[25, 22, 64]` the minimum is **22 at index 3**
- **2. Swap:** Swap the minimum (**22**) with the first of the unsorted array (**25**)
  - Before swap: `[11, 12, 25, 22, 64]` *(เขียนสมาชิกใน array ให้ครบทั้ง 5 ตัว)*
  - After swap: `[11, 12, 22, 25, 64]` *(เขียนสมาชิกใน array ให้ครบทั้ง 5 ตัว)*
- **3. Result:** Now, **3** elements (**11, 12, 22**) was sorted. The remaining unsorted array is **`[25, 64]`**

---

#### 🔴 Round 4 ($i = 3$, สมมติ $\text{min\_idx} = 3$) *(เติมคำตอบในใบงานหน้า 2-3)*:
- ตำแหน่งที่ 0, 1, 2 เรียงเสร็จแล้ว ลูป `for j in range(4, 5)` วิ่งตรวจสอบดัชนี 4:
  - $j=4$: $\text{arr}[4]=64 < \text{arr}[3]=25$ (เท็จ) $\implies \text{min\_idx} = 3$
- **1. Find the minimum:** From the unsorted array **`[25, 64]`** the minimum is **25 at index 3**
- **2. Swap:** Swap the minimum (**25**) with the first of the unsorted array (**25**) *(เนื่องจาก $\text{min\_idx} == i$ โค้ด `if min_idx != i:` จะไม่ทำการสลับ)*
  - Before swap: `[11, 12, 22, 25, 64]` *(เขียนสมาชิกใน array ให้ครบทั้ง 5 ตัว)*
  - After swap: `[11, 12, 22, 25, 64]` *(เขียนสมาชิกใน array ให้ครบทั้ง 5 ตัว)*
- **3. Result:** Now, **4** elements (**11, 12, 22, 25**) was sorted. The remaining unsorted array is **`[64]`**

---

#### 🔴 Round 5 ($i = 4$):
- **1.** There is only one element `[64]` mean sorted already.
- **2. Result:** Now, all elements were sorted: `[11, 12, 22, 25, 64]`.

### 💡 1.3 เจาะลึกเนื้อหาทฤษฎี Python Internals จากเอกสาร 169

> [!TIP]
> **บทวิเคราะห์โครงสร้างภาษา Python ที่อาจารย์เน้นย้ำเป็นพิเศษในสไลด์**:

1. **อย่าลืม: `for i in range(5)` ให้ผลลัพธ์เป็นอะไร?**
   - ให้ผลลัพธ์คือ `0, 1, 2, 3, 4` (จำนวน 5 รอบ)
   - **ไม่ใช่ `1, 2, 3, 4, 5` เด็ดขาด!**

2. **หลักการทำงานของ `range(n)` ในหน่วยความจำ (Metadata Concept)**:
   - ฟังก์ชัน `range(n)` เป็นฟังก์ชันสร้างลำดับตัวเลขที่กินหน่วยความจำน้อยมาก ($O(1)$ space)
   - `range(5)` **ไม่ได้สร้างลิสต์หรืออาร์เรย์ของตัวเลขเตรียมไว้ล่วงหน้า** ใน Memory
   - แต่เก็บข้อมูลการสร้างเป็น **Metadata เพียง 3 ค่าสั้นๆ** คือ:
     - `start = 0`
     - `stop = 5`
     - `step = 1`
   - หากไม่ใช้ `range(n)` เราสามารถเขียนแทนด้วยคำสั่ง `while` loop ได้ดังนี้:
     ```python
     j = 0
     while j < n:
         # โค้ดที่ต้องการรัน
         j += 1
     ```

3. **ถามว่า `range(0)` มีค่าเป็น `None` หรือ `[0]`?**
   - **คำตอบคือ: ไม่มีทั้งคู่!**
   - `range(0)` ไม่ใช่ `None` และไม่ใช่ `[0]` แต่เป็น **ลำดับว่างเปล่า (Empty Range / Sequence Object)** ที่มีจำนวนสมาชิกเป็น 0 ตัว (`len(range(0)) == 0`)

4. **`range(0)` มีความหมายเดียวกับ `[]` ใช่หรือไม่?**
   - **ในแง่ผลลัพธ์การใช้งาน (Runtime Effect):** ถือว่าเหมือนกัน เพราะเมื่อนำไปใช้ในลูป `for` ทั้งคู่จะ **ไม่ทำงานเลยแม้แต่รอบเดียว (ข้ามลูปทันที)**
     ```python
     for j in range(0):
         print("A")  # ไม่ถูกพิมพ์เลย

     for j in []:
         print("A")  # ไม่ถูกพิมพ์เลย
     ```
   - **ในเชิงโครงสร้างข้อมูล (Data Structure):** **ไม่เหมือนกัน!**
     - `[]` คือ **List Object** มีการจัดสรรพื้นที่ (Memory Allocation) เพื่อสร้างออบเจกต์ลิสต์จริง
     - `range(0)` คือ **Range Object** เป็นตัวสร้างลำดับตัวเลขที่ไม่เกิดการจองพื้นที่แบบลิสต์

5. **คำสั่ง `for j in range(i + 1, n):` หมายถึงอย่างไรใน Selection Sort?**
   - หมายถึง **"การให้ j วนลูปดูทีละตัว ตั้งแต่ตำแหน่งถัดจาก i ไปจนถึงตัวสุดท้ายของอาร์เรย์"**
   - ตัวอย่างเมื่อมีข้อมูล 5 ตัว ($n=5$, ดัชนีคือ 0, 1, 2, 3, 4):
     - **เมื่อ $i = 0$ (รอบแรก):** `range(i + 1, n)` จะกลายเป็น `range(1, 5)` โดย $j$ จะวิ่งไปที่ตำแหน่ง 1, 2, 3, 4 หมายถึงเราสมมุติให้ตัวที่ 0 น้อยที่สุดก่อน (`min_idx = 0`) แล้วใช้ $j$ เดินสำรวจตัวที่เหลือทั้งหมดเพื่อหาว่ามีตัวไหนน้อยกว่าตัวที่ 0 หรือไม่
     - **เมื่อ $i = 1$ (รอบที่สอง):** `range(i + 1, n)` จะกลายเป็น `range(2, 5)` โดย $j$ จะวิ่งไปที่ตำแหน่ง 2, 3, 4 หมายถึงตำแหน่งที่ 0 เรียงเสร็จแล้ว ไม่ต้องไปยุ่งกับมันอีก ให้สำรวจเฉพาะกลุ่มที่ยังไม่ได้จัดเรียง

## 📝 ส่วนที่ 2: Bubble Sort & เฉลยข้อสอบจริง (`For Example Bubble sort.pdf`)

### 📌 2.1 หลักการทำงานและสูตรการคำนวณ
- **หัวใจสำคัญ:** "หยิบตัวเลขทีละคู่ที่อยู่ติดกัน มาเปรียบเทียบและสลับที่กันไปเรื่อยๆ จากซ้ายไปขวา"
- **สูตรคำนวณจำนวนรอบ (Outer loop passes):** คือ $n - 1$ รอบเสมอ
  - หากข้อมูลมี 5 ตัว โปรแกรมจะทำงาน $5 - 1 = 4$ รอบ (ใน Python: `for i in range(n - 1):`)
- **สูตรคำนวณจำนวนครั้งในการสลับ (Total Swaps) และทฤษฎี Inversions:**
  - ไม่มีสูตรตายตัวขึ้นอยู่กับลำดับข้อมูลเดิม
  - **หลักการเด็ด:** จำนวนครั้งในการสลับทั้งหมด จะเท่ากับ **"จำนวนคู่อันดับที่เรียงผิดลำดับ (Inversions)"** ในลิสต์เริ่มต้นเสมอ!
  - **Inversion** คือ คู่ $(i, j)$ ที่ดัชนี $i < j$ แต่ค่า $\text{arr}[i] > \text{arr}[j]$
  - **ทำไมถึงเท่ากัน?** เพราะใน Bubble Sort การ Swap สมาชิกคู่ติดกัน 1 ครั้ง จะช่วยลด Inversion ไปได้ 1 คู่เสมอ ดังนั้นจำนวน Inversions ทั้งหมดที่มีในลิสต์ตั้งแต่แรก จึงเท่ากับจำนวนครั้งที่เราต้อง Swap จนกว่าจะเรียงเสร็จพอดี

#### ตัวอย่างการนับ Inversions บน `[5, 1, 4, 2, 8]`:
1. คู่ของ 5: (5, 1), (5, 4), (5, 2) $\to$ 3 คู่
2. คู่ของ 1: ไม่มี
3. คู่ของ 4: (4, 2) $\to$ 1 คู่
4. คู่ของ 2: ไม่มี
5. คู่ของ 8: ไม่มี
- **รวมจำนวนคู่ที่วางผิดลำดับ (Inversions):** $3 + 1 = 4$ คู่
- **สรุป:** ลิสต์นี้จะเกิดการ Swap ทั้งหมด **4 ครั้งแน่นอน**

## 📝 ส่วนที่ 3: Insertion Sort & การนับ Position Move (`Short note Insertion sort.pdf`)

### 🇬🇧 3.1 ซอร์สโค้ดมาตรฐานและโครงสร้างลูป
```python
def insertion_sort(a):
    for p in range(1, len(a)):
        tmp = a[p]
        j = p
        while j > 0 and tmp < a[j - 1]:
            a[j] = a[j - 1]
            j -= 1
        a[j] = tmp
```

---

### 📖 3.2 เจาะลึก 5 หัวใจสำคัญของ Insertion Sort (อธิบายบรรทัดต่อบรรทัด)
1. `j = p`: กำหนดตัวแปร `j` ให้มีค่าเท่ากับ `p` เพื่อใช้เป็นตัวชี้ (Pointer) ในการเปรียบเทียบและเลื่อนตำแหน่งจากขวามาซ้าย
2. `while j > 0 and tmp < a[j - 1]:` **นี่คือหัวใจของการแทรก**
   - `j > 0`: เงื่อนไขนี้ทำให้แน่ใจว่าเราไม่ได้พยายามเข้าถึง Index ที่น้อยกว่า 0 (ในภาษา Python หากไม่มีเงื่อนไขนี้ `a[-1]` จะไปดึงตัวสุดท้ายของลิสต์มาเปรียบเทียบ ทำให้โปรแกรมเพี้ยนทันที)
   - `tmp < a[j - 1]`: เปรียบเทียบค่าของสมาชิกที่เรากำลังจะแทรก (`tmp`) กับสมาชิกที่อยู่ก่อนหน้า (`a[j - 1]`)
3. **ถ้าทั้งสองเงื่อนไขเป็นจริง:** หมายความว่า `tmp` มีค่าน้อยกว่าสมาชิกที่อยู่ก่อนหน้า ดังนั้นสมาชิกตัวก่อนหน้า (`a[j - 1]`) ต้องถูก **เลื่อนไปทางขวาหนึ่งตำแหน่ง** เพื่อเปิดทางให้ `tmp`
4. `a[j] = a[j - 1]`: เลื่อนสมาชิก `a[j - 1]` ไปยังตำแหน่ง `a[j]` (นำค่าทางขวามาใส่ทางซ้าย) $\implies$ **นับเป็น 1 Position Move!**
5. `j -= 1`: ลดค่า `j` ลง 1 เพื่อขยับไปเปรียบเทียบกับสมาชิกตัวถัดไปทางซ้าย
6. **เมื่อเงื่อนไขใน while เป็นเท็จ** (คือ `j == 0` หรือ `tmp >= a[j - 1]`): แสดงว่าเจอตำแหน่งที่เหมาะสมแล้ว จึงนำค่า `tmp` ไปใส่ไว้ที่ตำแหน่ง `j` ด้วยคำสั่ง `a[j] = tmp`

## 📝 ส่วนที่ 4: สรุปสไลด์บรรยายทางการ (`DATA STRUCTURES & ALGORITHMS_Lecture 9 168.pdf`)

### 🌐 4.1 Preliminaries of Comparison-Based Sorting
- อัลกอริทึมทั้งหมดทำงานแบบ **Exchangeable** (สามารถสลับใช้งานแทนกันได้บนชุดข้อมูลเดียวกัน)
- ส่งผ่านข้อมูลด้วย Array ที่บรรจุสมาชิกทั้งหมด
- มีสมมติฐานว่าข้อมูลสนับสนุนตัวดำเนินการเปรียบเทียบ `<` และ `>`
- การจัดเรียงภายใต้เงื่อนไขนี้เรียกว่า **Comparison-based sorting** ซึ่งมีขอบเขตล่างเชิงทฤษฎีอยู่ที่ $\Omega(N \log N)$

### 📊 4.2 3 Cases in Algorithm Analysis
ในการศึกษาประสิทธิภาพของขั้นตอนวิธี จะพิจารณา 3 กรณีหลัก:
1. **Best Case:** กรณีที่ดีที่สุด (ข้อมูลเรียงลำดับอยู่แล้ว) เช่น Insertion Sort ใช้เวลาเพียง $O(N)$
2. **Worst Case:** กรณีที่แย่ที่สุด (ข้อมูลเรียงกลับทิศจากมากไปน้อย) มีความซับซ้อน $O(N^2)$
3. **Average Case:** กรณีเฉลี่ย (ข้อมูลสุ่มกระจายตัว) มีความซับซ้อน $O(N^2)$

### 💻 4.3 โค้ดมาตรฐาน Bubble Sort ในสไลด์อาจารย์
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        last_index = n - 1 - i
        for j in range(last_index):
            if arr[j] > arr[j + 1]:
                temp = arr[j]
                arr[j] = arr[j + 1]
                arr[j + 1] = temp
```
- ตัวแปร `last_index = n - 1 - i`: ทำให้ลูปภายในลดขอบเขตการเปรียบเทียบลงทีละ 1 ในแต่ละรอบ เพราะตัวที่มากที่สุดถูกนำไปไว้ทางขวาสุดเรียบร้อยแล้ว
- **ข้อสรุปสำคัญของอาจารย์:** "Bubble Sort requires at most n-1 passes for n elements"
