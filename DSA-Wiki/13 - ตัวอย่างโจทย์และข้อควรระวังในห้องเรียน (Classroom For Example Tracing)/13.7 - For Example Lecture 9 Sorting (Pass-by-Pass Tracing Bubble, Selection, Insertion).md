## 📝 ส่วนที่ 1: Selection Sort (โจทย์ภาษาอังกฤษต้นฉบับ & เฉลยละเอียด 5 รอบ)

### 🇬🇧 โจทย์ภาษาอังกฤษต้นฉบับจากเอกสารแจก (Original English Handout):
```text
For Example Selection sort:
If there is the exist array (list in python) contains the numbers [64, 25, 12, 22, 11]
Write the step for the selection_sort() function.
In each round, consists of:
1) what is the minimum, and
2) what is the remaining un-sorted are executed under.

Code structure:
for i in range(n):
    min_idx = i
    for j in range(i + 1, n):
        if arr[j] < arr[min_idx]:
            min_idx = j
    arr[i], arr[min_idx] = arr[min_idx], arr[i]
```

### 🔍 เฉลยละเอียดครบทั้ง 5 รอบ (Bilingual Model Answer):

#### 🔴 Round 1 (i = 0, min_idx เริ่มต้น = 0):
- ลูป `for j in range(1, 5)` วิ่งตรวจสอบ:
  - $j=1$: $\text{arr}[1]=25 < \text{arr}[0]=64 \implies \text{min\_idx} = 1$
  - $j=2$: $\text{arr}[2]=12 < \text{arr}[1]=25 \implies \text{min\_idx} = 2$
  - $j=3$: $\text{arr}[3]=22 < \text{arr}[2]=12$ (เท็จ)
  - $j=4$: $\text{arr}[4]=11 < \text{arr}[2]=12 \implies \text{min\_idx} = 4$
- **1. Find the minimum:** From the unsorted array `[64, 25, 12, 22, 11]` the minimum is **11 at index 4**.
- **2. Swap:** Swap the minimum (11) with the first element of the unsorted array (64):
  - **Before swap:** `[64, 25, 12, 22, 11]`
  - **After swap:** `[11, 25, 12, 22, 64]`
- **3. Result:** Now, 1 element (`[11]`) was sorted. The remaining unsorted array is `[25, 12, 22, 64]`.

---

#### 🔴 Round 2 (i = 1, min_idx เริ่มต้น = 1):
- แปลว่าตำแหน่งที่ 0 เรียงเสร็จแล้ว พิจารณาจากตำแหน่งที่ 1 เป็นต้นไป
- **1. Find the minimum:** From the unsorted array `[25, 12, 22, 64]` the minimum is **12 at index 2**.
- **2. Swap:** Swap the minimum (12) with the first element of the unsorted array (25):
  - **Before swap:** `[11, 25, 12, 22, 64]`
  - **After swap:** `[11, 12, 25, 22, 64]`
- **3. Result:** Now, 2 elements (`[11, 12]`) were sorted. The remaining unsorted array is `[25, 22, 64]`.

---

#### 🔴 Round 3 (i = 2, min_idx เริ่มต้น = 2):
- แปลว่าตำแหน่งที่ 0 และ 1 เรียงเสร็จแล้ว
- **1. Find the minimum:** From the unsorted array `[25, 22, 64]` the minimum is **22 at index 3**.
- **2. Swap:** Swap the minimum (22) with the first element of the unsorted array (25):
  - **Before swap:** `[11, 12, 25, 22, 64]`
  - **After swap:** `[11, 12, 22, 25, 64]`
- **3. Result:** Now, 3 elements (`[11, 12, 22]`) were sorted. The remaining unsorted array is `[25, 64]`.

---

#### 🔴 Round 4 (i = 3, min_idx เริ่มต้น = 3):
- **1. Find the minimum:** From the unsorted array `[25, 64]` the minimum is **25 at index 3**.
- **2. Swap:** Swap 25 with 25 (อยู่ที่เดิม):
  - **Before swap:** `[11, 12, 22, 25, 64]`
  - **After swap:** `[11, 12, 22, 25, 64]`
- **3. Result:** Now, 4 elements (`[11, 12, 22, 25]`) were sorted. The remaining unsorted array is `[64]`.

---

#### 🔴 Round 5 (i = 4):
- **1. There is only one element `[64]` mean sorted already.**
- **2. Result:** Now, all elements were sorted: `[11, 12, 22, 25, 64]`.

## 📝 ส่วนที่ 2: ข้อควรระวังเรื่อง Loop Range ใน Python ("หมายเหตุ ในหัวข้อ insertion sort.pdf")

### 🇬🇧 คำเตือนคำสอนจากอาจารย์ประดิษฐ์:
```text
คำสั่ง for p in range(1, 5): และ for p in range(5): ใน Python มีความแตกต่างกันที่:
1) จุดเริ่มต้น (Start index)
2) จำนวนรอบ (Number of iterations)

for p in range(1, 5):
- ช่วง (Range): เริ่มต้นที่ 1 และ สิ้นสุดที่ 4 (ไม่รวม 5)
- ตัวแปร p: จะมีค่าเป็น 1, 2, 3, 4
- จำนวนรอบ: วนซ้ำทั้งหมด 4 ครั้ง

for p in range(5):
- ช่วง (Range): เริ่มต้นที่ 0 (โดยปริยาย) และ สิ้นสุดที่ 4 (ไม่รวม 5)
- ตัวแปร p: จะมีค่าเป็น 0, 1, 2, 3, 4
- จำนวนรอบ: วนซ้ำทั้งหมด 5 ครั้ง
```

> [!CAUTION]
> **กับดักที่นิสิตชอบผิดในข้อสอบ:**  
> คำสั่ง `range(5)` ในภาษา Python หมายถึง `[0, 1, 2, 3, 4]` **ไม่ใช่ `[1, 2, 3, 4, 5]` เด็ดขาด!**

## 📝 ส่วนที่ 3: Insertion Sort & "Position Move" ละเอียด ("Short note Insertion sort.pdf")

### 🇬🇧 ซอร์สโค้ดและหลักการทำงานของฟังก์ชัน:
```python
def insertion_sort(a):     
    for p in range(1, len(a)): 
        tmp = a[p] 
        j = p 
        while j > 0 and tmp < a[j - 1]: 
            a[j] = a[j - 1] 
            j -= 1 
        a[j] = tmp 

my_list = [34, 8, 64, 51, 32, 21] 
insertion_sort(my_list) 
print("Result   :", my_list)
```

### 📖 คำอธิบายบรรทัดสำคัญจาก Short Note ของอาจารย์:
- `j = p`: กำหนดตัวแปร `j` ให้มีค่าเท่ากับ `p` เพื่อใช้เป็นตัวชี้ในการเปรียบเทียบและเลื่อนตำแหน่ง
- `while j > 0 and tmp < a[j - 1]:` **นี่คือหัวใจของการแทรก**
  - `j > 0`: เงื่อนไขนี้ทำให้แน่ใจว่าเราไม่ได้พยายามเข้าถึง index ที่น้อยกว่า 0 (ซึ่งไม่มีในลิสต์)
  - `tmp < a[j - 1]`: เปรียบเทียบค่าของสมาชิกที่เรากำลังจะแทรก (`tmp`) กับสมาชิกที่อยู่ก่อนหน้า (`a[j - 1]`)
  - **ถ้าทั้งสองเงื่อนไขเป็นจริง:** หมายความว่า `tmp` มีค่าน้อยกว่าสมาชิกที่อยู่ก่อนหน้า ดังนั้นสมาชิกตัวก่อนหน้า (`a[j - 1]`) ต้องถูก **เลื่อนไปทางขวาหนึ่งตำแหน่ง** เพื่อเปิดทางให้ `tmp`
  - `a[j] = a[j - 1]`: เลื่อนสมาชิก `a[j - 1]` ไปยังตำแหน่ง `a[j]` (นำค่าทางขวามาใส่ทางซ้าย) $\rightarrow$ **นับเป็น 1 Position Move!**
  - `j -= 1`: ลดค่า `j` ลง 1 เพื่อขยับไปเปรียบเทียบกับสมาชิกตัวถัดไปทางซ้าย
- เมื่อเงื่อนไขใน while เป็นเท็จ (คือ `j == 0` หรือ `tmp >= a[j - 1]`): แสดงว่าเจอตำแหน่งที่เหมาะสมแล้ว จึงนำค่า `tmp` ไปใส่ไว้ที่ตำแหน่ง `j` ด้วยคำสั่ง `a[j] = tmp`

---

### 🔍 ตาราง Tracing นับ Position Move บนชุดข้อมูล `[34, 8, 64, 51, 32, 21]`:

| Pass ($p$) | ค่า `tmp` | การทำงานในลูป while | จำนวน Position Move | สภาพ Array หลังจบ Pass |
| :---: | :---: | :--- | :---: | :--- |
| **Pass 1** ($p=1$) | $8$ | $j=1$: $1 > 0$ และ $8 < 34$ (จริง) $\to a[1] = a[0] = 34$, $j=0$ (หลุดลูป) $\to a[0]=8$ | **1 ครั้ง** | `[8, 34, 64, 51, 32, 21]` |
| **Pass 2** ($p=2$) | $64$ | $j=2$: $2 > 0$ แต่ $64 < 34$ (เท็จ) $\to$ หลุดลูปทันที $\to a[2]=64$ | **0 ครั้ง** | `[8, 34, 64, 51, 32, 21]` |
| **Pass 3** ($p=3$) | $51$ | $j=3$: $3 > 0$ และ $51 < 64$ (จริง) $\to a[3] = a[2] = 64$, $j=2$ $\to 51 < 34$ (เท็จ) หลุดลูป $\to a[2]=51$ | **1 ครั้ง** | `[8, 34, 51, 64, 32, 21]` |
| **Pass 4** ($p=4$) | $32$ | $j=4$: $32 < 64$ (เลื่อน 64), $j=3$: $32 < 51$ (เลื่อน 51), $j=2$: $32 < 34$ (เลื่อน 34), $j=1$: $32 < 8$ (เท็จ) $\to a[1]=32$ | **3 ครั้ง** | `[8, 32, 34, 51, 64, 21]` |
| **Pass 5** ($p=5$) | $21$ | $j=5$: เลื่อน 64, $j=4$: เลื่อน 51, $j=3$: เลื่อน 34, $j=2$: เลื่อน 32, $j=1$: $21 < 8$ (เท็จ) $\to a[1]=21$ | **4 ครั้ง** | `[8, 21, 32, 34, 51, 64]` |

**🎯 ผลรวม Position Moves ทั้งหมด:**  
$$1 + 0 + 1 + 3 + 4 = \mathbf{9 \text{ ครั้ง}}$$

## 📝 ส่วนที่ 4: Bubble Sort ("For Example Bubble sort.pdf")

### 🇬🇧 ตัวอย่างที่ 1 บนชุดข้อมูล `[5, 1, 4, 2, 8]`:
- **รอบที่ 1:**
  - เปรียบเทียบ 5 กับ 1: $5 > 1 \implies$ สลับตำแหน่งกัน $\to `[1, 5, 4, 2, 8]`$
  - เปรียบเทียบ 5 กับ 4: $5 > 4 \implies$ สลับตำแหน่งกัน $\to `[1, 4, 5, 2, 8]`$
  - เปรียบเทียบ 5 กับ 2: $5 > 2 \implies$ สลับตำแหน่งกัน $\to `[1, 4, 2, 5, 8]`$
  - เปรียบเทียบ 5 กับ 8: $5 < 8 \implies$ ไม่ต้องสลับตำแหน่ง $\to `[1, 4, 2, 5, 8]`$
  - *สิ้นสุดรอบที่ 1: ตัวเลขที่มากที่สุดคือ 8 จะถูก "bubble" ไปอยู่ที่ตำแหน่งสุดท้ายของรายการ*
- **รอบที่ 2:**
  - เปรียบเทียบ 1 กับ 4: $1 < 4$ ไม่สลับ
  - เปรียบเทียบ 4 กับ 2: $4 > 2$ สลับ $\to `[1, 2, 4, 5, 8]`$
  - เปรียบเทียบ 4 กับ 5: $4 < 5$ ไม่สลับ
  - เปรียบเทียบ 5 กับ 8: ไม่จำเป็นต้องเปรียบเทียบแล้ว เพราะ 8 อยู่ในตำแหน่งที่ถูกต้อง
  - *สิ้นสุดรอบที่ 2: ตัวเลข 5 จะถูก "bubble" ไปอยู่ในตำแหน่งรองสุดท้าย*
- **รอบที่ 3:**
  - เปรียบเทียบ 1 กับ 2: ไม่สลับ, เปรียบเทียบ 2 กับ 4: ไม่สลับ, เปรียบเทียบ 4 กับ 5: ไม่สลับ
  - *สิ้นสุดรอบที่ 3: ไม่มีการสลับเกิดขึ้นเลย แสดงว่ารายการถูกเรียงลำดับเสร็จสมบูรณ์แล้ว!*
