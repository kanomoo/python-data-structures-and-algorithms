## 📝 ส่วนที่ 1: โจทย์ภาษาอังกฤษต้นฉบับ For Example 1 (Empty Queue Trace)

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับ:
```text
For example 1:
If the initial queue with size=5 is empty and do with the following instructions:
enqueue(5), enqueue(10), dequeue(), enqueue(15), dequeue().
What value will remain on the queue?

Answer: [15]
```

### 🔍 ขั้นตอนการ Trace ทีละคำสั่ง:
1. `myqueue = Queue(5)` $\implies$ คิวว่าง `[]`, `count = 0`
2. `enqueue(5)` $\implies$ คิวเป็น `[5]`
3. `enqueue(10)` $\implies$ คิวเป็น `[5, 10]`
4. `dequeue()` $\implies$ ดึง **5** ออก (FIFO: ตัวแรกสุดหลุดออก) $\to$ คิวเหลือ `[10]`
5. `enqueue(15)` $\implies$ คิวเป็น `[10, 15]`
6. `dequeue()` $\implies$ ดึง **10** ออก $\to$ คิวเหลือ **`[15]`**

## 📝 ส่วนที่ 2: โจทย์ภาษาอังกฤษต้นฉบับ For Example 2 (Existing Queue Trace)

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับ:
```text
For example 2:
If the exist queue with size=5 contains the numbers [20, 30, 40],
and do with the following instructions:
dequeue(), enqueue(50), dequeue(), enqueue(60).
What value will remain on the queue?

Answer: [40, 50, 60]
```

### 🔍 ขั้นตอนการ Trace:
1. สถานะเริ่มต้น: `[20, 30, 40]` (Front คือ 20, Rear คือ 40)
2. `dequeue()` $\implies$ ดึง **20** ออก $\to$ เหลือ `[30, 40]`
3. `enqueue(50)` $\implies$ เพิ่ม 50 ต่อท้าย $\to$ กลายเป็น `[30, 40, 50]`
4. `dequeue()` $\implies$ ดึง **30** ออก $\to$ เหลือ `[40, 50]`
5. `enqueue(60)` $\implies$ เพิ่ม 60 ต่อท้าย $\to$ กลายเป็น **`[40, 50, 60]`**

```text
For example 3:
```

### 🛑 การวิเคราะห์จุดตัดคะแนนของอาจารย์ประดิษฐ์:
- **ในกรณี Example 3 (ไม่มีตัวแปรมาก่อน):**
  ```python
  myqueue = Queue(5)   # ต้องสร้าง Instance ใหม่
  for i in range(1, 6):
      myqueue.enqueue(i)

  ```
- **ในกรณี Example 3.1 (มี Instance `myqueue` อยู่แล้ว):**

  ```python
  myqueue.enqueue(...)
  myqueue.dequeue(...)
  ```

## 📝 ส่วนที่ 4: วงรอบ Circular Queue และเลขคณิตโมดุโล (Modulo Arithmetic)

### ⚠️ ปัญหา False Overflow:
ในคิวแถวตรง เมื่อ `rear` เดินไปชนขอบขวา (`capacity - 1`) แม้ด้านหน้าจะถูก `dequeue()` ออกไปจนว่างแล้ว โปรแกรมก็จะฟ้องว่าคิวเต็ม (Overflow)

### 🔄 สูตร Circular Queue:
วนตำแหน่งกลับมาที่ Index 0 ด้วยสูตร:
$$\text{rear} = (\text{rear} + 1) \bmod \text{capacity}$$
$$\text{front} = (\text{front} + 1) \bmod \text{capacity}$$
