## 📝 ส่วนที่ 1: โจทย์ภาษาอังกฤษต้นฉบับ For Example 1 (Empty Stack Trace)

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับ:
```text
For example 1:
If the initial stack with size=5 is empty and the numbers 5, 10, 15, 20 
are pushed in that order and popped 4 times, then 25, 30, 35 are pushed 
in that order and popped 2 times, what value will remain on the stack?

Answer: [25]
```

### 🔍 ขั้นตอนการ Trace ทีละขั้นตอน:
| ขั้นตอน | คำสั่งที่สั่ง | ข้อมูลที่ส่ง | สภาพ Stack (ก้น $\to$ ยอด) | คำอธิบายพฤติกรรม LIFO |
| :---: | :---| :---: | :--- | :---|
| 0 | เริ่มต้น | — | `[]` | สแต็กว่างเปล่า (`top = -1`) |
| 1 | `push(5)` | 5 | `[5]` | 5 อยู่ก้นสแต็ก |
| 2 | `push(10)` | 10 | `[5, 10]` | |
| 3 | `push(15)` | 15 | `[5, 10, 15]` | |
| 4 | `push(20)` | 20 | `[5, 10, 15, 20]` | 20 อยู่บนยอด (`top = 20`) |
| 5 | `pop()` | — | `[5, 10, 15]` | ดึง 20 ออก |
| 6 | `pop()` | — | `[5, 10]` | ดึง 15 ออก |
| 7 | `pop()` | — | `[5]` | ดึง 10 ออก |
| 8 | `pop()` | — | `[]` | ดึง 5 ออก $\implies$ ว่างเปล่า |
| 9 | `push(25)` | 25 | `[25]` | 25 เป็นก้นใหม่ |
| 10 | `push(30)` | 30 | `[25, 30]` | |
| 11 | `push(35)` | 35 | `[25, 30, 35]` | 35 อยู่บนยอด |
| 12 | `pop()` | — | `[25, 30]` | ดึง 35 ออก |
| 13 | `pop()` | — | **`[25]`** | ดึง 30 ออก |

**คำตอบสุดท้าย:** สมาชิกที่เหลืออยู่ใน Stack คือ **`[25]`**

---

## 📝 ส่วนที่ 2: โจทย์ภาษาอังกฤษต้นฉบับ For Example 2 (Existing Stack Trace)

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับ:
```text
For example 2:
If the initial stack with size=5 contains the numbers [10, 20, 30, 40], 
and is popped twice, then pushed 50, 60 in that order, then popped 3 times, 
what value will remain on the stack?

Answer: [10]
```

### 🔍 ขั้นตอนการ Trace:
1. สถานะเริ่มต้น: `[10, 20, 30, 40]` (ตัวบนสุด Top คือ 40)
2. `pop()` ครั้งที่ 1: ดึง **40** ออก $\to$ เหลือ `[10, 20, 30]`
3. `pop()` ครั้งที่ 2: ดึง **30** ออก $\to$ เหลือ `[10, 20]`
4. `push(50)`: เพิ่ม 50 $\to$ กลายเป็น `[10, 20, 50]`
5. `push(60)`: เพิ่ม 60 $\to$ กลายเป็น `[10, 20, 50, 60]`
6. `pop()` ครั้งที่ 3: ดึง **60** ออก $\to$ เหลือ `[10, 20, 50]`
7. `pop()` ครั้งที่ 4: ดึง **50** ออก $\to$ เหลือ `[10, 20]`
8. `pop()` ครั้งที่ 5: ดึง **20** ออก $\to$ เหลือ **`[10]`**

**คำตอบสุดท้าย:** สมาชิกที่เหลืออยู่ใน Stack คือ **`[10]`**

## 📝 ส่วนที่ 3: โจทย์ภาษาอังกฤษต้นฉบับ For Example 3 vs 3.1 (กับดักคะแนนศูนย์!)

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับ:
```text
For example 3:
If there is no stack's instance variable before, write statements in main 
program to create the instance variable mystack with size=5. 
Then push the number 1, 2, 3, 4, 5 in that order, and pop 3 times by 
using class Stack's methods that we learned. 
Finally write the element that remain on the stack's instance variable mystack.

Is Different from:

For example 3.1:
If there is the exist stack's instance variable mystack with size=5 
contains the numbers [10, 20, 30, 40] ...
```

### 🛑 การวิเคราะห์จุดตัดคะแนนของอาจารย์ประดิษฐ์:
- **ในกรณี Example 3 (ไม่มีตัวแปรมาก่อน):**
  ```python
  mystack = Stack(5)   # ต้องประกาศตัวแปรออบเจกต์ใหม่
  for i in range(1, 6):
      mystack.push(i)
  for _ in range(3):
      mystack.pop()
  print(mystack.items) # ผลลัพธ์เหลือ [1, 2]
  ```
- **ในกรณี Example 3.1 (มี Instance `mystack` อยู่แล้ว):**
  ```python
  # ห้ามเขียน: mystack = Stack(5)  <- ได้ 0 คะแนนทันที!
  # เพราะจะทำให้ข้อมูล [10, 20, 30, 40] เดิมถูกสร้างทับจนหายไปหมด
  mystack.pop()
  mystack.push(...)
  ```

## 📝 ส่วนที่ 4: การแปลงนิพจน์ Infix เป็น Postfix (Shunting-Yard Algorithm)

### 🇬🇧 นิพจน์เป้าหมาย:
$$(a + (b \times c)) + (((d \times e) + f) \times g)$$

### 🔍 ตาราง Shunting-Yard Trace ทีละโทเคน:

| โทเคน | ประเภท | การดำเนินการบน Stack | สภาพ Stack (ก้น $\to$ ยอด) | Output Postfix String |
| :---: | :---: | :---| :---| :---|
| `(` | วงเล็บเปิด | Push ลง Stack | `['(']` | ` ` |
| `a` | ตัวถูกดำเนินการ | ส่งออก Output | `['(']` | `a` |
| `+` | ตัวดำเนินการ | Push ลง Stack | `['(', '+']` | `a` |
| `(` | วงเล็บเปิด | Push ลง Stack | `['(', '+', '(']` | `a` |
| `b` | ตัวถูกดำเนินการ | ส่งออก Output | `['(', '+', '(']` | `a b` |
| `*` | ตัวดำเนินการ | Push ลง Stack | `['(', '+', '(', '*']` | `a b` |
| `c` | ตัวถูกดำเนินการ | ส่งออก Output | `['(', '+', '(', '*']` | `a b c` |
| `)` | วงเล็บปิด | Pop จนเจอ `(` | `['(', '+']` | `a b c *` |
| `)` | วงเล็บปิด | Pop จนเจอ `(` | `[]` | `a b c * +` |
| `+` | ตัวดำเนินการ | Push ลง Stack | `['+']` | `a b c * +` |
| `(` | วงเล็บเปิด | Push | `['+', '(']` | `a b c * +` |
| `(` | วงเล็บเปิด | Push | `['+', '(', '(']` | `a b c * +` |
| `(` | วงเล็บเปิด | Push | `['+', '(', '(', '(']` | `a b c * +` |
| `d` | ตัวถูกดำเนินการ | ส่งออก Output | `['+', '(', '(', '(']` | `a b c * + d` |
| `*` | ตัวดำเนินการ | Push | `['+', '(', '(', '(', '*']` | `a b c * + d` |
| `e` | ตัวถูกดำเนินการ | ส่งออก Output | `['+', '(', '(', '(', '*']` | `a b c * + d e` |
| `)` | วงเล็บปิด | Pop จนเจอ `(` | `['+', '(', '(']` | `a b c * + d e *` |
| `+` | ตัวดำเนินการ | Push | `['+', '(', '(', '+']` | `a b c * + d e *` |
| `f` | ตัวถูกดำเนินการ | ส่งออก Output | `['+', '(', '(', '+']` | `a b c * + d e * f` |
| `)` | วงเล็บปิด | Pop จนเจอ `(` | `['+', '(']` | `a b c * + d e * f +` |
| `*` | ตัวดำเนินการ | Push | `['+', '(', '*']` | `a b c * + d e * f +` |
| `g` | ตัวถูกดำเนินการ | ส่งออก Output | `['+', '(', '*']` | `a b c * + d e * f + g` |
| `)` | วงเล็บปิด | Pop จนเจอ `(` | `['+']` | `a b c * + d e * f + g *` |
| *End* | สิ้นสุดนิพจน์ | Pop ที่เหลือทั้งหมด | `[]` | **`a b c * + d e * f + g * +`** |
