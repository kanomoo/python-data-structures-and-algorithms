## 🎯 วัตถุประสงค์ของชุดตัวอย่างในห้องเรียนนี้
อาจารย์ประดิษฐ์ใช้เอกสาร `Topological sort.pdf` และ `For Example Graph.pdf` เพื่อเน้นย้ำความแม่นยำใน 5 ประเด็นสำคัญ:
1. **กฎการเขียน Path**: กฎเหล็กที่อาจารย์ย้ำซ้ำๆ ทั้งใน Tree และ Graph คือ **"ใช้เครื่องหมายจุลภาค (Comma) ห้ามใส่ลูกศร `->` เด็ดขาด มิฉะนั้นได้ 0 คะแนน"**
2. **ความหมายของคำว่า Adjacent และ Connect**:
   - $F \text{ adjacent to } E$ แปลว่ามีคู่ลำดับ $(E, F)$
   - คำว่า **Connect** ในวิชานี้แปลว่า **"ต่อเนื่อง" ไม่ใช่ "ต่อเชื่อม"**
3. **การคำนวณ Memory Waste ของ Adjacency Matrix**: การพิสูจน์ว่าทำไม Matrix ถึงสิ้นเปลืองและต้องใช้ Adjacency List
4. **กระบวนการคำนวณ Topological Sort ด้วย Indegree Table และ Queue**
5. **การไล่ตาราง Unweighted Shortest Path (BFS) พร้อมกับดักการหาเส้นทางที่เป็นไปไม่ได้ ($\infty$)**

## 📝 ส่วนที่ 1: กฎเหล็กการเขียน Path และนิยามพื้นฐาน (Lecture 10)

### 📌 ตัวอย่างที่ 1.1: กราฟไม่มีทิศทาง (Undirected Graph)
- กำหนดเซตของจุดยอดและเส้นเชื่อม:
  $$V = \{A, B, C, D\}$$
  $$E = \{(A, B), (B, C), (C, D), (D, A)\}$$
- **คำถามในสไลด์**: จงเขียน path จาก vertex $A$ ไป vertex $D$
- **คำตอบที่ถูกต้อง**:
  $$\mathbf{A, B, C, D}$$
- ⚠️ **คำเตือนจากอาจารย์บนกระดาน (Verbatim)**:
  > *"อย่าเขียน $A \rightarrow B \rightarrow C \rightarrow D$ เด็ดขาด ได้ 0 คะแนน!"*

### 📌 ตัวอย่างที่ 1.2: กราฟมีทิศทาง (Directed Graph)
- กำหนดเซตของจุดยอดและเส้นเชื่อม:
  $$V = \{E, F, G, H\}$$
  $$E = \{(E, F), (F, G), (G, H), (H, E), (F, E)\}$$
- **นิยาม Adjacent**:
  - $F \text{ adjacent to } E$ เพราะมีคู่อันดับ $(E, F)$ ชี้จาก $E$ ไปหา $F$
  - แต่ $E$ **ไม่ได้ adjacent** กับ $F$ สำหรับเส้นทางแรก เพราะไม่มีคู่อันดับชี้ตรงไปหากัน (จนกระทั่งเพิ่ม $(F, E)$)
- **คำถามในสไลด์**: จงเขียนเส้นทาง (path) จากจุด $E$ ไป $G$
- **คำตอบที่ถูกต้อง**:
  $$\mathbf{E, F, G}$$
  *(ห้ามเขียน $E \rightarrow F \rightarrow G$ ได้ 0 คะแนน)*

### 📌 ตัวอย่างที่ 1.3: สูตร Complete Graph
- กราฟสมบูรณ์ (Complete Graph) ที่ทุกคู่จุดยอดมีเส้นเชื่อมถึงกัน:
  $$\text{Edges} = \frac{N(N - 1)}{2}$$
  - $N=2$ จุดยอด $\implies \frac{2(1)}{2} = 1$ เส้น
  - $N=3$ จุดยอด $\implies \frac{3(2)}{2} = 3$ เส้น
  - $N=4$ จุดยอด $\implies \frac{4(3)}{2} = 6$ เส้น
  - $N=5$ จุดยอด $\implies \frac{5(4)}{2} = 10$ เส้น
- **โจทย์ข้อสอบ**: Complete Graph ที่มี 10 vertex ถามว่ามี edge กี่เส้น?
  $$\text{Edges} = \frac{10(10 - 1)}{2} = \frac{10 \times 9}{2} = \mathbf{45\text{ เส้น}}$$

## 📝 ส่วนที่ 2: Representation of Graph & การคำนวณ Memory Waste

### 📌 สไลด์ Adjacency Matrix $7 \times 7$ (จาก For Example Graph.pdf หน้า 1)

```
Adjacency Matrix
u \ v |  1  2  3  4  5  6  7
------+---------------------
  1   |  0  1  1  1  0  0  0
  2   |  0  0  0  1  1  0  0
  3   |  0  0  0  0  0  1  0
  4   |  0  0  1  0  0  1  1
  5   |  0  0  0  1  0  0  1
  6   |  0  0  0  0  0  0  0
  7   |  0  0  0  0  0  1  0
```

### 📌 Verbatim English Problem Statement
> **"Adjacency Matrix ไม่นิยมใช้ เพราะเปลืองเนื้อที่ในหน่วยความจำ**
> 
> - 49 ช่อง มีช่องที่เป็น 1 อยู่ 12 ช่อง
> - 100 ช่อง มีช่องที่เป็น 1 อยู่ = $(12 / 49) \times 100 = \mathbf{24.48\%}$
> - มีช่องที่เป็น 0 หรือไม่ได้ใช้งาน อยู่ = $(37 / 49) \times 100 = \mathbf{75.52\%}$
> 
> **What percentage of the memory space is used for entries with a value of 1, and what percentage is used for entries with a value of 0?"**

### 🔍 ขั้นตอนการคำนวณและสรุปผล
1. **ขนาดตารางทั้งหมด**: $|V|^2 = 7 \times 7 = 49\text{ ช่อง}$
2. **จำนวนช่องที่มีเส้นเชื่อม (ค่าเป็น 1)**:
   - แถว 1: 3 ช่อง $(v_2, v_3, v_4)$
   - แถว 2: 2 ช่อง $(v_4, v_5)$
   - แถว 3: 1 ช่อง $(v_6)$
   - แถว 4: 3 ช่อง $(v_3, v_6, v_7)$
   - แถว 5: 2 ช่อง $(v_4, v_7)$
   - แถว 6: 0 ช่อง
   - แถว 7: 1 ช่อง $(v_6)$
   - **รวมทั้งหมด**: $3 + 2 + 1 + 3 + 2 + 0 + 1 = \mathbf{12\text{ ช่อง}}$
3. **จำนวนช่องที่ว่างเปล่า (ค่าเป็น 0)**:
   $$49 - 12 = \mathbf{37\text{ ช่อง}}$$
4. **คำนวณร้อยละ (Percentage)**:
   - **Used Memory (Value 1)**: $\frac{12}{49} \times 100\% = \mathbf{24.48\%}$
   - **Wasted Memory (Value 0)**: $\frac{37}{49} \times 100\% = \mathbf{75.52\%}$

- $v_2 \longrightarrow [4, 5]$
- $v_3 \longrightarrow [6]$
- $v_4 \longrightarrow [3, 6, 7]$
- $v_5 \longrightarrow [4, 7]$
- $v_6 \longrightarrow []$ (ไม่มีเส้นเชื่อมออก)

### 📌 ขั้นที่ 2: ตาราง Indegree Array & Queue Tracing
**Indegree** คือจำนวน edge ที่ชี้พุ่งเข้าหาจุดยอดนั้นๆ:

| Vertex ($v$) | Indegree เริ่มต้น | รอบที่ 1 (Pop 1) | รอบที่ 2 (Pop 2) | รอบที่ 3 (Pop 5) | รอบที่ 4 (Pop 4) | รอบที่ 5 (Pop 3) | รอบที่ 6 (Pop 7) | รอบที่ 7 (Pop 6) |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **1** | **0** | - | - | - | - | - | - | - |
| **2** | **1** | **0** | - | - | - | - | - | - |
| **3** | **2** | 1 | 1 | 1 | **0** | - | - | - |
| **4** | **3** | 2 | 1 | **0** | - | - | - | - |
| **5** | **1** | 1 | **0** | - | - | - | - | - |
| **6** | **3** | 3 | 3 | 3 | 2 | 1 | **0** | - |
| **7** | **2** | 2 | 2 | 1 | **0** | 0 | - | - |
| **Queue ($q$)** | `[1]` | `[2]` | `[5]` | `[4]` | `[3, 7]` | `[7]` | `[6]` | `[]` |

> 
> **After computing the topological sort, write down the topological ordering that is the solution for this graph."**
> 
> **Official Answer:**
> $$\mathbf{1, 2, 5, 4, 3, 7, 6}$$
> *(หรือหากคิวในรอบที่ 4 เก็บ 7 ก่อน 3 จะได้ลำดับ: $1, 2, 5, 4, 7, 3, 6$)*

### 📌 โค้ดมาตรฐานในสไลด์ (Page 4 Verbatim Algorithm)
```python
if w.dist == INFINITY:
    w.dist = v.dist + 1

```

### 📌 โจทย์คำถามจริงจาก For Example Graph.pdf หน้า 5

#### ❓ ข้อสอบคำถามที่ 1: จาก Vertex 3 ไป Vertex 5
> **"จงหาเส้นทางที่สั้นที่สุด จาก $v_3$ ไป $v_5$ จากตารางที่คำนวณได้ และ ความยาวของเส้นทางนั้น เท่ากับเท่าไร**
> 
> **After computing the shortest path, write down the length of the shortest path and the shortest path from Vertex 3 to Vertex 5 from the calculated table."**

**เฉลยและการวิเคราะห์:**
หากเราเริ่มต้นที่ $v_3$ ($v_{\text{start}} = 3$):
- $d(v_3) = 0$, Enqueue($v_3$)
- Dequeue($v_3$): ดูเพื่อนบ้านของ $v_3$ $\implies$ มีเพียง $v_6$ ตัวเดียว!
  - $d(v_6) = 0 + 1 = 1$, $p(v_6) = v_3$, Enqueue($v_6$)
- Dequeue($v_6$): เพื่อนบ้านของ $v_6$ เป็นเซตว่าง ($\emptyset$) ไม่มีทางออกต่อ
- คิวว่าง! จุดยอด $v_1, v_2, v_4, v_5, v_7$ ไม่เคยถูกเข้าถึงเลยและค่า `dist` ยังคงเป็น $\infty$!

> **Official Answer เขียนตอบอาจารย์:**
> - **The length of the shortest path from Vertex 3 to Vertex 5 = $\infty$ (No path exists / ไม่มีเส้นทางเชื่อมถึง)**
> - **The shortest path from Vertex 3 to Vertex 5 = None (ไม่มีเส้นทาง)**

#### ❓ ข้อสอบคำถามที่ 2: จาก Vertex 3 ไป Vertex 7

**เฉลยและการวิเคราะห์:**

> **Official Answer เขียนตอบอาจารย์:**
> - **The length of the shortest path from Vertex 3 to Vertex 7 = $\infty$ (No path exists / ไม่มีเส้นทางเชื่อมถึง)**
> - **The shortest path from Vertex 3 to Vertex 7 = None (ไม่มีเส้นทาง)**

#### ❓ ข้อสอบคำถามที่ 3: เส้นทางจาก Vertex 4 ไป Vertex 5 ("v4 ไป v5")
จาก $v_4$ เส้นเชื่อมออกมีไปยัง $v_3, v_6, v_7$:
- $v_3 \to v_6$
- $v_7 \to v_6$
- ทุกเส้นทางวิ่งไปสิ้นสุดที่ $v_6$ (Dead End) ไม่มีเส้นทางเชื่อมกลับไปหา $v_5$ เช่นกัน!
- **ระยะทาง = $\infty$ (No path exists)**
