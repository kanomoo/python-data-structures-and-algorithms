1. **ความเข้าใจในฟังก์ชัน `add()`**: การแทรกหัวลิสต์ (Insert at Beginning) สลับลำดับข้อมูลหากใส่ตามลำดับ
2. **การต่อยอด Linked List เดิม**: ห้าม new ออบเจกต์ใหม่ทับของเดิมเด็ดขาด
3. **การสลับพอยน์เตอร์ (Pointer Manipulation)**: ลำดับการย้ายเส้นเชื่อม `next` โดยไม่ทำโหนดอื่นหลุดหาย (Dangling/Lost Node)

## 📝 ตัวอย่างที่ 1: การสร้าง Linked List เรียง 1 ถึง 5 (No Instance Before)

### 📌 Original English Problem Statement (Verbatim จากสไลด์อาจารย์ หน้า 1)
> **"For example: if there is no list's instance variable before, write statements in main program to create the instance variable mylist with ordered inputs are 1, 2, 3, 4, 5 and has result outputs are 1, 2, 3, 4, 5 by using class LinkedList's methods that we learned.**
> 
> *First of all, I suggest you to use pencil or pen to underline or circle the important parts of Question, ask yourself,*
> 1. *What is the question want to do?*
> 2. *What are inputs and what are outputs?*"
> 
> *(ฉบับ New-Lectures 169: "For example: If no list instance has been created, write statements in the main program to create a mylist instance with ordered inputs 1, 2, 3, 4, and 5. Ensure the resulting output is 1, 2, 3, 4, 5 by using the LinkedList class methods we have learned.")*

### ❌ The Wrong Solution (ข้อผิดพลาดที่นักศึกษาทำผิดจนได้ 0 คะแนน)
นักศึกษาส่วนใหญ่มักจะเขียนแบบนี้:
```python
# The wrong solution is:
mylist = LinkedList()
mylist.add(1)
mylist.add(2)
mylist.add(3)
mylist.add(4)
mylist.add(5)
```

> [!CAUTION]
> **Why is it wrong? (ทำไมเขียนแบบนี้ถึงได้ 0 คะแนน?):**
> เมธอด `add(item)` ในเอกสารคำสอนของคลาส `LinkedList` ที่เรียน คือ **การแทรกที่หัวลิสต์ (Insert at Beginning / Prepend)**
> - `add(1)` $\to$ `[1]`
> - `add(2)` $\to$ `[2] -> [1]`
> - `add(3)` $\to$ `[3] -> [2] -> [1]`
> - `add(4)` $\to$ `[4] -> [3] -> [2] -> [1]`
> - `add(5)` $\to$ `[5] -> [4] -> [3] -> [2] -> [1]`
> 
> ผลลัพธ์ที่ได้จริงจากการพิมพ์หรือท่องลิสต์คือ **`5 -> 4 -> 3 -> 2 -> 1`** (Descending / Reverse Order) ซึ่งขัดกับโจทย์ที่สั่งอย่างชัดเจนว่า *"has result outputs are 1, 2, 3, 4, 5"*!

### ✅ The Right Solution (เฉลยที่ถูกต้องตามเอกสารอาจารย์)
มี 2 แนวทางที่ถูกต้องในการเขียนตอบ:

#### วิธีที่ 1: สลับลำดับการเรียก `add()` ย้อนหลังจากมากไปน้อย (Reverse Input Order)
```python
mylist = LinkedList()
mylist.add(5)
mylist.add(4)
mylist.add(3)
mylist.add(2)
mylist.add(1)
# เมื่อแทรก 1 เข้าหัวสุด ผลลัพธ์ที่ได้คือ: 1 -> 2 -> 3 -> 4 -> 5
```

#### วิธีที่ 2: ใช้ `add(1)` เริ่มต้น แล้วตามด้วย `insert(pos, item)` หรือ `append(item)`
```python
mylist = LinkedList()
mylist.add(1)           # ตำแหน่งที่ 0 คือ 1
mylist.insert(1, 2)     # แทรก 2 ต่อท้าย 1 (index 1)
mylist.insert(2, 3)     # แทรก 3 (index 2)
mylist.insert(3, 4)     # แทรก 4 (index 3)
mylist.insert(4, 5)     # แทรก 5 (index 4)
# ผลลัพธ์: 1 -> 2 -> 3 -> 4 -> 5
```

## 📝 ตัวอย่างที่ 2: กำหนดโหนดเริ่มต้น [3] ห้ามสร้าง LinkedList ใหม่! (Exist Instance Variable)

### 📌 Original English Problem Statement (Verbatim จากสไลด์อาจารย์ หน้า 2)
> **"For example: if there is the exist list's instance variable mylist which has one input 3 already, write statements in main program to create the instance variable mylist with ordered inputs are 1, 2, 4, 5 and has result outputs are 1, 2, 3, 4, 5 by using class LinkedList's methods that we learned.**
> 
> *The solution is:*
> - `mylist = LinkedList()` $\to$ **$\times$ no need to create a new instance variable (ห้ามสร้างใหม่เด็ดขาด! ถ้าเขียนบรรทัดนี้ได้ 0 คะแนนทันที)**
> - `mylist.add(1)` $\to$ **$\checkmark$ (ใส่ 1 ที่หัวได้)**
> - `mylist.add(2)` $\to$ **$\times$ not use add method (ห้ามใช้ add(2) เพราะจะกลายเป็น 2 -> 1 -> 3)**"
> 
> *(ฉบับ New-Lectures 169: "For example: If an instance of mylist already exists containing the value 3, write statements in main program to create the instance variable mylist with ordered inputs are 1, 2, 4, 5 and has result outputs are 1, 2, 3, 4, 5 by using class LinkedList's methods that we learned.")*

### 🔍 การวิเคราะห์สถานะและความผิดพลาด
สถานะเริ่มต้นในหน่วยความจำ:
$$\text{head} \longrightarrow [3] \longrightarrow \text{None}$$

หากนักศึกษาเผลอเขียน:
1. `mylist = LinkedList()` $\implies$ **พอยน์เตอร์เดิมที่ชี้ `[3]` จะขาดหาย กลายเป็นลิสต์ว่างใหม่ (Lost Reference / Memory Leak)**
2. ถ้าใช้ `mylist.add(2)` ต่อจาก `add(1)` $\implies$ ลิสต์จะกลายเป็น `[2] -> [1] -> [3]` ซึ่งผิดลำดับ

### ✅ คำตอบที่ถูกต้อง (The Right Solution)
ต้องใช้การรวมกันระหว่าง `add()` หรือ `insert()` เพื่อคงลำดับ `1, 2, 3, 4, 5`:

```python
# สถานะเริ่มต้น: mylist มีโหนด [3] อยู่แล้ว ห้ามพิมพ์ mylist = LinkedList() เด็ดขาด!
mylist.add(1)        # แทรก 1 ที่หัว: [1] -> [3]
mylist.insert(1, 2)  # แทรก 2 ที่ตำแหน่ง index 1 (ระหว่าง 1 กับ 3): [1] -> [2] -> [3]
mylist.insert(3, 4)  # แทรก 4 ต่อท้าย 3 (index 3): [1] -> [2] -> [3] -> [4]
mylist.insert(4, 5)  # แทรก 5 ต่อท้าย 4 (index 4): [1] -> [2] -> [3] -> [4] -> [5]
# หรือหากมีเมธอด append(): mylist.append(4); mylist.append(5)
```

## 📝 ตัวอย่างที่ 2.3: ปัญหาการสลับพอยน์เตอร์ 4 โหนด (Pointer Swapping)

### 📌 โจทย์คำถามจากหน้า 3 ของเอกสาร
> มีโหนด 5 โหนดเชื่อมต่อกันอยู่เดิม:
> `node1 -> node2 -> node3 -> node4 -> node5`
> 
> จงเขียนคำสั่งเพื่อปรับโครงสร้างให้กลายเป็น:
> `node1 -> node4 -> node3 -> node2 -> node5`

### 🔍 การวิเคราะห์การเปลี่ยนแปลง
- โหนดที่ไม่เปลี่ยนตำแหน่ง: `node1` (หัว) และ `node5` (ท้าย)
- โหนดที่มีการสลับ: `node2`, `node3`, `node4` กลับลำดับเป็น `node4 -> node3 -> node2`
- เส้นเชื่อมที่ต้องเปลี่ยน:
  1. `node1.next` ต้องชี้ไปที่ `node4` (เดิมชี้ `node2`)
  2. `node4.next` ต้องชี้ไปที่ `node3` (เดิมชี้ `node5`)
  3. `node3.next` ต้องชี้ไปที่ `node2` (เดิมชี้ `node4`)
  4. `node2.next` ต้องชี้ไปที่ `node5` (เดิมชี้ `node3`)

### ⚠️ ลำดับการสลับพอยน์เตอร์เพื่อไม่ให้เกิดโหนดหลุดหาย
หากทำผิดลำดับ เช่น แก้ `node1.next = node4` แล้ว `node4.next = node3` ก่อนบันทึกหรือต่อท้าย จะทำให้ลิสต์ขาดตอน!

**คำตอบที่อาจารย์กำหนดในเฉลย**:
```python
node2.next = node5   # ขั้นที่ 1: ให้ node2 ชี้ไปที่ node5 ก่อน
node3.next = node2   # ขั้นที่ 2: ให้ node3 ชี้กลับมาที่ node2
node4.next = node3   # ขั้นที่ 3: ให้ node4 ชี้มาที่ node3
node1.next = node4   # ขั้นที่ 4: ปรับหัวลิสต์ node1 ให้ชี้ไปที่ node4 เป็นตัวแรก
```

```
[ก่อนสลับ]
node1 ──► node2 ──► node3 ──► node4 ──► node5

[หลังคำสั่ง node2.next = node5]
node1 ──► node2 ──────────────────────► node5
          node3 ──► node4 ──► node5

[หลังคำสั่ง node3.next = node2]
node1 ──► node2 ──────────────────────► node5
            ▲
node3 ──────┘
node4 ──► node5

[หลังคำสั่ง node4.next = node3]
node4 ──► node3 ──► node2 ──► node5

[หลังคำสั่ง node1.next = node4]
node1 ──► node4 ──► node3 ──► node2 ──► node5  (เสร็จสมบูรณ์!)
```
