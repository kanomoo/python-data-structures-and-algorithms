## 📝 ส่วนที่ 1: โจทย์ต้นฉบับภาษาอังกฤษ For Example 5.1: Insert 5

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับจากเอกสารแจก (Page 1):
```text
"Example for Binary Search Tree: Insert
For example 5.1: if there is the exist BinarySearchTree's instance variable name bst 
contains the numbers [1, 2, 3, 4, 6, 8] (In-order traversal) as the image following:

Write the steps for the _insert_recursive() function when insert 5 into the instance variable bst. 
In each round, consists of:
1) what are the values of the parameters value and current_node of the _insert_recursive() function, and
2) what statements are executed under the if-else condition that is checked as true.
Each iteration must write 2 things."
```

### 💻 คำสั่งใน Main Program:
```python
bst = BinarySearchTree()
# สมมติมีการ insert โหนด [6, 2, 8, 1, 4, 3] เข้ามาก่อนหน้าแล้ว
bst.insert(5)
```

### 🔍 เฉลยละเอียดสองภาษา (Bilingual Step-by-step Trace):
- **First round (รอบที่ 1):**
  - `value = 5`, `current_node = Node(6)`
  - เงื่อนไข `value < current_node.value` ($5 < 6$) เป็นจริง
  - ประโยคคำสั่งที่ทำงาน:  
    `self._insert_recursive(current_node.left, value)`
- **Round 2 (รอบที่ 2):**
  - `value = 5`, `current_node = Node(2)`
  - เงื่อนไข `value > current_node.value` ($5 > 2$) เป็นจริง
  - ประโยคคำสั่งที่ทำงาน:  
    `self._insert_recursive(current_node.right, value)`
- **Round 3 (รอบที่ 3):**
  - `value = 5`, `current_node = Node(4)`
  - เงื่อนไข `value > current_node.value` ($5 > 4$) เป็นจริง
  - ตรวจสอบ `if current_node.right is None:` เป็นจริง (True)
  - ประโยคคำสั่งที่ทำงาน:  
    `current_node.right = Node(value)` (นำ 5 ไปสร้างโหนดใหม่ผูกเป็นลูกขวาของ 4)
- **Round 4 (รอบที่ 4 - Return & Unwind):**
  - `value = 5`, `current_node = None`
  - คืนค่ากลับออกจาก Recursion Call Stack จนครบทุกชั้น

## 📝 ส่วนที่ 2: โจทย์ต้นฉบับภาษาอังกฤษ For Example 5.2: Remove (4) One Child

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับจากเอกสารแจก (Page 4):
```text
"Example for Binary Search Tree: Remove (4), one child.
For example 5.2: if there is the exist BinarySearchTree's instance variable name bst 
contains the numbers [1, 2, 3, 4, 6, 8] (In-order traversal) as the image following:

Write the steps for the _delete_recursive() function when remove 4 from the instance variable bst. 
In each round, consists of:
1) what are the values of the parameters value and current_node of the _delete_recursive() function, and
2) what statements are executed under the if-else condition that is checked as true.
Each iteration must write 2 things."
```

### 🔍 เฉลยละเอียดสองภาษา (Bilingual Step-by-step Trace):
- **First round (รอบที่ 1):**
  - `value = 4`, `current_node = Node(6)`
  - เงื่อนไข `value < current_node.value` ($4 < 6$) เป็นจริง
  - ประโยคคำสั่งที่ทำงาน:  
    `current_node.left = self._delete_recursive(current_node.left, value)`
- **Round 2 (รอบที่ 2):**
  - `value = 4`, `current_node = Node(2)`
  - เงื่อนไข `value > current_node.value` ($4 > 2$) เป็นจริง
  - ประโยคคำสั่งที่ทำงาน:  
    `current_node.right = self._delete_recursive(current_node.right, value)`
- **Round 3 (รอบที่ 3 - เจอต้วที่ต้องการลบ):**
  - `value = 4`, `current_node = Node(4)`
  - เงื่อนไข `value == current_node.value` (เข้าสู่ส่วน `else:`)
  - โหนด 4 มีเฉพาะลูกซ้าย (โหนด 3) แต่ไม่มีลูกขวา (`current_node.right is None` เป็นจริง)
  - ประโยคคำสั่งที่ทำงาน:  
    ```python
    elif current_node.right is None:
        return current_node.left
    ```
  - ส่งกลับโหนดลูก (`Node(3)`) ข้ามโหนด 4 ไปผูกติดกับกิ่งขวาของโหนด 2 แทน

## 📝 ส่วนที่ 3: โจทย์ต้นฉบับภาษาอังกฤษ For Example 5.3: Remove (2) Two Children

### 🇬🇧 ข้อความโจทย์ภาษาอังกฤษต้นฉบับจากเอกสารแจก:
```text
"Example for Binary Search Tree: Remove (2), two children.
For example 5.3: if there is the exist BinarySearchTree's instance variable name bst 
contains the elements as the image following:

Write the steps for the _delete_recursive() function when remove 2 from the instance variable bst. 
In each round, consists of:
1) what are the values of the parameters value and current_node of the _delete_recursive() function, and
2) what statements are executed under the if-else condition that is checked as true.
Each iteration must write 2 things."
```

### 🔍 เฉลยละเอียดสองภาษา (Bilingual Step-by-step Trace):
- **First round (รอบที่ 1):**
  - `value = 2`, `current_node = Node(6)`
  - เงื่อนไข `value < current_node.value` ($2 < 6$) เป็นจริง
  - ประโยคคำสั่งที่ทำงาน:  
    `current_node.left = self._delete_recursive(current_node.left, value)`
- **Round 2 (รอบที่ 2 - เจอต้วที่ต้องการลบซึ่งมี 2 ลูก):**
  - `value = 2`, `current_node = Node(2)`
  - เงื่อนไข `value == current_node.value` (เข้าสู่กรณีมี 2 ลูก)
  - ประโยคคำสั่งที่ทำงาน:  
    ```python
    temp_node = self._min_value_node(current_node.right)
    current_node.value = temp_node.value
    current_node.right = self._delete_recursive(current_node.right, temp_node.value)
    ```
- **การทำงานใน `_min_value_node(current_node.right)` เพื่อหา In-order Successor:**
  - โค้ดของอาจารย์บนสไลด์:
    ```python
    def _min_value_node(self, node):
        current = node
        while current.left is not None:
            current = current.left
        return current
    ```
  - วิ่งไปทางซ้ายสุดของ Subtree ด้านขวาจนกระทั่ง `current.left is None`
  - นำค่าต่ำสุดที่พบ (เช่น โหนด 3) มาเขียนทับลงที่ `current_node.value`
  - สั่งลบโหนด 3 ออกจาก Subtree ด้านขวาเพื่อไม่ให้ข้อมูลซ้ำซ้อน
