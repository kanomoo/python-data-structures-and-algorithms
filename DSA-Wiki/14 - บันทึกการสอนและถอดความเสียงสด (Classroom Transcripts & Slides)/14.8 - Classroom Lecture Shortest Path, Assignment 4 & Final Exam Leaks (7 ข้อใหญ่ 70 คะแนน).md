## 📝 3. ขั้นตอนวิธี Unweighted Shortest Path Algorithm (บทที่ 11)

### 3.1 Pseudocode ของขั้นตอนวิธี
```python
def unweighted_shortest_path(graph, start_vertex):
    # กำหนดค่าเริ่มต้น
    for v in graph.vertices:
        v.dist = 999  # infinity
        v.known = False
        v.path = 0
    
    start_vertex.dist = 0
    Q = Queue()
    Q.enqueue(start_vertex)
    
    while not Q.is_empty():
        v = Q.dequeue()
        v.known = True
        
        for w in v.adjacent_vertices:
            if w.dist == 999:  # ยังไม่เคยไปถึง
                w.dist = v.dist + 1
                w.path = v
                Q.enqueue(w)
```

### 3.2 ตัวอย่างการ Trace บนสไลด์หน้า 11-14 (จุดเริ่มต้น $v_3$)
ตารางผลลัพธ์สุดท้ายที่สอดคล้องกับโปรแกรมของอาจารย์:

| Vertex | Known | Dist ($d_v$) | Path ($p_v$) |
| :---: | :---: | :---: | :---: |
| $v_1$ | **T** | **1** | $v_3$ |
| $v_2$ | **T** | **2** | $v_1$ |
| $v_3$ | **T** | **0** | $0$ |
| $v_4$ | **T** | **2** | $v_1$ |
| $v_5$ | **T** | **3** | $v_2$ |
| $v_6$ | **T** | **1** | $v_3$ |
| $v_7$ | **T** | **3** | $v_4$ |

**การหา Shortest Path จาก $v_3$ ไปยัง $v_5$:**
1. ตรวจสอบ $d_v$ ของ $v_5 \rightarrow \mathbf{3}$ (ระยะทาง = 3 ขอบ)
2. Backtrack ย้อนกลับผ่านคอลัมน์ $p_v$:
   - $v_5 \leftarrow v_2$
   - $v_2 \leftarrow v_1$
   - $v_1 \leftarrow v_3$
3. **เส้นทางสั้นสุด:** `v3 -> v1 -> v2 -> v5` (หรือเขียนลำดับ $v_3, v_1, v_2, v_5$)

## 📋 4. เฉลยละเอียด Assignment 4 ฉบับสมบูรณ์ (ส่งจริงในห้องเรียน)

### 4.1 ข้อมูลกราฟในใบงาน
- จุดยอด: $A, B, C, D, E, F, G$ (7 จุดยอด)
- จุดเริ่มต้น: **Vertex A**
- ทิศทางเส้นเชื่อม:
  - $A \to B, C$
  - $B \to G, E, C$
  - $C \to E, D$
  - $D \to F, A$
  - $E \to D, F$
  - $F \to \text{Ground}$
  - $G \to E$

### 4.2 เฉลยข้อ 1: Adjacency List
```text
A -> [ B ] -> [ C ] -||
B -> [ G ] -> [ E ] -> [ C ] -||
C -> [ E ] -> [ D ] -||
D -> [ F ] -> [ A ] -||
E -> [ D ] -> [ F ] -||
F -> -||
G -> [ E ] -||
```

### 4.3 เฉลยข้อ 2: ตารางประมวลผล Shortest Path (เริ่มต้นที่ A)

| Vertex | Known | Dist ($d_v$) | Path ($p_v$) | รอยขีดฆ่าแสดงการเปลี่ยนสถานะ |
| :---: | :---: | :---: | :---: | :--- |
| **A** | **T** | **0** | **0** | $F \to T$, $999 \to 0$ |
| **B** | **T** | **1** | **A** | $F \to T$, $999 \to 1$, $0 \to A$ |
| **C** | **T** | **1** | **A** | $F \to T$, $999 \to 1$, $0 \to A$ |
| **D** | **T** | **2** | **C** | $F \to T$, $999 \to 2$, $0 \to C$ |
| **E** | **T** | **2** | **B** | $F \to T$, $999 \to 2$, $0 \to B$ |
| **F** | **T** | **3** | **E** | $F \to T$, $999 \to 3$, $0 \to E$ (หรือ $D$) |
| **G** | **T** | **2** | **B** | $F \to T$, $999 \to 2$, $0 \to B$ |

- **สถานะของ Queue $Q$ ในแต่ละรอบ:**
  - เริ่มต้น: `[A]`
  - Dequeue A: `[B, C]`
  - Dequeue B: `[C, G, E]`
  - Dequeue C: `[G, E, D]`
  - Dequeue G: `[E, D]`
  - Dequeue E: `[D, F]`
  - Dequeue D: `[F]`
  - Dequeue F: `[]` (สิ้นสุดขั้นตอนวิธี)
