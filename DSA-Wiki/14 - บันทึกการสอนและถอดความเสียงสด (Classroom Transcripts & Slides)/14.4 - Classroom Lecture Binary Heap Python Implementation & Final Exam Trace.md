> *"เปิดดูไฟล์โปรแกรม BinaryHeap.py นะครับ...

## 📥 2. เจาะลึกการแทรกข้อมูล (`insert`) และการลอยตัวขึ้น (Percolate Up)

![สไลด์โจทย์ข้อสอบแทรก 14 ลงใน Heap 10 สมาชิก](assets/dsa-pic/IMG_20260909_094140_669.jpg)

![คำสั่งเรียก insert(14) ในฟังก์ชัน main](assets/dsa-pic/IMG_20260909_094609_602.jpg)

### 2.1 ซอร์สโค้ดเมธอด `insert` จากโปรแกรมจริง
```python
class BinaryHeap:
    def __init__(self, capacity=100):
        self.current_size = 0
        self.array = [None] * (capacity + 1)

    def insert(self, x):
        if self.is_full():
            return
        self.current_size += 1
        hole = self.current_size
        
        # กลไก Percolate Up (ลอยตัวขึ้นสู่ผิวน้ำ)
        while hole > 1 and x < self.array[hole // 2]:
            self.array[hole] = self.array[hole // 2]
            hole //= 2
            
        self.array[hole] = x
```

### 2.3 ตารางการไล่โปรแกรมฉบับสมบูรณ์ (Step-by-step Trace Table)
คำสั่ง: `myHeap.insert(14)`

| ลำดับขั้นตอน / รอบลูป | ค่าของ `hole` | เงื่อนไขใน While Loop | การเปรียบเทียบ ($x < \text{Parent}$) | ผลการตรวจสอบ | การกระทำในรอบลูป (Action) | สถานะ Array หลังจบรอบ |
| :---: | :---: | :---: | :---: | :---: | :--- | :--- |
| **ก่อนเข้าลูป** | `10 + 1 = 11` | - | - | - | ขยาย `current_size = 11`, สร้างช่องว่างที่ `hole = 11` | `array[11]` ว่างเปล่ารอรับค่า |
| **While รอบที่ 1** | `11` | `11 > 1` (True) | $14 < \text{array}[11 // 2] \implies 14 < \text{array}[5] \implies \mathbf{14 < 31}$ | **จริง (True)** | `array[11] = array[5]` (เลื่อน 31 ลงมาที่ช่อง 11)<br>`hole = 11 // 2 = 5` | ช่อง 11 เก็บ 31, หลุมเลื่อนไปช่อง 5 |
| **While รอบที่ 2** | `5` | `5 > 1` (True) | $14 < \text{array}[5 // 2] \implies 14 < \text{array}[2] \implies \mathbf{14 < 21}$ | **จริง (True)** | `array[5] = array[2]` (เลื่อน 21 ลงมาที่ช่อง 5)<br>`hole = 5 // 2 = 2` | ช่อง 5 เก็บ 21, หลุมเลื่อนไปช่อง 2 |
| **While รอบที่ 3** | `2` | `2 > 1` (True) | $14 < \text{array}[2 // 2] \implies 14 < \text{array}[1] \implies \mathbf{14 < 13}$ | **เท็จ (False)** | หลุดออกจาก While Loop ทันที! | หลุมหยุดอยู่ที่ช่อง 2 |
| **หลังออกจากลูป** | `2` | - | - | - | `self.array[hole] = x`<br>$\implies \mathbf{\text{array}[2] = 14}$ | ช่อง 2 บรรจุค่า 14 อย่างสมบูรณ์ |

## 📤 3. เจาะลึกการลบข้อมูลค่าน้อยสุด (`deleteMin`) และการลอยตัวลง (Percolate Down)

![สไลด์นิยามการทำงาน deleteMin](assets/dsa-pic/IMG_20260909_103928_646.jpg)

![สไลด์ซอร์สโค้ด deleteMin และ _percolate_down](assets/dsa-pic/IMG_20260909_110520_920.jpg)

### 3.1 ซอร์สโค้ดเมธอด `deleteMin` และ `_percolate_down`
```python
    def delete_min(self):
        if self.is_empty():
            return None
            
        min_item = self.array[1]                  # 1. บันทึกค่า Root (ค่าน้อยสุด)
        temp = self.array[self.current_size]     # 2. นำค่าโหนดท้ายสุดมาถือไว้ในมือ
        self.current_size -= 1                   # 3. ยุบขนาดอาร์เรย์ลง 1 ตำแหน่ง
        
        self._percolate_down(1, temp)             # 4. ทำการ Percolate Down หลุมที่ราก
        return min_item

    def _percolate_down(self, hole, temp):
        while hole * 2 <= self.current_size:
            child = hole * 2
            # ตรวจสอบว่ามีลูกขวาหรือไม่ และลูกขวามีค่าน้อยกว่าลูกซ้ายหรือไม่
            if child != self.current_size and self.array[child + 1] < self.array[child]:
                child += 1
                
            # ถ้าลูกตัวที่น้อยกว่า มีค่าน้อยกว่า temp ให้ยกก้นลูกขึ้นมาแทนหลุม
            if self.array[child] < temp:
                self.array[hole] = self.array[child]
                hole = child
            else:
                break
                
        self.array[hole] = temp
```

> [!CAUTION]
> **กับดักคะแนน 0 ในห้องสอบ:**  
> เมธอด `deleteMin()` **ไม่มี Parameter** ห้ามเขียน `myHeap.deleteMin(13)` เด็ดขาด! เพราะคอมพิวเตอร์จะค้นหาและดึงค่าที่โหนดรากออกมาให้เองโดยอัตโนมัติ เขียนส่งค่าเข้าไป = ได้ 0 คะแนนทันที!

### 3.2 การจำลองสถานะโจทย์จริง (ทำ `deleteMin` ต่อจากการแทรก 14)

![สไลด์ขั้นตอน deleteMin ตัวแปร temp=31 และ hole=1](assets/dsa-pic/IMG_20260909_110606_048.jpg)

![สไลด์การเลือกลูกตัวที่น้อยกว่าสลับที่](assets/dsa-pic/IMG_20260909_113011_426.jpg)

- ค่าที่ถูกดึงออก: `min_item = array[1] = 13`
- ค่าตัวท้ายสุดที่ต้องหาที่ลง: `temp = array[11] = 31`
- ขนาดยุบลง: `current_size = 11 - 1 = 10`
- ตำแหน่งหลุมเริ่มต้น: `hole = 1`

#### ตารางการไล่โปรแกรม `deleteMin` (Percolate Down Trace Table):

| รอบลูป | ค่า `hole` | ลูกซ้าย (`child`) | ตรวจสอบลูกขวา (`child+1 < child`) | ลูกตัวที่เลือก (`child`) | เปรียบเทียบกับ `temp=31` (`array[child] < 31`) | การกระทำในรอบลูป | ตำแหน่ง `hole` ใหม่ |
| :---: | :---: | :---: | :---: | :---: | :---: | :--- | :---: |
| **รอบที่ 1** | `1` | `2` (ค่า 14) | `array[3]=16 < array[2]=14` (เท็จ) | `child = 2` (ค่า 14) | $14 < 31$ **(จริง)** | `array[1] = array[2] = 14`<br>เลื่อน 14 ขึ้นแทนราก | `hole = 2` |
| **รอบที่ 2** | `2` | `4` (ค่า 24) | `array[5]=21 < array[4]=24` **(จริง)** | `child = 4 + 1 = 5` (ค่า 21) | $21 < 31$ **(จริง)** | `array[2] = array[5] = 21`<br>เลื่อน 21 ขึ้นแทนหลุม | `hole = 5` |
| **รอบที่ 3** | `5` | `10` (ค่า 32) | `child == current_size` (ไม่มีลูกขวา) | `child = 10` (ค่า 32) | $32 < 31$ **(เท็จ!)** | เข้าเงื่อนไข `else: break`<br>**หยุดลูปทันที!** | `hole = 5` |

- จบลูป: นำ `temp` ใส่ลงในหลุม `self.array[5] = 31`
- ส่งคืนค่า `13`
