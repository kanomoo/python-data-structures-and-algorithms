## 🏛️ 2. นิยามทางคณิตศาสตร์และจุดตัด 0 คะแนนในข้อสอบ

### 2.1 นิยามของกราฟ (Graph Definition)
$$G = (V, E)$$
- $V$ (Vertices / Nodes): เซตของจุดยอด $V = \{v_1, v_2, \dots, v_n\}$
- $E$ (Edges): เซตของเส้นเชื่อม $E = \{e_1, e_2, \dots, e_m\}$ โดยที่ $e_i = (u, v)$ ซึ่ง $u, v \in V$
- **Undirected Graph:** เส้นเชื่อมไม่มีลูกศร $(u, v) = (v, u)$
- **Directed Graph (Digraph):** เส้นเชื่อมมีทิศทาง $(u, v) \ne (v, u)$ ชี้จาก $u \to v$

### 2.2 นิยามคำว่า Adjacent (ประชิด)
- จุดยอด $w$ อยู่ติดกับ $v$ ($w$ is adjacent to $v$) ก็ต่อเมื่อมีเส้นเชื่อม $(v, w) \in E$
- ใน Digraph: หากมีเส้นเชื่อม $A \to B$ กล่าวได้ว่า $B$ adjacent to $A$ แต่ **ห้ามกล่าวว่า $A$ adjacent to $B$**

---

### ⚠️ กับดักข้อสอบที่ 1: กฎเหล็กการเขียน Path (ได้ 0 คะแนนทันทีหากใช้ลูกศร)

![ตัวอย่าง Path บนกระดาน](assets/dsa-pic/IMG_20260923_101115_542@-1909020087.jpg)

> [!CAUTION]
> **คำเตือนจากคำพูดอาจารย์ประดิษฐ์ในห้องเรียน:**
> *"นักศึกษาฟังให้ดีนะครับ... เวลาโจทย์ถามว่าจงเขียน Path จาก Vertex $A$ ไปยัง Vertex $C$  
> รุ่นพี่คุณชอบเขียนแบบนี้: `A -> B -> C`  
> **ผมให้ 0 คะแนนทันทีนะครับ! ไม่ตรวจต่อเลย!**  
> เพราะนิยามของ Path ในทางคณิตศาสตร์ คือ **Sequence of vertices** (ลำดับของจุดยอด)  
> คุณต้องตอบเป็นลำดับคั่นด้วยเครื่องหมายจุลภาคเท่านั้น คือ:  
> **`A, B, C`** หรือ **`(A, B, C)`** จำไว้ให้ขึ้นใจ!"*

| รูปแบบคำตอบ | ผลการตรวจข้อสอบ | เหตุผลทางวิชาการ |
| :--- | :---: | :--- |
| `A -> B -> C` หรือ `A → B → C` | ❌ **0 คะแนน** | ละเมิดนิยาม Sequence of vertices |
| **`A, B, C`** หรือ **`(A, B, C)`** | ✅ **คะแนนเต็ม 100%** | ถูกต้องตามนิยาม Tuple/Sequence ใน Discrete Math |

---

### ⚠️ กับดักข้อสอบที่ 2: หน่วยของความยาวเส้นทาง (Length of Path)
- **นิยาม:** จำนวนเส้นเชื่อมที่อยู่บน Path (The number of edges on the path)
- หากมีจุดยอด $N$ จุดยอด $\implies \text{Length} = N - 1$
- ❌ **คำตอบที่ได้ 0 คะแนน:** ตอบเป็นหน่วยวัดความยาว เช่น "2 นิ้ว", "5 ซม."
- ✅ **คำตอบที่ถูกต้อง:** ตอบเป็นจำนวนเส้นเชื่อม เช่น **`2`** หรือ **`2 เส้น`**

![กราฟว่างบนกระดานดำ](assets/dsa-pic/IMG_20260923_103736_910@1714137841.jpg)

> **โจทย์ข้อสอบลวง:** กำหนดกราฟว่าง $V = \{\}, E = \{\}$ จงเขียน Path จากจุด $A$ ไปยังจุด $C$  
> - ❌ คำตอบที่ผิด: ตอบว่า `A, C` หรือขีดละไว้
> - ✅ **คำตอบที่ได้คะแนนเต็ม:** **"ไม่มี Path จาก $A$ ไปยัง $C$ เนื่องจากไม่มีจุดยอด $A$ และไม่มีจุดยอด $C$ อยู่ในกราฟนี้"**

## 🎯 3. ข้อสอบรั่วสูตรลัด Complete Graph: $V=10 \implies 45$ เส้น

![Complete Graph บนกระดานคำนวณ 45 เส้น](assets/dsa-pic/IMG_20260923_104814_788@-1807977296.jpg)

### 3.1 สูตรคำนวณจำนวนเส้นใน Complete Graph (Undirected)
$$E = \frac{V(V - 1)}{2}$$

### 3.2 ข้อสอบปลายภาคจริงที่อาจารย์เผยในห้อง:
> **โจทย์:** กำหนดให้ Undirected Complete Graph มีจุดยอดจำนวน 10 จุด ($V = 10$) จงหาว่ากราฟนี้จะมีเส้นเชื่อมทั้งหมดกี่เส้น?  
>  
> **วิธีคำนวณ:**  
> $$E = \frac{10 \times (10 - 1)}{2} = \frac{10 \times 9}{2} = \frac{90}{2} = \mathbf{45}$$  
>  
> **⚠️ ข้อควรระวังในการตอบ:**  
> - **ต้องตอบเลขจำนวนเต็ม `45` หรือ `45 เส้น` เท่านั้น!**  
> - หากตอบติดสูตร เช่น `10*(10-1)/2` หรือ `90/2` **อาจารย์จะหักจนเหลือ 0 คะแนน!**

## 📊 4. โครงสร้าง Adjacency Matrix vs Adjacency List & การคำนวณ Memory Waste

### 4.1 Adjacency Matrix (เมทริกซ์ประชิด)

![ตาราง Adjacency Matrix 7x7 บนจอ](assets/dsa-pic/IMG_20260923_110059_773@1901326602.jpg)
![การคำนวณเปอร์เซ็นต์ Memory Waste 24.48% และ 75.51%](assets/dsa-pic/IMG_20260923_110522_696@1035849451.jpg)

- **โครงสร้าง:** 2D Array ขนาด $|V| \times |V|$
- กราฟตัวอย่างในคาบเรียนมี **7 Vertices ($|V|=7$)** และ **12 Edges ($|E|=12$)**
- ตารางมีขนาด $7 \times 7 = \mathbf{49\text{ ช่อง}}$

#### ตาราง Adjacency Matrix จากภาพกระดานจริง:

| $u \setminus v$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | เส้นเชื่อมที่ออกจาก $u$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **1** | 0 | 1 | 1 | 1 | 0 | 0 | 0 | $(1,2), (1,3), (1,4)$ |
| **2** | 0 | 0 | 0 | 1 | 1 | 0 | 0 | $(2,4), (2,5)$ |
| **3** | 0 | 0 | 0 | 0 | 0 | 1 | 0 | $(3,6)$ |
| **4** | 0 | 0 | 1 | 0 | 0 | 1 | 1 | $(4,3), (4,6), (4,7)$ |
| **5** | 0 | 0 | 0 | 1 | 0 | 0 | 1 | $(5,4), (5,7)$ |
| **6** | 0 | 0 | 0 | 0 | 0 | 0 | 0 | (ไม่มีเส้นออก) |
| **7** | 0 | 0 | 0 | 0 | 0 | 1 | 0 | $(7,6)$ |

#### 📝 ข้อสอบภาษาอังกฤษคำนวณ Memory Waste (Verbatim จากกระดาน `IMG_20260923_110522`):
> **Exam Question:**  
> *"What percentage of the memory space is used for entries with a value of 1, and what percentage is used for entries with a value of 0?"*  
>  
> **การคำนวณ:**  
> - จำนวนช่องทั้งหมด: $7 \times 7 = 49$ ช่อง  
> - ช่องที่มีค่า 1 (แทนเส้นเชื่อม 12 เส้น):  
>   $$\text{Percentage (Value 1)} = \frac{12 \times 100}{49} = \mathbf{24.48\%}$$  
> - ช่องที่มีค่า 0 (สูญเปล่า / ไม่ได้ใช้งาน): $49 - 12 = 37$ ช่อง  
>   $$\text{Percentage (Value 0)} = \frac{37 \times 100}{49} = 100 - 24.48 = \mathbf{75.51\%}$$  
>  
> **บทวิเคราะห์ของอาจารย์:** *"Adjacency Matrix ไม่เป็นที่นิยมในโลกความจริง เพราะสูญเสียพื้นที่หน่วยความจำไปถึง 75.51% ให้กับเลข 0 สำหรับ Sparse Graph"*

### 4.2 Adjacency List (รายการประชิด)

![สไลด์ Adjacency List และโจทย์ 10 Vertices 20 Edges](assets/dsa-pic/IMG_20260923_113450_494@173595678.jpg)
![สไลด์เปรียบเทียบขนาด Matrix vs List](assets/dsa-pic/IMG_20260923_113807_477@-1558442029.jpg)

- **โครงสร้าง:** 1D Array ขนาด $|V|$ แต่ละช่องเก็บหัว Linked List ชี้ไปยังโหนดเพื่อนบ้าน
- **ขนาดพื้นที่หน่วยความจำ:** $\text{Space} = O(|V| + |E|)$
- **สำหรับกราฟตัวอย่างเดิม (|V| = 7, |E| = 12):**  
  Array 7 ช่อง + โหนด Linked List 12 โหนด $= 7 + 12 = \mathbf{19\text{ ช่อง}}$ (ประหยัดกว่า Matrix ที่ใช้ 49 ช่องถึง **61.22%**)

#### แผนผัง Adjacency List ของกราฟ 7 จุดยอด:
```text
[1] -> 2 -> 3 -> 4 -> NULL
[2] -> 4 -> 5 -> NULL
[3] -> 6 -> NULL
[4] -> 3 -> 6 -> 7 -> NULL
[5] -> 4 -> 7 -> NULL
[6] -> NULL
[7] -> 6 -> NULL
```

---

### 4.3 ข้อสอบเปรียบเทียบ Matrix vs List จากกระดาน `IMG_20260923_113450`

> **โจทย์ข้อสอบ:** กำหนด Directed Graph มี 10 จุดยอด ($|V|=10$) และมี 20 เส้นเชื่อม ($|E|=20$)  
> 1. การแทนด้วย Adjacency Matrix ต้องใช้พื้นที่กี่ช่อง?  
>    **ตอบ:** $|V|^2 = 10^2 = \mathbf{100\text{ ช่อง}}$  
> 2. การแทนด้วย Adjacency List ต้องใช้พื้นที่กี่ช่อง?  
>    **ตอบ:** $|E| + |V| = 20 + 10 = \mathbf{30\text{ ช่อง}}$  
> 3. Adjacency List ประหยัดหน่วยความจำได้กี่เปอร์เซ็นต์?  
>    **ตอบ:** $\frac{100 - 30}{100} \times 100 = \mathbf{70.0\%}$
