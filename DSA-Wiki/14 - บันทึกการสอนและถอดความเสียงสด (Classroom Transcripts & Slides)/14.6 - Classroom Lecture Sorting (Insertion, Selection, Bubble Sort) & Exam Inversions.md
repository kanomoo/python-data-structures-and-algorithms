## 📥 1. เจาะลึก Insertion Sort & ตาราง Position Move

![สไลด์ตาราง Insertion Sort Trace](assets/dsa-pic/IMG_20260916_094820_819@893369530.jpg)

### 1.1 หัวใจสำคัญของ Insertion Sort
1. เริ่มต้นลูปนอกที่รอบ $p = 1$ ถึง $p = N - 1$ (ไม่เริ่มที่ 0)
2. กำหนด `temp = a[p]`
3. เปรียบเทียบย้อนหลังไปทางซ้ายมือ ($j - 1$) ถ้าตัวซ้ายมากกว่า `temp` ให้ขยับตัวซ้ายมาทางขวา 1 ตำแหน่ง ($a[j] = a[j-1]$) นับเป็น **Position Move 1 ครั้ง**
4. เมื่อเจอตำแหน่งที่ถูกต้อง นำ `temp` เสียบกลับลงไป ($a[j] = temp$)

### 1.2 ตาราง Trace ละเอียดบนอาร์เรย์ `[34, 8, 64, 51, 32, 21]`

| รอบ ($p$) | ค่า `temp` | การเปรียบเทียบย้อนหลัง (ซ้ายมือ) | การเลื่อนตำแหน่ง (Moves) | Position Move ในรอบนี้ | สถานะ Array หลังจบรอบ (After $p$) |
| :---: | :---: | :--- | :--- | :---: | :--- |
| **Original** | - | - | - | - | `[34, 8, 64, 51, 32, 21]` |
| **After $p=1$** | **8** | $8 < 34 \implies$ True | เลื่อน 34 มาแทนที่ 8, วาง 8 ที่ Index 0 | **1** | `[8, 34, 64, 51, 32, 21]` |
| **After $p=2$** | **64** | $64 < 34 \implies$ False<br>$64 < 8 \implies$ False | ไม่มีการเลื่อนตำแหน่ง | **0** | `[8, 34, 64, 51, 32, 21]` |
| **After $p=3$** | **51** | $51 < 64 \implies$ True<br>$51 < 34 \implies$ False | เลื่อน 64 มาแทนที่ 51, วาง 51 ที่ Index 2 | **1** | `[8, 34, 51, 64, 32, 21]` |
| **After $p=4$** | **32** | $32 < 64$ (True) $\implies 32 < 51$ (True)<br>$\implies 32 < 34$ (True) $\implies 32 < 8$ (False) | เลื่อน 64 $\to$ เลื่อน 51 $\to$ เลื่อน 34,<br>วาง 32 ที่ Index 1 | **3** | `[8, 32, 34, 51, 64, 21]` |
| **After $p=5$** | **21** | $21 < 64, 51, 34, 32$ (True ทุกตัว)<br>$21 < 8$ (False) | เลื่อน 64 $\to$ เลื่อน 51 $\to$ เลื่อน 34 $\to$ เลื่อน 32,<br>วาง 21 ที่ Index 1 | **4** | `[8, 21, 32, 34, 51, 64]` |

> [!IMPORTANT]
> **ผลรวม Position Move ทั้งหมด:** $1 + 0 + 1 + 3 + 4 = \mathbf{9} \text{ ครั้ง}$

![บันทึกกระดานโจทย์ Worst Case 64, 51, 34, 32, 21, 8](assets/dsa-pic/IMG_20260916_095816_275@-1897800400.jpg)

### คำถอดความจากเสียงบรรยายสดของอาจารย์:
> *"Best Case คือกรณีที่ดีที่สุด ข้อมูลบังเอิญเรียงมาพอดี เช่น `8, 21, 32, 34, 51, 64` ไม่เกิด Position Move เลย ตอบ 0 ครั้ง!  
> ส่วน Worst Case คือข้อมูลเรียงกลับทิศทาง `64, 51, 34, 32, 21, 8` เกิด Position Move รวมทั้งสิ้นกี่ครั้ง?

> คนที่มองอนุกรมออก 1 นาทีก็ตอบได้ แต่คนที่ไม่รู้นั่งไล่โปรแกรมทีละรอบเสียเวลาเป็นชั่วโมงนะครับ วงเอาไว้เลย Worst Case เนี่ยอาจารย์ชอบถาม!"*

## 🔍 3. Selection Sort & กับดักข้อสอบ `range(0)` ใน Python

### 3.1 กลไกการทำงานของ Selection Sort
แบ่งอาร์เรย์เป็น **Sorted Part** (ทางซ้าย) และ **Unsorted Part** (ทางขวา) ในแต่ละรอบ:
1. ค้นหาค่าที่น้อยที่สุดใน Unsorted Part (`min_idx`)
2. นำค่าที่ `min_idx` มา **Swap** กับสมาชิกตัวแรกของ Unsorted Part
3. ทำซ้ำ $N - 1$ รอบ

### 3.2 ตาราง Trace บนอาร์เรย์ `[64, 25, 12, 22, 11]`
- **Pass 0 ($i=0$):** `min_idx = 4` (ค่า 11) $\to$ Swap(64, 11) $\to$ `[11, 25, 12, 22, 64]` (Sorted: `[11]`)
- **Pass 1 ($i=1$):** `min_idx = 2` (ค่า 12) $\to$ Swap(25, 12) $\to$ `[11, 12, 25, 22, 64]` (Sorted: `[11, 12]`)
- **Pass 2 ($i=2$):** `min_idx = 3` (ค่า 22) $\to$ Swap(25, 22) $\to$ `[11, 12, 22, 25, 64]` (Sorted: `[11, 12, 22]`)
- **Pass 3 ($i=3$):** `min_idx = 3` (ค่า 25) $\to$ Swap(25, 25) $\to$ `[11, 12, 22, 25, 64]` (เสร็จสิ้นสมบูรณ์)

### 3.3 กับดักข้อสอบ: `range(0)` vs `[]`
> *"คำถามข้อสอบถามว่า `range(0)` มีค่าเป็น `None` หรือ `[0]` ใช่หรือไม่?  
> คำตอบคือ **ไม่ใช่ทั้งคู่!** `range(0)` คือ **Empty Sequence**  
> ในเชิงหน่วยความจำ `[]` จะจองพื้นที่หน่วยความจำสำหรับ List Object แต่ `range(0)` เป็น Range Object ที่เก็บเพียง Metadata 3 ตัว (`start=0, stop=0, step=1`) ไม่ได้จองหน่วยความจำเพื่อเก็บตัวเลข"*

## 🫧 4. Bubble Sort & เคล็ดลับการหา Total Swaps ด้วย Inversion

### 4.1 กลไกการลอยตัว
- เปรียบเทียบตัวเลขทีละคู่ที่ติดกัน ($a[j], a[j+1]$) จากซ้ายไปขวา
- ถ้าตัวซ้ายมากกว่าตัวขวา ให้ทำการสลับที่ (Swap)
- ตัวเลขที่มากที่สุดจะค่อยๆ ลอยขึ้นไปอยู่ขวาสุดของแต่ละรอบเสมอ
- จำนวนรอบ (Passes / Outer loop) $= N - 1$ เสมอ

### 4.2 เคล็ดลับขั้นเทพ Inversion Counting
> [!TIP]
> **ทฤษฎี Inversion ใน Bubble Sort:**
> **"การ Swap ใน Bubble Sort 1 ครั้ง จะกำจัด Inversion (คู่ลำดับที่ผิด) ไปได้ 1 คู่พอดีเสมอ"**  
> ดังนั้น **Total Swaps ทั้งหมด = ผลรวมของจำนวนตัวเลขทางขวามือที่น้อยกว่าตัวมันเอง**
