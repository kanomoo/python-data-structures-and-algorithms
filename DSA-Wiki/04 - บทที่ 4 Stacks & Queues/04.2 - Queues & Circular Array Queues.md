## 🏛️ 1. ปัญหาของ List-based Queue vs ทางออก Circular Array

### 1.1 ทำไม `list.pop(0)` จึงเป็นกับดักประสิทธิภาพ ($O(N)$)
ในภาษา Python หากสร้าง Queue ด้วย List แบบง่าย:
```python
# กับดักข้อสอบ: อย่าใช้ pop(0) สำหรับ High Performance Queue!
queue = []
queue.append(10)  # enqueue: O(1) Amortized
val = queue.pop(0)  # dequeue: O(N) เพราะต้องเลื่อนทุก Element ที่เหลือไปทางซ้าย 1 ช่อง!
```
- เมื่อมีข้อมูล 1,000,000 ตัว การ `pop(0)` จะต้องสั่งเลื่อนข้อมูลใน Memory ถึง **999,999 ครั้ง**!
- หากใช้ตัวแปร `front` และ `rear` บน Array คงที่โดยไม่วนรอบ เมื่อ `dequeue` บ่อยๆ ค่า `front` จะเลื่อนไปทางขวาเรื่อยๆ จนหลุดขอบ แม้ข้างหน้าจะว่างกลายเป็น **False Overflow**

### 1.2 ทางออก: Circular Array Queue ($O(1)$ แท้จริง)
เรามอง Array ขนาดคงที่ $M$ ให้ปลายชนต้นเป็นวงกลม โดยใช้คณิตศาสตร์เศษเหลือ (**Modulo Arithmetic `%`**) ทำให้ทั้ง `enqueue` และ `dequeue` ทำงานได้ในเวลา **$O(1)$ เสมอโดยไม่ต้องเลื่อนข้อมูลแม้แต่ตัวเดียว!**

## 🔄 2. สูตรคณิตศาสตร์ Modulo ประจำบท (ออกสอบ 100%)

ให้ $M = \text{capacity}$ (ขนาดของอาร์เรย์):
$$\text{rear}_{\text{new}} = (\text{rear} + 1) \pmod M$$
$$\text{front}_{\text{new}} = (\text{front} + 1) \pmod M$$

### การจัดการ Full และ Empty State
มี 2 แนวทางที่พบบ่อยในข้อสอบ:
1. **ใช้ตัวแปร `current_size` นับจำนวนข้อมูลจริง (วิธีที่แนะนำและเข้าใจง่ายที่สุด - ตรงตาม `Exams/Queue.py`)**:
   - $\text{isEmpty} \iff \text{current\_size} == 0$
   - $\text{isFull} \iff \text{current\_size} == \text{capacity}$
   - ใช้พื้นที่ได้ครบทุกช่อง $100\%$
2. **วิธีสังเกตตำแหน่ง Pointer โดยไม่ใช้ตัวนับ (ยอมเสียพื้นที่ 1 ช่อง)**:
   - $\text{isEmpty} \iff \text{front} == \text{rear}$
   - $\text{isFull} \iff (\text{rear} + 1) \pmod M == \text{front}$

## 📊 3. ตาราง Trace การทำงานจริง (Step-by-Step Simulation)

สมมติกำหนดคิวมีขนาด `capacity = 5`, เริ่มต้น `front = 0`, `rear = 0`, `current_size = 0`, Array = `[None, None, None, None, None]`

| ลำดับที่ | Operation | ค่าที่จัดการ | Array ภายใน `[0, 1, 2, 3, 4]` | `front` | `rear` | `size` | คำอธิบายสเต็ป |
| :---: | :--- | :---: | :--- | :---: | :---: | :---: | :--- |
| 0 | เริ่มต้น | - | `[None, None, None, None, None]` | 0 | 0 | 0 | คิวว่าง |
| 1 | `enqueue(20)` | 20 | `[20, None, None, None, None]` | 0 | 1 | 1 | ใส่ที่ index 0, rear = $(0+1)\%5 = 1$ |
| 2 | `enqueue(30)` | 30 | `[20, 30, None, None, None]` | 0 | 2 | 2 | ใส่ที่ index 1, rear = $(1+1)\%5 = 2$ |
| 3 | `enqueue(40)` | 40 | `[20, 30, 40, None, None]` | 0 | 3 | 3 | ใส่ที่ index 2, rear = $(2+1)\%5 = 3$ |
| 4 | `dequeue()` | คืน 20 | `[None, 30, 40, None, None]` | 1 | 3 | 2 | ดึงจาก index 0, front = $(0+1)\%5 = 1$ |
| 5 | `enqueue(50)` | 50 | `[None, 30, 40, 50, None]` | 1 | 4 | 3 | ใส่ที่ index 3, rear = $(3+1)\%5 = 4$ |
| 6 | `enqueue(60)` | 60 | `[None, 30, 40, 50, 60]` | 1 | 0 | 4 | **วนรอบ!** ใส่ที่ 4, rear = $(4+1)\%5 = 0$ |
| 7 | `dequeue()` | คืน 30 | `[None, None, 40, 50, 60]` | 2 | 0 | 3 | ดึงจาก index 1, front = $(1+1)\%5 = 2$ |
| 8 | `enqueue(70)` | 70 | `[70, None, 40, 50, 60]` | 2 | 1 | 4 | ใส่ที่ index 0 (วนกลับมาหัวอาร์เรย์!), rear = 1 |

> [!TIP]
> **จุดสังเกต**: ในแถวที่ 6 และ 8 ค่า `rear` วนกลับมาที่ `0` และ `1` ทำให้ช่องที่ถูกปล่อยว่างจากการ `dequeue` ถูกนำกลับมาใช้วนซ้ำได้อย่างคุ้มค่า ไม่สูญเสียพื้นที่แม้แต่นิดเดียว!

## 💻 4. โค้ดมาตรฐานระดับข้อสอบ (Runnable Python Implementation)

โค้ดนี้จำลองโครงสร้างเดียวกับข้อสอบ `Exams/Queue.py` คุณสามารถกด **▶ รันโค้ดทันที** เพื่อดูผลลัพธ์:

```python
class CircularQueue:
    def __init__(self, capacity: int):
        self.the_array = [None] * capacity
        self.capacity = capacity
        self.current_size = 0
        self.front = 0
        self.back = 0  # rear index สำหรับใส่ข้อมูลตัวถัดไป

    def is_empty(self) -> bool:
        return self.current_size == 0

    def is_full(self) -> bool:
        return self.current_size == self.capacity

    def _increment(self, index: int) -> int:
        """ขยับ index ไปข้างหน้าทีละ 1 หากถึงขนาดความจุให้วนกลับมาที่ 0"""
        index += 1
        if index == self.capacity:
            index = 0
        return index

    def enqueue(self, item) -> bool:
        if self.is_full():
            print(f"❌ Queue is Overflow! Cannot enqueue {item}")
            return False
        self.the_array[self.back] = item
        self.back = self._increment(self.back)
        self.current_size += 1
        print(f"📥 Enqueued: {item:2d} | Front={self.front}, Back={self.back}, Size={self.current_size}")
        return True

    def dequeue(self):
        if self.is_empty():
            print("❌ Queue is Underflow! Cannot dequeue")
            return None
        item = self.the_array[self.front]
        self.the_array[self.front] = None  # ล้างหน่วยความจำ
        self.front = self._increment(self.front)
        self.current_size -= 1
        print(f"📤 Dequeued: {item:2d} | Front={self.front}, Back={self.back}, Size={self.current_size}")
        return item

    def print_queue(self):
        print(f"👉 Current Queue items (Total {self.current_size}): [", end="")
        curr = self.front
        for i in range(self.current_size):
            end_char = ", " if i < self.current_size - 1 else ""
            print(f"{self.the_array[curr]}", end=end_char)
            curr = self._increment(curr)
        print(f"] | Raw Buffer: {self.the_array}")


if __name__ == "__main__":
    q = CircularQueue(capacity=5)
    print("--- 1. Enqueue ข้อมูล 3 ตัว ---")
    q.enqueue(20)
    q.enqueue(30)
    q.enqueue(40)
    q.print_queue()

    print("\n--- 2. Dequeue 1 ตัวแล้ว Enqueue เพิ่มจนวนรอบ ---")
    q.dequeue()
    q.enqueue(50)
    q.enqueue(60)
    q.print_queue()

    print("\n--- 3. Enqueue ตัวที่วนกลับมาที่ Index 0 ---")
    q.enqueue(70)
    q.print_queue()
```

## 🎯 5. สรุปความซับซ้อน (Time & Space Complexity)

| การทำงาน (Operation) | List-based Queue | Circular Array Queue | Linked List Queue |
| :--- | :---: | :---: | :---: |
| `enqueue(x)` | $O(1)$ amortized | **$O(1)$** | **$O(1)$** |
| `dequeue()` | $O(N)$ (เลื่อนทั้งแถว) | **$O(1)$** | **$O(1)$** |
| `front()` / `peek()` | $O(1)$ | **$O(1)$** | **$O(1)$** |
| Memory Overhead | ปานกลาง (Dynamic array) | **ต่ำที่สุด (คงที่)** | สูงกว่า (มี Next Pointer) |

### 💻 7.4 โค้ดส่งงานจริงในคาบเรียน (Test Program 1_ Queue)

```python
# โค้ดมาตรฐานที่ส่งอาจารย์ในห้องเรียน (จัดการ Overflow & Underflow สมบูรณ์)
class Queue:
    def __init__(self, limit):
        self.items = []
        self.limit = limit
        self.front = 0
        self.rear = -1
        self.size = 0
        
    def isEmpty(self):
        return len(self.items) <= 0
    
    def enQueue(self, item):
        if len(self.items) >= self.limit:
            print("Queue is overflow, Cannot enqueue", item)
        else: 
            self.items.append(item)
            self.rear += 1
            self.size += 1
    
    def deQueue(self):
        if self.isEmpty():
            print("Queue is underflow")
            return None
        else: 
            val = self.items.pop(0)
            self.size = self.size - 1
            self.rear = self.size - 1
            return val
    
    def printqueue(self):
        for i in range(self.size):
            print(self.items[i], end=' ')
        print()
```
