# 📑 06.4 - Queue Practice Exam Problems & Solutions (ชุดโจทย์ Queue สไตล์ข้อสอบจริง)

> [!IMPORTANT] **กฎเหล็กสำหรับการทำข้อสอบ Queue (ตามหลักการของอาจารย์):**
> 1. **ห้ามเข้าถึง Private Attributes หรือ Index ภายในตรงๆ** (เช่น ห้ามใช้ `q.item[0]` หรือ `q[1]` เด็ดขาด)
> 2. **ต้องใช้เฉพาะ Method ของคลาส `Queue` ที่เรียนเท่านั้น:** `enQueue(item)`, `deQueue()`, `isEmpty()`, `size()`, `front()`
> 3. **หากต้องใช้โครงสร้างข้อมูลเสริม** ให้ใช้ `Stack` (`push()`, `pop()`, `top()`, `is_empty()`) หรือตัวแปรชั่วคราว (Temporary Variable) เท่านั้น ห้ามพึ่งพา List/Array ของ Python
> 4. **กำหนดตอนเริ่มต้นให้:** `q = Queue()` (หัวแถว Front อยู่ซ้าย, ท้ายแถว Rear อยู่ขวา: `[Front: ... Rear]`)
> 5. **หากโจทย์ซับซ้อนเกินกว่าจะใช้คำสั่งเดียว** ให้เขียนลำดับคำสั่ง (Sequence of Operations) ให้ถูกต้องและรักษาระเบียบ FIFO เสมอ

## 📋 ตารางโจทย์ Queue สไตล์เดียวกับแบบฝึกหัดในห้อง (พร้อมเงื่อนไขและเฉลย)

| ข้อ | โจทย์ (Input $\rightarrow$ Output) | เงื่อนไข (Condition) | เฉลยคำตอบ / โค้ด (Solution) |
| :---: | :--- | :--- | :--- |
| **1** | **ตอนเริ่มต้น ตัวแปร `q` ว่าง**<br>`[] -> [10, 20, 30]`<br>*(Front: 10, Rear: 30)* | เริ่มจาก Queue ว่าง ให้ใช้คำสั่ง `enQueue` สร้างผลลัพธ์นี้ | ```python
q.enQueue(10)
q.enQueue(20)
q.enQueue(30)
``` |
| **2** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[1, 2, 3, 4]` *(Front คือ 1)*<br>`[1, 2, 3, 4] -> [2, 3, 4]` | ลบข้อมูลที่อยู่หน้าสุด (Front = 1) ออก 1 ตัว | ```python
q.deQueue()
``` |
| **3** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[A, B, C, D]` *(Front คือ A)*<br>`[A, B, C, D] -> [A, B, D, C]` | สลับตำแหน่ง C และ D (ท้ายแถว) โดยห้ามแก้ข้อมูลตรงๆ ให้ใช้ `deQueue` กับ `enQueue` | ```python
# 1. วน Dequeue สองตัวหน้าไปต่อท้าย
q.enQueue(q.deQueue()) # ส่ง A ไปท้าย -> [B, C, D, A]
q.enQueue(q.deQueue()) # ส่ง B ไปท้าย -> [C, D, A, B]

# 2. นำ C และ D ออกมาสลับลำดับ
c = q.deQueue()        # ดึง C ออก
d = q.deQueue()        # ดึง D ออก
q.enQueue(d)           # ใส่ D ก่อน -> [A, B, D]
q.enQueue(c)           # ใส่ C ตาม -> [A, B, D, C]
``` |
| **4** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[1, 2, 3, 4]` *(Rear คือ 4)*<br>`[1, 2, 3, 4] -> [1, 2, 3]` | ลบข้อมูลท้ายแถว (Rear = 4) ออก โดยคงลำดับสมาชิกตัวอื่นไว้เหมือนเดิม | ```python
# Dequeue 3 ตัวแรกแล้วส่งไปต่อท้าย ส่วนตัวที่ 4 (เลข 4) ให้ทิ้ง
for _ in range(q.size() - 1):
    q.enQueue(q.deQueue())
q.deQueue()  # ทิ้งเลข 4 ที่อยู่หัวแถวในรอบสุดท้าย
``` |
| **5** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[1, 2, 1, 3]` *(Front คือ 1 ตัวแรก)*<br>`[1, 2, 1, 3] -> [1, 2, 3]` | ลบเลข `1` ตัวหลังออก (ตัวที่อยู่ระหว่าง 2 กับ 3) | ```python
q.enQueue(q.deQueue()) # ส่ง 1 ตัวแรกไปท้าย -> [2, 1, 3, 1]
q.enQueue(q.deQueue()) # ส่ง 2 ไปท้าย -> [1, 3, 1, 2]
q.deQueue()            # ทิ้ง 1 ตัวที่สอง -> [3, 1, 2]
q.enQueue(q.deQueue()) # ส่ง 3 ไปท้าย -> [1, 2, 3]
``` |
| **6** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[A, B, C]` *(Front: A, Rear: C)*<br>`[A, B, C] -> [A, C]` | ลบ B ที่อยู่ตรงกลางออก โดยห้ามเข้าถึง index ตรงๆ | ```python
q.enQueue(q.deQueue()) # ส่ง A ไปท้าย -> [B, C, A]
q.deQueue()            # ทิ้ง B -> [C, A]
q.enQueue(q.deQueue()) # ส่ง C ไปท้าย -> [A, C]
``` |
| **7** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[A, B, C, D]` *(Front: A)*<br>`[A, B, C, D] -> [D, C, B, A]` | กลับลำดับข้อมูลใน Queue ทั้งหมด (Reverse Queue) โดยใช้ Stack `s` | ```python
# 1. เทจาก Queue เข้า Stack
while not q.isEmpty():
    s.push(q.deQueue())

# 2. เทจาก Stack กลับเข้า Queue ลำดับจะกลับด้านทันที
while not s.is_empty():
    q.enQueue(s.pop())
``` |
| **8** | **สมมติตอนเริ่มต้น ตัวแปร `q` ข้อมูลคือ**<br>`[A, B, C]` *(Front: A)*<br>`[A, B, C] -> [A, X, B, C]` | เพิ่ม X เข้าไปใน Queue ระหว่าง A กับ B | ```python
q.enQueue(q.deQueue()) # ส่ง A ไปท้าย -> [B, C, A]
q.enQueue('X')         # ใส่ X ต่อท้าย A -> [B, C, A, X]
q.enQueue(q.deQueue()) # ส่ง B ไปท้าย -> [C, A, X, B]
q.enQueue(q.deQueue()) # ส่ง C ไปท้าย -> [A, X, B, C]
``` |

## 📌 ข้อสอบข้อเขียนเพิ่มเติม: Special Boundary Cases ของ Queue (5 คะแนน)

**Question:**  
เมื่อเราพัฒนาหรือใช้งาน **Queue ADT (แบบ Circular Array ขนาด $N=5$)** จงเขียนกรณีพิเศษ (Special Boundary Cases) อย่างน้อย **3 กรณี** พร้อมยกตัวอย่าง Method Call และอธิบายว่าเกิดข้อผิดพลาดหรือพฤติกรรมอย่างไรหากไม่เขียนดักไว้

```text
กรณีที่ 1 (Queue Underflow):
ตัวอย่าง: เรียก q.deQueue() ขณะ q.isEmpty()
คำอธิบาย: หากไม่มีข้อมูลในคิว การ deQueue จะเกิด IndexError หรือดึงค่าว่างไม่ได้ ต้องเช็ค if self.isEmpty(): return None

กรณีที่ 2 (Queue Overflow / Full in Circular Queue):
ตัวอย่าง: กำหนดขนาด limit=5 มีข้อมูลอยู่ 5 ตัว แล้วเรียก q.enQueue(99)
คำอธิบาย: ใน Circular Queue หากขนาดเต็มแล้วไม่ตรวจ (rear + 1) % limit == front การ enQueue จะไปทับข้อมูลเดิมที่ Front

กรณีที่ 3 (Pointer Wrap-Around / Index Reset):
ตัวอย่าง: Rear ชี้ที่ช่องสุดท้าย (index 4) เมื่อมีพื้นที่ว่างด้านหน้า
คำอธิบาย: ต้องใช้สูตร modulo (rear + 1) % limit เพื่อวนกลับมาชี้ที่ index 0 มิฉะนั้น Index จะหลุดขอบอาเรย์
```
