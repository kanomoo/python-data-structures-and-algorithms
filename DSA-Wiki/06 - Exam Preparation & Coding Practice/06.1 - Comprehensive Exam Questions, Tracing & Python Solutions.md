## 🧮 หมวดที่ 1: การวิเคราะห์ Big-O และ Data Structure Concept (ข้อ 1 - 5)

### ❓ ข้อที่ 1: การวิเคราะห์ Time Complexity ของ Loop ลึกซ้อน
**โจทย์**: จงวิเคราะห์ Time Complexity ในรูป Big-O ของฟังก์ชันต่อไปนี้:
```python
def example1(n):
    count = 0
    i = n
    while i > 0:
        for j in range(n):
            count += 1
        i = i // 2
    return count
```

**✏️ เฉลยละเอียด**:
- ลูปภายนอก `while i > 0` เริ่มต้นที่ $i = n$ แล้วหารครึ่ง $i = i // 2$ ทุกรอบ $\to$ วนลูปทั้งหมด **$\log_2 N$ รอบ**
- ลูปภายใน `for j in range(n)` วนลูปคงที่ **$N$ รอบ** เสมอ
- ผลรวมการทำงาน $= N \times \log_2 N = \mathbf{O}(N \log N)$

### ❓ ข้อที่ 2: เปรียบเทียบ Singly vs Doubly Linked List ในการ Delete Tail
**โจทย์**: หากมี Pointer ชี้ที่ `head` และ `tail` จงเปรียบเทียบ Time Complexity การลบโหนดท้ายสุด (Delete Tail) ระหว่าง Singly Linked List และ Doubly Linked List พร้อมอธิบายเหตุผล

**✏️ เฉลยละเอียด**:
- **Singly Linked List**: เป็น **$O(N)$** เพราะแม้ว่าจะมี `tail` pointer แต่เมื่อลบ `tail` ทิ้ง เราจำเป็นต้องเปลี่ยน `next` ของโหนดก่อนหน้า `tail` (Predecessor) ให้เป็น `None` ซึ่ง Singly Linked List ไม่สามารถเดินถอยหลังได้ จึงต้องวนลูปเริ่มจาก `head` เพื่อค้นหาโหนดก่อนหน้า `tail`
- **Doubly Linked List**: เป็น **$O(1)$** เพราะมี `tail.prev` ชี้ย้อนกลับไปยังโหนดก่อนหน้า สามารถอัปเดต pointer ได้ทันทีโดยไม่ต้องวนลูป!

### ❓ ข้อที่ 3: ความแตกต่างระหว่าง Stable และ Unstable Sorting
**โจทย์**: อธิบายความหมายของ **Stable Sort** และยกตัวอย่างสถานการณ์จริงที่จำเป็นต้องใช้ Stable Sort

**✏️ เฉลยละเอียด**:
- **Stable Sort**: คืออัลกอริทึมการเรียงลำดับที่ **รักษาลำดับดั้งเดิมของข้อมูลที่มีค่าเท่ากัน** ไว้เสมอหลังการเรียงลำดับ
- **ตัวอย่างการประยุกต์ใช้งานจริง**:
  การเรียงลำดับรายชื่อนักเรียน โดยรอบแรกเรียงตาม "ชื่ออักษร ก-ฮ" และรอบสองเรียงตาม "คะแนนสอบ"
  หากใช้ Stable Sort (เช่น Merge Sort) นักเรียนที่มีคะแนนเท่ากันจะยังคงเรียงชื่อตามอักษร ก-ฮ ตามลำดับเดิมในรอบแรก!

### ❓ ข้อที่ 4: การคำนวณ Index ของ Circular Array Queue
**โจทย์**: Circular Array Queue มีขนาด `capacity = 6`, ปัจจุบัน `front = 4`, `size = 4`
1. จงหาตำแหน่ง `rear` ปัจจุบัน
2. หากทำการ `enqueue()` ข้อมูลใหม่เข้าไป 1 ตัว ตำแหน่ง `rear` ใหม่จะเป็นเท่าใด?

**✏️ เฉลยละเอียด**:
1. สูตร: $\text{rear} = (\text{front} + \text{size}) \pmod{\text{capacity}}$
   $$\text{rear} = (4 + 4) \pmod 6 = 8 \pmod 6 = \mathbf{2}$$
2. เมื่อ `enqueue()` เพิ่ม: $\text{rear}_{\text{new}} = (\text{rear} + 1) \pmod{\text{capacity}} = (2 + 1) \pmod 6 = \mathbf{3}$

### ❓ ข้อที่ 6: การแปลง Infix เป็น Postfix ด้วย Stack
**โจทย์**: จงแปลงนิพจน์ Infix: `( A + B ) * C - D / E` เป็น Postfix โดยแสดงตาราง Trace การทำงานของ Stack

**✏️ เฉลยละเอียด**:

| Token | Stack | Output Expression |
| :--- | :--- | :--- |
| `(` | `['(']` | |
| `A` | `['(']` | `A` |
| `+` | `['(', '+']` | `A` |
| `B` | `['(', '+']` | `A B` |
| `)` | `[]` | `A B +` |
| `*` | `['*']` | `A B +` |
| `C` | `['*']` | `A B + C` |
| `-` | `['-']` | `A B + C *` |
| `D` | `['-']` | `A B + C * D` |
| `/` | `['-', '/']` | `A B + C * D` |
| `E` | `['-', '/']` | `A B + C * D E` |
| End | `[]` | `A B + C * D E / -` |

**ผลลัพธ์ Postfix**: `A B + C * D E / -`

### ❓ ข้อที่ 7: การประเมินผล Postfix (Postfix Evaluation)
**โจทย์**: จงแสดงการคำนวณนิพจน์ Postfix: `6 2 3 + * 4 /` ด้วย Stack

**✏️ เฉลยละเอียด**:
1. Push `6`, Push `2`, Push `3` $\to$ Stack: `[6, 2, 3]`
2. เจอ `+`: Pop `3`, Pop `2` $\to 2 + 3 = 5 \to$ Push `5` $\to$ Stack: `[6, 5]`
3. เจอ `*`: Pop `5`, Pop `6` $\to 6 * 5 = 30 \to$ Push `30` $\to$ Stack: `[30]`
4. Push `4` $\to$ Stack: `[30, 4]`
5. เจอ `/`: Pop `4`, Pop `30` $\to 30 / 4 = 7.5 \to$ Push `7.5`
**คำตอบสุดท้าย**: **7.5**

### ❓ ข้อที่ 9: การ Insert และ Percolate Up ใน Min-Heap
**โจทย์**: พิจารณา Min-Heap Array: `[10, 20, 30, 40, 50]`
ทำการ `push(5)` เข้าไป จงแสดงสภาพ Array ของ Heap หลังทำ Percolate Up เสร็จสิ้น

**✏️ เฉลยละเอียด**:
1. แปะ `5` ไว้ท้าย Array $\to$ Index 5: `[10, 20, 30, 40, 50, 5]`
2. **Compare 5 กับ Parent (Index 2: 30)**: $5 < 30 \to$ Swap! $\to$ `[10, 20, 5, 40, 50, 30]`
3. **Compare 5 กับ Parent ใหม่ (Index 0: 10)**: $5 < 10 \to$ Swap! $\to$ `[5, 20, 10, 40, 50, 30]`
4. **สภาพ Heap Final Array**: **`[5, 20, 10, 40, 50, 30]`**

### ❓ ข้อที่ 10: การหา Topological Ordering ใน DAG
**โจทย์**: กราฟมีโหนด `A, B, C, D` และ Edges: `A->B`, `A->C`, `B->D`, `C->D` จงหาลำดับ Topological Sort ที่เป็นไปได้ทั้งหมด

**✏️ เฉลยละเอียด**:
- Indegree เริ่มต้น: `A:0, B:1, C:1, D:2`
- โหนดที่มี Indegree = 0 คือ `A`
- หลังประมวลผล `A`: Indegree ของ `B` และ `C` กลายเป็น 0
- ดังนั้น ลำดับที่เป็นไปได้มี 2 แบบ:
  1. **`A -> B -> C -> D`**
  2. **`A -> C -> B -> D`**

### ❓ ข้อที่ 11: โค้ดกลับลำดับ Linked List (Reverse Singly Linked List)
**โจทย์**: เขียนฟังก์ชัน Python กลับลำดับ Singly Linked List แบบ In-place โดยใช้เวลา $O(N)$ และ Memory $O(1)$

```python
def reverse_linked_list(head):
    prev = None
    curr = head
    while curr is not None:
        next_temp = curr.next  # 1. จำโหนดถัดไป
        curr.next = prev       # 2. กลับทิศ Pointer
        prev = curr            # 3. ขยับ prev ไปข้างหน้า
        curr = next_temp       # 4. ขยับ curr ไปข้างหน้า
    return prev  # prev จะกลายเป็น Head ตัวใหม่
```

### ❓ ข้อที่ 12: โค้ดตรวจสอบว่า Binary Tree เป็น BST หรือไม่
**โจทย์**: เขียนฟังก์ชัน Python ตรวจสอบว่า Binary Tree ที่กำหนดให้มีคุณสมบัติเป็น BST หรือไม่

```python
def is_valid_bst(root, min_val=float('-inf'), max_val=float('inf')):
    if root is None:
        return True
    if root.val <= min_val or root.val >= max_val:
        return False
    return (is_valid_bst(root.left, min_val, root.val) and 
            is_valid_bst(root.right, root.val, max_val))
```
