(คำแปลภาษาไทย): กำหนดอาร์เรย์ขนาด 12 ช่อง (ดัชนี 0 ถึง 11) จงรัน Insertion Sort จากรอบ $P = 1$ ถึง $P = 11$ โดยแสดงสถานะของอาร์เรย์หลังจบรอบ, ตัวเลขที่ถูกนำมาแทรก (tmp), และจำนวนครั้งของการเลื่อนตำแหน่งข้อมูล (position moves)

Question 4: Selection Sort & Bubble Sort Tracing (10 คะแนน)

4.1 Selection Sort & 4.2 Bubble Sort Tracing (5 + 5 = 10 Marks) Score: 10 Marks

Question Statement (EN): Given the input array $\mathbf{[64, 25, 12, 22, 11]}$.

  1. Show the state of the array after each pass of Selection Sort until fully sorted. State the min element identified and the swap made.
  2. Show the state of the array after each pass of Bubble Sort with early-termination flag checking.
(คำแปลภาษาไทย): กำหนดอาร์เรย์ $[64, 25, 12, 22, 11]$ จงแสดงผลลัพธ์ของอาร์เรย์ในแต่ละรอบเมื่อเรียงลำดับด้วย Selection Sort (ระบุค่าต่ำสุดที่พบและการสลับ) และแสดงผลลัพธ์แต่ละรอบเมื่อเรียงลำดับด้วย Bubble Sort
💡 เฉลยละเอียดและหลักการทางทฤษฎี (Complete Solution & Principles):

1. การทำงานของ Selection Sort:

  • Initial: [64, 25, 12, 22, 11]
  • Pass 1: Min ในช่วง index 0..4 คือ 11 (index 4) → สลับกับ index 0 (64) → [11, 25, 12, 22, 64]
  • Pass 2: Min ในช่วง index 1..4 คือ 12 (index 2) → สลับกับ index 1 (25) → [11, 12, 25, 22, 64]
  • Pass 3: Min ในช่วง index 2..4 คือ 22 (index 3) → สลับกับ index 2 (25) → [11, 12, 22, 25, 64]

2.1 หลักการ Map ของ Binary Heap (Complete Binary Tree to 1D Array)

ทำไม Binary Heap จึงไม่จำเป็นต้องใช้ Pointer เชื่อมโยงเหมือน Linked Tree ทั่วไป?

คำตอบ: เพราะคุณสมบัติ Complete Binary Tree รับประกันว่าโหนดจะถูกเติมเต็มชิดซ้ายเสมอ จึงสามารถ Map ลงใน 1D Array ได้โดยไม่มีช่องว่าง (Gaps) ทำให้หา Parent และ Child ได้ด้วยสูตรคณิตศาสตร์ $\lfloor i/2 \rfloor, 2i, 2i+1$ ได้ทันทีในเวลา $O(1)$ ประหยัด Memory ของ Pointer และเพิ่ม Cache Locality

2.2 การ Trace ฟังก์ชัน insert(x) ด้วยตัวแปร hole

การแทรกข้อมูลใน Binary Min-Heap จะเปิดช่องว่างที่เรียกว่า hole ที่ตำแหน่งท้ายสุดของอาร์เรย์ (currentSize + 1) จากนั้นทำการเปรียบเทียบค่า x กับ Parent ที่ hole // 2 หาก x < array[hole // 2] จะเลื่อนค่า Parent ลงมาที่ hole และเลื่อน hole = hole // 2 จนกว่าจะเจอตำแหน่งที่เหมาะสม (Percolate Up) จึงใส่ x ลงใน hole

2.3 ไวยากรณ์การเรียกเมธอด deleteMin() ใน Python

ในภาษา Python คลาส BinaryHeap เมธอด deleteMin() ไม่มีการรับพารามิเตอร์ใดๆ

min_val = heap.deleteMin()  # ถูกต้อง! ห้ามใส่พารามิเตอร์ เช่น heap.deleteMin(x) เด็ดขาด

2.4 นิยามภาษาอังกฤษของหลักการ Wrap Around ใน Hashing & Queue

Wrap Around Definition: "The circular indexing mechanism where the pointer or probe index that reaches the end of the array (size - 1) cycles back to the beginning (index 0) using the modulo operator (index % size), avoiding array boundary overflow."

2.5 การเลือกค่า R ในสูตร Double Hashing

ในสูตร $f(i) = i \times (R - (X \bmod R))$ ค่า $R$ จะต้องเป็น จำนวนเฉพาะ (Prime Number) ที่น้อยกว่า TableSize เสมอ เพื่อให้ค่า step size ที่ได้เป็นจำนวนเต็มบวก ($1 \le \text{step} \le R$) และเป็น Coprime กับ TableSize ป้องกันการวนลูปไม่ทั่วตาราง
